# ADR-0011: 小众关键词做透 = 自然保护 = 小团队优势

- status: accepted
- date: 2026-08-09
- source: Kun 第 7 轮后方向梳理（原话要点）

## 背景

Kun 明确：**把小众关键词做透，会形成自然的保护**；这也是小团队的优势，且没有 ROI 压力（不需要烧钱抢量）。结合 ADR-0010（纯数字产品、能力/体感双门、形态不限），选词策略从「找容量大词」转向「在小众垂直里做透」。

## 决策

1. **策略优先级**：小众关键词做透 > 大词抢量。一个小众细分里覆盖完整词族（主词 + 长尾 + 相关任务），形成排名/内容/外链的自然壁垒。
2. **形态不偏颇**：Notion 模板（红海）排除；GPTs/AI 生态工具、AI 工具目录/索引、细分从业者模板与数字产品、卖家工具均保留候选。权重由「树」（找词→取证→复读→场景→灯色）统一裁决，不单独偏颇某一形态。
3. **本 > 术，三结合推进**：Ahrefs KD、月搜 1000+、稳定词、趋势、SERP 分析等都是「术」（工具）；Kun 的想法与判断是「本」（本质）；Agent 的检索/取证发现是输入。**本 + 术 + 发现三结合**才能推进，指标永远不替代判断。主流程（找词→取证→复读→场景→灯色）是承载三结合的骨架，不是独立于 Kun 想法的「树」。
4. **无 ROI 压力**：小团队策略，不追求短期大流量；慢而稳地在小众垂直建立资产。

## 理由

- 小众垂直竞争低、内容可做深，单页/单站容易形成自然排名保护。
- 小团队资源有限，做透一个小细分比铺开大词更现实；没有 ROI 压力意味着可以长期主义。
- 纯数字产品（模板/工具/目录/指南）天然适合「做透」——内容即产品，产品即内容。

## 后果

- 后续找词以「小众垂直 × 可做透」为第一筛；大词、红海形态（Notion 模板等）直接排除。
- 与 ADR-0008（旧需求薄弱点）、ADR-0010（纯数字产品边界）共同构成方向三件套。
