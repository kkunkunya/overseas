# ADR-0013: 有限并行的站点组合，而非单站押注

- status: accepted
- date: 2026-08-15
- source: Kun 与哥飞《SEO 扫盲新手指南》精读后的路径对齐

## 背景

当前路径是「垂直细分 + 长期稳定增长」（ADR-0005）。此前知识库把哥飞的多站组合经验简化成「一个站跑通完整闭环后，再复制到多个站」，意外把防止薄站变成了单站押注。

Kun 当前仍在找方向与关键词。只押一个站会把方向、算法、竞争和执行失误集中到单点；但一次铺十个站又会稀释内容、产品、SEO 基础和维护能力，变成薄站组合。

Kun 明确判断：以当前精力，首批可直接上线并运营 3–4 个站；长期正常维护 5–6 个，10 个为硬上限；在完成 4–5 个后，以流量及更早期 SEO 信号决定保留、加码或淘汰。

## 决策

1. **方向并行，首批直接上线 3–4 个站**：不要求先有一个站跑通商业闭环。每站必须是独立的「人群 × 场景 × 关键词簇 × 产品承接 × 变现假设」，不是同模板改域名。
2. **每站先过最小上线质量**：核心任务能完成、目标词与 SERP 已取证、初始 HTML 可抓、页面内容与 title/H1 清楚、索引页面角色/内链/robots/sitemap 就位，并能记录数据；不达标不进入首批。
3. **组合有维护边界**：长期常态维护 5–6 个站，10 个为硬上限。现有站出现内容、SEO 修复或用户反馈维护欠账时，不新增站。
4. **按证据淘汰，不只看短期流量**：每站预设首个 8–12 周观察窗，依次看收录、目标查询展示/长尾出词、目标页排名、有效点击/真实使用、留存或收入。短期无排名不自动淘汰；连续两轮针对性调整后仍无收录改善、无目标词展示且无可解释修复路径，停止投入或归档。
5. **扩张以可维护性与胜者信号为前提**：首批 3–4 个站完成可观测维护后，只有在没有维护积压且已有站持续出现展示、排名、真实使用或收入信号时，才逐步补到 5–6 个；连续两批没有胜者，回到选词/需求取证，不继续堆站。

## 理由

- 当前最大风险是方向判断错误，有限并行让不同垂直假设获得真实对照，避免单点失败。
- SEO 的抓取、索引、排名与信任积累慢，不能用一两周流量替代上线前需求取证，也不能无限等待没有早期信号的站。
- 3–4 个首批站符合 Kun 当前精力判断；5–6 个常态站与 10 个硬上限保留组合分散的收益，同时给质量和复盘留出容量。
- 「站内关联做深一个垂直」与「多个独立垂直站组成组合」不矛盾：前者约束每个站内部不能浅，后者分散不同方向的风险。

## 后果

- 当前阶段选词允许并行筛选 3–4 个候选，并可直接将各自做成首批 3–4 个独立小站。
- 未来产品项目的 SEO 上线检查、数据台账和复盘 skill 应按「每站独立假设 + 页面角色 + 最小观测指标 + 观察窗」设计；工程性 skill 真身仍放具体产品仓库（ADR-0003）。
- 站群互链、批量低质量页面、没有独立需求证据的复制站不属于本决策允许的组合。
- ADR-0011 的「小众关键词做透」继续有效，但“做透”以每个垂直站为单位，不再被误读为整个探索期只能押一个站。
