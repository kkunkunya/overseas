# ADR-0012: 触达策略——先做产品力，后做线上触达；不先卖空气

- status: accepted
- date: 2026-08-09
- source: Kun 第 8 轮后拍板（PRC 照片工具）

## 背景

此前 mvp-validation skill 等材料建议「先卖空气/最小触达验证需求」。但 Kun 对 PRC 照片工具明确否掉这条路径：

- 需求已经多重取证（官方 FAQ + 申请表 PDF + Reddit/TikTok/YouTube 真实讨论），**不需要再最小验证**。
- AI 时代拿粗劣 demo 触达，**没有人会回复**；只有产品力足够才值得触达。
- Kun 是个人方式出海，**无法投流**，只能靠产品本身吸引人。

## 决策

1. **PRC 照片工具不走「先触达验证」**：直接开发（PRD 已交付），开发期就把 SEO/GEO 做好。
2. **线上触达放在产品开发得差不多之后**：先有拿得出手的产品，再做触达（社媒/Reddit/内容页等）。
3. **综合多种打法**：不绑定单一打法；触达时机、渠道、方式按产品阶段选择最适合的。
4. 卖空气/最小触达仍保留为其它方向的**可选**手段，不因本 ADR 废弃（mvp-validation skill 仍是工具箱一格）。

## 理由

- 触达是放大器：粗劣产品 + 触达 = 浪费触达机会；好产品 + 触达 = 复利。
- 个人出海无投流预算，信任和产品力是唯一杠杆；触达窗口要用在产品成熟后。
- 「多种打法综合」符合 Kun 一贯的「术」「本」结合：方法都是术，按场景裁决。

## 后果

- PRC 工具项目里程碑不含「先卖空气」阶段；M1-M4 为开发 + SEO/GEO + 上线。
- 触达计划在 M3/M4（产品可用）后另行制定。
- 本 ADR 只约束当前产品线；其它方向仍可自由选择验证方式。
