# ADR-0014: SEO 产品先做可用承接，以观察窗而非预售作默认淘汰机制

- status: accepted
- date: 2026-08-16
- source: Kun 完整精读哥飞《SEO 扫盲新手指南》后拍板

## 背景

`mvp-validation` 把真实价格、预订或人工交付实验做成独立的活跃 skill。它本意是低成本验证付费意愿，但在当前「垂直细分 + 长期稳定增长 + 有限并行站点组合」路径中，容易把卖空气误读为每个方向的默认前置。

Kun 的当前判断是：AI 时代轻量产品可较快做出一个真正完成任务的版本；拿未兑现的粗略承诺过早触达，既难得到高质量反馈，也会浪费首次分发机会。哥飞课程的主线也不是用短期排名或一次预售决定生死，而是先完成搜索承接与产品体验，再经历抓取、索引、比较、信任积累、分发、回访和持续优化。

ADR-0012 已为 PRC 照片工具采用产品优先、后触达策略。本 ADR 将该原则确立为当前 SEO 产品组合的默认淘汰机制；它不否认历史材料中预售/人工验证作为其他路径的研究工具。

## 决策

1. **移除活跃的 `mvp-validation` skill**：不再把卖空气、预订或预付测试放在默认路由中。相关知识保留在知识库，可在未来出现明确高开发成本、不可快速兑现核心任务、且用户主动要求预售实验时重新设计一项针对该情境的能力。
2. **SEO 产品默认直接做可用 MVP**：在选词/SERP/竞争/场景/变现已取证后，进入站点蓝图，做能兑现核心任务的最小产品，同时落实 SEO/GEO 最小包；不以 Landing Page 的口头兴趣或短期预售替代产品承接。
3. **淘汰按观察窗与证据链进行**：每站预设 8–12 周观察窗，依次观察收录、目标查询展示/长尾出词、目标页排名、有效点击/真实使用、回访/留存或收入。短期无排名不淘汰；连续两轮针对最早瓶颈的调整后，若仍无早期信号且没有可解释修复路径，停止投入或归档。
4. **持续优化是默认经营方式**：页面、产品、内链、分发、外链和变现以每轮一个最早瓶颈的实验持续改善；有效用户和业务结果而非 PV、一次引用或一次排名决定加码。

## 理由

- 搜索型产品的真实价值需要由可用承接页、真实任务完成和长期搜索信号共同验证，预售页不能替代这些证据。
- AI 降低了做核心功能的成本，但也提高了用户对可用结果的期望；产品力、体验和可被引用的事实资产应更早进入验证。
- 8–12 周观察窗和“两轮针对性调整”同时避免了短期恐慌淘汰与无限等待，与 ADR-0013 的有限并行组合相容。

## 继承与取代

本 ADR 继承 ADR-0012 的「先有拿得出手的产品，再用触达放大」原则，并将其从 PRC 产品的局部策略扩展为当前 SEO 产品组合的默认路径；ADR-0012 由本 ADR 取代。ADR-0005 的路径主导、亲测裁决与“卖空气并非强制门槛”仍有效；其旧的 runtime skill 指针改由本 ADR 的主链取代。

## 后果

- 主链变为：方向/选词 → `seo-site-blueprint` → 独立产品仓库实现可用 MVP → `seo-readiness-audit` → `distribution-link-loop` / `geo-source-loop` → `product-growth-review`。
- `product-growth-review` 必须以每站独立假设、基线、8–12 周观察窗和两轮针对性调整为默认复盘边界。
- `mvp-validation` 的术语、历史材料与预售案例仍可检索，但不显示在活跃 skill 路由中。
