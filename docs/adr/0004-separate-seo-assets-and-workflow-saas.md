# ADR-0004: 将 SEO 资产与 Workflow SaaS 分轨验证

- status: accepted
- date: 2026-07-30

## 背景

本库原先以关键词、SERP、竞争和变现为主线查方向。这适合目录、内容和轻工具等 SEO 资产，却曾把 `calculator`、`generator`、`template` 等一次性查询误推向订阅产品，也可能因 B2B 工作流搜索量不强而过早淘汰。

近期的针织定价计算器验证没有出现强行动信号；专业服务商家的 Chrome SERP 实查则显示，泛 `client intake software` 等词已有成熟承接。两者说明关键词、CPC 或 SERP 缺口都不能单独裁决持续产品价值。

## 决策

1. 方向验证先标为 **SEO 资产**、**Workflow SaaS** 或 **混合式楔子**，三条路线不放进同一张关键词表或统一总分排序。
2. SEO 资产仍按查询意图、SERP、可维护页面、流量和自然变现验证，允许一次性任务。
3. Workflow SaaS 在扩词前先验证人群的触发、完整工作与最痛交接、当前替代、损失、长期价值、切换理由、买家与可复现触达；搜索词只承担发现、获客或商业角色之一。
4. 混合式楔子先作为免费 SEO 入口；只有用户反复提交真实后续工作，才升级为持续产品假设。

## 理由

- 统一关键词流程的替代方案更简单，但会混淆“能获得搜索流量”和“值得持续付费”的不同命题。
- 分轨保留赫兹 018 对搜索和竞争的判断，同时让 028/029 的人群、场景与痛点证据在 Workflow SaaS 中先行。
- 两张证据卡让每条路线的最早失败闸门可观察，避免以热度、CPC、竞品数量或一次性查询掩盖核心未知。

## 后果

- `direction-validator` 提供 SEO 关键词证据卡和 Workflow SaaS 证据卡；社区观察先导向其中一条路线。
- 搜索没有形成时，Workflow SaaS 可以用合规社区、伙伴、人工服务或定向触达取得行动证据；它不因此直接淘汰。
- SERP 的竞品和社区热度均记录为局部信号，继续通过具体交接、切换理由和真人行动验证。
- 以后新增找词或人群方法时，必须说明它服务哪条路线，不能恢复成统一总分。
