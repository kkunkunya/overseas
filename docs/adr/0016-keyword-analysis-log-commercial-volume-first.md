# ADR-0016: 选词先记分析账，正式池只收有量的 C 词

- status: accepted
- date: 2026-08-23

## 背景

ADR-0015 把选词改成「付费参考站先行，再交 3 个核心词 + 10–15 个长尾」。执行中仍会出现：没有表或图就填数、跳过分类直接交短名单、把信息词或品牌首页词塞进正式池、只按 KD 排序、以及把 SERP 页型完全不同的高量 C 词当成自己的订阅产品词。

需要把已经在 `CONTEXT.md` 和 `vertical-keyword-loop` 里跑通的闸门写成现行权威，避免后人只读 ADR-0015 的「优先 KD < 50 且量较好」而把顺序和池子搞反。

## 决策

1. **证据**：流量、反链、流量占比和排名词只读人交的 Semrush **导出或截图**。图上/表上没有的数写 `No data`，禁止编造，也不用 treg/插件顶上。
2. **先记关键词分析账**：人交证据后，先转录词、月搜、词流量、KD、意图，分成蹭流量 / 品牌观察 / 反推，写成当前领域笔记。账没记完不交 3+15。
3. **正式池只收 C**：信息词、未核实意图、品牌首页词不进短名单。品牌词只作品类观察，并从旁边反推通用 C 词。
4. **先量，再 KD**：排序先看月搜和参考站该词带来的流量，再用 KD 当「能不能排到前面」的杠杆。量大的 C 不因 KD 略高就丢掉；KD 极低但量瘦的只当长尾，不当核心。新手仍优先 KD < 50，这是过滤器不是禁区。
5. **页型必须对得上要做的产品**：C 和高量不够。SERP 若是百科、即时聊天、本地 pack 或其它与自己产品形态无关的页，该词不进本轮订阅/工具站词池。
6. **交付形状不变，页数更少**：仍交 3 个核心词 + 10–15 个长尾。3 个核心词对应可做的任务页；长尾默认并进这 3 页的词群，不为每个长尾开独立 URL。

## 理由

- 有搜索、有流量才有获客；KD 解决的是「这些人能不能看见你」，不能反过来当第一筛子。
- C 是付费意愿的粗筛，分析账避免把参考站里的百科词、品牌词和未核实说法直接写成产品词。
- 塔罗轮次里 `psychic` 一类词量/C 都好看，但 SERP 是即时咨询而不是可订阅工具；若不锁页型，下一垂直还会把错形态的词做成核心。

## 继承 ADR-0015

- 参考站先行：先多模型找付费/订阅站，人审商业逻辑后再挖词；电商和纯广告站不进正式清单。
- 量/KD 必须取证、禁止编造；数字是过滤器不是宗教；SERP 与真实付费逻辑仍硬于裸 KD。
- AITDK 等扩词器只提供说法，不含量/KD。
- 词名单之后用 Instagram / Reddit / TikTok 反查需求，再做产品。

## 后果

- `vertical-keyword-loop`、选词 SOP、`CONTEXT.md` 选词词条以本 ADR 为现行权威。
- ADR-0015 由本 ADR 取代；ADR-0007 仍经由 0015 被本条间接取代，不必改 0007 的 status 行。
- 塔罗等单次短名单、分析账和分析报告留在 `1-选方向/` 与产品仓库，不进 ADR。
