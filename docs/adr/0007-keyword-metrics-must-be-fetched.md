# ADR-0007: 选词量/KD 必取证，参考带不卡死

- status: superseded by ADR-0015
- date: 2026-08-09

## 背景

垂直选词需要判断「有没有人搜、好不好排」。此前 handoff/作战卡把「月搜 1000+ ∩ KD 0–30」写成软筛，执行中易滑向两种错误：

1. **不取证**：无 🔑 就跳过数字，凭 SERP 印象或感觉给 go/watch；  
2. **卡死阈值**：略低于 1000 或 KD 略高于 30 就机械删词，或反过来数字过线就免死。

第 5 轮实践证明：Ahrefs 免费 KD Checker 等通道可在无完整付费账号时拉到 **KD + SERP 页指标/topVolume 线索**；AITDK 网页 Keywords 只扩词、**不含量/KD**。

## 决策

1. **证据硬**：选词交付必须尽力取 **月搜与 KD**（或明确标注的降级量线索），写清厂商、日期、地区；**禁止编造**。  
2. **阈值软**：约 **月搜 1000+、KD 0–30** 是**参考带**（缩小池子/排序），不是全有或全无门槛；略偏可 `watch` 交人审；过线但 SERP 铁板/无付费线索仍可 `reject`。  
3. **通道顺序（可换实现）**：免费/登录网页 SEO 工具（如 Ahrefs Free KD）→ 插件人眼读数/粘贴 → 付费 Overview 或 DataForSEO API；AITDK 等 AI 扩词器**不得**冒充量级源。  
4. **SERP 仍硬于裸 KD**：结构可打、场景清、付费线索与数字并列；低 KD + 极低量或巨头 SERP 不得因「好排」单独升级为 go。  
5. 术语写入 `CONTEXT.md`（月搜、参考带、topVolume 线索、shortage、灯色等）；作战卡「量/KD」行改为「证据硬、阈值软」。

## 理由

- 选词是数据分析问题，不是品味投票；无数字的 go 不可复查。  
- 全条件卡死会丢掉「贴线但场景极清」的切口；无阈值则无法排序。  
- 免费 KD/页指标通道已足够把「完全没数」升级为「有厂商标注的线索」，成本低于等完整 API。

## 后果

- 第 5 轮及以后词表：无量/KD 必须写 No data / 线索性质，不得空填。  
- `direction-validator` 与关键词证据卡须显式要求量/KD 取证字段与参考带用法。  
- ADR-0002 三件套仍成立；本 ADR **补强**量/KD 层，不取消 AITDK 扩词角色。  
- 完整 Keyword Overview（CPC、12 月趋势）仍推荐，但不阻塞「有 KD + topVolume 线索」的 watch 级结论。
