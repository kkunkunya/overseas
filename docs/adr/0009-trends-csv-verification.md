# ADR-0009: 趋势验证必须逐词下载 CSV 原始序列，截图口述不作数

- status: accepted
- date: 2026-08-09
- source: 第 7 轮成功经验固化

## 背景

第 7 轮早期用 Chrome 截图口述 Trends 曲线，代理返回「jewelry insurance 明显缓涨」等结论；但核对原始截图发现**证据错位**：jewelry insurance 截图空白、另外两张都是 watch appraisal。若直接落库会把未经验证的趋势当已验证。

## 决策

1. **趋势验证标准动作**：逐词打开 Google Trends（US / Web Search / 过去 5 年）→ 等 Interest over time 图渲染 → 下载 CSV 原始周度序列 → 计算**首年均值 vs 末年均值、零值占比、季节/尖刺**，再作结论。
2. **截图/口述不作数**：无法导出或渲染失败时写 `No data`，不得根据空白图或印象声称趋势。
3. **指数不是月搜**：0–100 相对指数只用于比较形状，不换算成搜索次数。

## 理由

- 趋势形状是可复核数据，不是观感；CSV 序列可重算、可审计。
- 截图会错位/空白/被模型误读，导致「未验证当已验证」的脏数据进入决策。

## 后果

- 后续所有趋势取证按此标准动作执行；skill 的找词步骤已固化该姿势。
- `docs/kun-profile.md` 三波流程与协作契约已同步。
