# ADR-0001: 方法论以赫兹原文为主源

- status: accepted
- date: 2026-07-21

## 背景

知识库同时收录了多类材料：赫兹 227 篇一手文章（`原文/`）、目录站 YouTube 视频笔记、YC 课程整理、小耳朵复盘，以及 Agent 执行调研时写的二手笔记。

选方向阶段一度以**目录站视频**的 near me 流程为主操作手册，导致用户困惑：「笔记层写得很细，但赫兹原文好像没在指挥」。用户明确决定：**以后都以赫兹大佬为主**。

## 决策

1. **赫兹主源**：`原文/` 中赫兹文章是本项目学法与行动的默认第一权威。
2. **辅源**：目录站视频、YC、小耳朵等可参考，**不得在冲突时覆盖赫兹**；引用时标明来源层级。
3. **Agent 默认行为**：给建议、定调研步骤、写笔记时，优先对齐赫兹对应篇目（如选方向优先 015/018/028/029 等）；辅源只作案例或补洞。
4. **既有 E / 目录站材料**：保留为辅源案例与练习痕迹，须在导航/方法文首标明「辅源；主框架见赫兹」；后续深挖与拍板改以赫兹评估框架为准。

## 理由

- 本库建设目标就是「按 6 步重排赫兹 227 篇 + 二手笔记」——主源与仓库使命一致。
- 用户已读材料后主动选择赫兹，减少多权威互相打架。
- 目录站视频仍有价值（具体形态 case），但应挂在赫兹「找词→评估词→验证」之下，而不是反过来。

## 后果

- Agent 不得再默认「先打开目录站视频流程再行动」；应先问：赫兹哪几篇覆盖这一步？
- 笔记层新增内容：能链到 `原文/` 篇目的要链；纯辅源内容标题或导语标明辅源。
- 与赫兹冲突的旧表述（若有）在碰到时改正，不搞一次性全库重写。
- 用户仍可选用目录站形态做第一站，但验证标准走赫兹（尤其 018、015），而非仅视频清单。
