# ADR-0006: 淘汰既有三方向候选，主线只走垂直选词

- status: accepted
- date: 2026-08-09

## 背景

知识库中曾并行或接力验证过多条候选：TikTok Shop landed-cost 计算器（卖空气合同已定但未闭环）、激光清洗服务目录（watch 证据）、专业服务商家 Workflow（人群卡 / 第 4 轮）。用户已亲身尝试并判断**均不适合继续**，且不再按旧「多轮验证池续研」方式推进；当前路径为 ADR-0005 的垂直细分 + 长期稳定 + 简单闭环。

若不显式淘汰，Agent 与导航仍可能把 TTS / 激光清洗 / 专业服务当 watch 旁路或可自动续研。

## 决策

1. **永久移出活跃候选**（本阶段）：TTS landed-cost、激光清洗服务目录、专业服务商家 Workflow 主线。状态统一为 **历史淘汰 / reject**，不是 `watch`。
2. **材料保留为历史案例**：相关笔记与证据卡不删，仅改状态与入口文案；可查阅归因，**不自动续研、不排入本周闭环**。
3. **当前唯一主线入口**：[第一步-垂直选词与简单闭环.md](../../1-选方向/第一步-垂直选词与简单闭环.md)——新开垂直场景词 → 简单闭环；E 目录词表等方法可用，但须重新选词，不继承上述三方向。

## 理由

- 用户实测否决优先于材料完整度；继续 watch 会占决策带宽。
- 删文件会丢失败归因；保留 + 入口切断即可。
- 与 ADR-0005「路径与实测优先」一致。

## 后果

- `候选方向池`、`材料总览`、`_本步导航`、作战卡同步标注淘汰。
- 再启用任一方向须用户**明确重开**，并重新走选词/验证，不得默认恢复旧合同。
