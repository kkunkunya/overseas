# ADR-0008: 选方向——旧需求薄弱点切入 + 蓝海市场优先 + 不做纯计算器

- status: accepted
- date: 2026-08-09
- source: Kun 第 7 轮拍板（原话要点）

## 背景

第 7 轮按 ADR-0007「量/KD 取证 + 参考带」筛出两个 watch：pool cost calculator（KD 7、topV 线索 6.2K）与 jewelry insurance calculator（KD 25、topV 线索 8.7K、趋势 4.15×）。但 Kun 明确否掉这个方向：

- 他家里没有泳池、不了解泳池建造；也不熟悉珠宝保费估算。**没有体感，不想做。**
- 明确不做「趋势上涨 + 本质没人竞争」的**新需求**——他判断这类需求没有验证，不值得投入。
- 明确不喜欢**纯计算器**这种单薄形态；独立站想清楚「到底做什么样的站」比先抄一个工具形态更重要。
- 他不只想做欧美；欧美已是红海，可以去看**东南亚、中东等蓝海增长市场**，同一种需求在那边可能还少人做。
- 前辈方法（「术」）要结合他自己的判断（「本」），以「服务好用户、通过独立站产品赚到钱」为目的；不要做复杂，但面向海外与全球。

## 决策

1. **选方向目标从「找低 KD 新词」改为「在已验证旧需求/已有系统里找薄弱点」**：优先分析已形成规模、已有付费行为的系统（平台、行业、工作流），找出它没做好的一个点切入；不追未验证的「新需求」。
2. **纯 calculator/单薄工具形态不再作为首选交付物**；若要计算，也只是完整价值主张的一小块，不是站的全部。
3. **市场优先从欧美红海扩到东南亚、中东等增长市场**：观察这些市场已投资哪些系统、还缺什么、竞争（SD/竞品）是否稀少、需求是否明确；有明确需求且竞争少才切入。
4. **体感是硬门**：Kun 不熟悉、不想懂的题材不硬选；数字好看不替代体感。
5. **「术」「本」结合**：材料（赫兹等）提供方法与经验切片，方向裁决始终以 Kun 的判断和实测为准。

## 理由

- Kun 的判断：已验证需求里找薄弱点，比赌「新需求没人做」更接近可复制生意；欧美红海下，蓝海市场同需求可能竞争更低。
- 纯计算器容易做但浅，难以成为有长期价值的独立站；只有「服务好用户、接得住钱」才值得做。
- 体感缺失会导致无法长期研究（与第 6 轮 wedding deprecate 同一教训）。

## 后果

- 下一轮选词不再以「KD 低 + 趋势涨」为第一优先级；改为：**选定一个已有规模系统 → 找薄弱点 → 看市场（欧美/东南亚/中东）→ 验证需求与竞争 → 再做产品**。
- `vertical-keyword-loop` skill 与 `docs/kun-profile.md` 需同步「旧需求薄弱点 + 蓝海市场 + 不做纯计算器 + 体感硬门」。
- 第 7 轮笔记的 pool / jewelry / watch 三个词标记为**不合本轮方向**，归档不深挖；除非 Kun 之后改变方向。
