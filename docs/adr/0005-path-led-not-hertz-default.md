# ADR-0005: 路径主导，赫兹降为可选工具箱

- status: accepted
- date: 2026-08-07

## 背景

ADR-0001 规定方法论以赫兹原文为默认第一权威，辅源冲突时一律以赫兹为准。实际学习中发现：

1. 「出海」过泛——网站、APP、工具站、内容产品等，只要能**一份做、多份卖**并面向海外订阅/付费，都是产品；不存在唯一正确操作手册。
2. 赫兹 018 等全套闸门对当前阶段偏重，容易把「选路径试」拖成「先学完框架」。
3. 用户已明确采纳《AI应用出海新手完全指南》中的两条路径：**垂直细分** + **长期稳定增长**；**热词抢占**明确不做。
4. 用户要求：不全盘否定赫兹，但**不以赫兹为主导**；按垂直方向、自身情况与收集到的信息选型，赫兹只在相关时当参考。

## 决策

1. **路径主导**：当前默认打法 = **垂直细分起手** + **长期稳定增长**（内容 / 多平台持续推流 / 产品迭代）。热词抢占不在当前路径菜单内。
2. **材料按需取用**：赫兹 `原文/`、辅源笔记、外部 PDF/视频等均为**工具箱**。与当前路径相关则用，冲突时以**当前路径目标 + 实测结果**裁决，不以「是否赫兹」裁决。
3. **赫兹不再是默认第一权威**：ADR-0001 由本 ADR 取代。笔记仍可标注材料来源（赫兹 / 未署名 PDF / Marc Lou…），便于检索，**来源层级不再等于执行优先级**。
4. **Agent 默认行为**：先对齐用户已选路径与垂直方向，再从知识库抽相关片段；不默认「先过赫兹 015/018 闸门才能动」。卖空气、018 评分等仍可作为**可选检查项**，不设为强制门禁。
5. **术语与数字**：KD、月搜门槛等进入词汇表时标明出处与局限；厂商 KD 不可互比，不当成唯一真理。

## 理由

- 用户已用自身判断选定可尝试路径，继续以赫兹压路径会造成执行摩擦。
- 多材料并存时，「主源压一切」会掩盖路径差异（SEO 工具站 vs Workflow SaaS vs 社区产品）。
- 保留赫兹全文仍有查阅价值，降级为工具箱成本低、可逆性高于删库。

## 后果

- `CONTEXT.md`「权威与来源」、`AGENTS.md` / `CLAUDE.md` 约定同步本决策。
- 既有「辅源不压主源」表述改为「材料按需；路径与实测优先」。
- `direction-validator` / `vertical-keyword-loop` 等 skill 仍是按当前问题选用的流程，不是默认必经；SEO 产品默认主链见 ADR-0014。
- 旧笔记里的「以赫兹为准」字样不搞一次性全库重写；碰到再改，或新笔记按本 ADR 写。
