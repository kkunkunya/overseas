# ADR-0010: 出海数字产品方向——纯数字、无重线下耦合、能力与体感双门

- status: accepted
- date: 2026-08-09
- source: Kun 第 7 轮后方向梳理（原话要点）

## 背景

Kun 对出海数字产品方向做了收敛，明确三点：

1. **放弃高净值人群 + 重线下耦合的项目**：马场管理、私人航空包机报价、游艇经纪等本质是「数字产品 × 现实生活强耦合」，以当前状态很难做好；未来海外旅居、找到更多需求后或许能结合。
2. **暂缓强线下连接项目**：如泰国本地小店建站（Google Maps 上没有、低价代建）——需要大量线下连接，深入了解后再考虑。
3. **聚焦「我能提供且有切身感受的数字产品」**：形态不设限——
   - 系统已建好时，做 **Notion 模板** 同样是数字产品；
   - 在 ChatGPT / OpenAI 官方允许的生态下，开发工具解决特定人群痛点并收费；
   - **行业指南、供应商数据库** 也是好方向；AI 索引同样是产品，变现不一定订阅制。

核心思路：**由 Agent 检索关键词、寻找海外正在增长的需求，结合 Kun 自身能力**；两点结合，除此之外无限制。

## 决策

1. 候选方向必须同时满足：**纯数字产品（无重线下耦合）** + **Kun 有切身感受** + **Kun 能做出来**；三者缺一不可。
2. **形态不限**：模板、生态工具（ChatGPT/OpenAI 等官方允许范围）、指南、目录/数据库、AI 索引、站点均可；**变现不限于订阅制**（一次性、列表收录、分成等皆可）。
3. **找词方式固定**：AI 检索海外增长需求 × Kun 自身能力交集；不单独依赖数据，也不单独依赖兴趣。
4. 高净值 × 线下耦合类、强线下连接类项目**不再主动提出**（未来旅居后再考虑）。

## 理由

- 纯数字产品交付成本低、可复制、可全球分发，适合当前阶段；线下耦合需要 Kun 目前不具备的资源与实地能力。
- 有切身感受 + 能做出来，才能长期投入并做出差异化（与第 6 轮 wedding deprecate、第 7 轮 pool/jewelry 无体感教训一致）。
- 形态不限避免把「独立站工具」当成唯一答案，Notion 模板 / 指南 / 数据库同样是可验证的数字产品。

## 后果

- 第 7 轮 pool / jewelry insurance / watch value，以及马场 / 包机 / 游艇等 B2B workflow 观察池**全部归档，不续研**。
- `vertical-keyword-loop` 的方向铁律与 `docs/kun-profile.md` 同步更新。
- 后续候选必须带「纯数字 + 能力/体感 + 海外需求」三要素；缺一即降级或淘汰。
