# sol 独立评议原文

日期：2026-09-06。以下为独立席位意见，不代表已采纳或实测结论；主会话核对与取舍见上一层整合迁移方案。

1. **推荐**：选 **B，保留现有 11 个闭环入口，按缺口选择性吸收方法/reference**。首批只试证据合同、技术审计覆盖、测量合同；暂不新增入口，不整套安装。方法规则仍落 mono，学习依据进知识库，具体采集/埋点工具随产品仓，符合 [ADR-0017](/Volumes/Storge/oversea/docs/adr/0017-overseas-method-skills-live-in-mono.md)。

2. **决定性理由与证据**：

- 本地 11 个入口已覆盖“方向→词→任务页→上线审计→分发/GEO→增长复盘”，缺的主要是检查深度和统一证据形状，并非流程阶段。
- Agentic 原文要求 `Finding / Evidence / Impact / Fix`、置信标签和全局去重验证；这是可横向复用的净新增，但其固定权重和总分没有效果验证。
- Corey 的 `analytics` 从业务决定倒推事件，能补 `product-growth-review` 目前“要求自有数据，却未规定数据如何成为可信基线”的上游缺口。
- pSEO 原文强调逐页独有价值、数据防御性、样本和索引门；适合作为 `seo-site-blueprint` 的后置扩量门，不应成为新入口。
- 三组笔记共同警告：评分、阈值、平台机制和作者案例均未实测，不能整套升格为本地规则。

3. **最强替代**：A“只归档知识”。若近期没有产品要上线、没有重复审计需求，或无人承担 reference 漂移维护，A 的成本最低。出现同类缺陷连续两次漏检，或同一证据合同跨两个产品稳定复用后，再进入 B。

4. **假设与未知**：尚未用同一真实站对照新旧方法；未知外部脚本准确率、依赖成本和维护频率。现行规则也有可疑限制：Semrush 单一证据源、正式池只收 C、固定 3+15、统一 8–12 周及两轮调整，可能随站型失配；`geo-source-loop` 对 AI 获取网页机制的确定性描述易随平台变化。这些均只标**候选复核**，不能由文档缺词推断真实行为失败。

5. **会改变结论的新证据**：整套外部体系在两个不同产品上显著减少漏报且维护成本可接受，可转向 D；选择吸收后持续产生重复入口、路由冲突且无额外发现，则退回 A；若现有 11 个入口在盲测中已覆盖决定性问题，则不改运行方法。

6. **置信度**：**中高，0.78**。对架构选择较有把握，对具体检查项效果仅中等，因为没有目标站实测。
