# Astra 独立初步评议

推荐 B：保留现有11个发现入口，以具体任务中的缺口吸收方法与必要reference；另把可学习材料归档。不是为了减少名称而无条件保留现有文本，也不是按外部项目数量迁移。

决定性依据：现有 seo-readiness-audit 已包含页面任务、初始HTML、canonical、robots、sitemap、内链、真实搜索证据；seo-site-blueprint 已包含任务分组、URL角色和brief；distribution-link-loop 已有小批quality pass与目录台账。这些不是空壳。外部有相同大分类，整套迁移会叠出同义入口和另一套依赖。

首批一个切片：Agentic LLM audit rubric 的“发现/证据/影响/修复 + 置信度/未知”表达，附到 seo-readiness-audit 的报告模板。现有文本已有证据/责任位置/复查方式，净增价值只可能是让推断和未覆盖明确呈现；必须用同一任务的产物对照证明，不能说缺栏目就已发现失败。原作任意分数公式、缺schema一律critical示例、variance改善数字不随模板带入。

第二批候选：content brief 的新页/改旧页分支、保留强项/仅补缺口、逐条承诺核验，落 seo-site-blueprint 的按需reference。现有brief已有独特任务和来源价值，不重复新增内容总入口；不带硬字数、关键词必须进图片alt、固定排除某类SERP网站。

其他候选：Corey site-architecture 的旧URL清单与迁移映射供已有站重构时参考；不把现有首版MVP蓝图升级成常驻大站架构流程。营销上下文可映射现有客户任务/证据合同，不新增另一份必读global context。复盘的基线/差异报告可对照现有 product-growth-review，看是否真的提高可比性；没有真实场景先归档。GEO相关平台访问规则与本地“搜索稳定露出前停GEO”等前置约束列为需证据复核的候选，不能直接把任一家规则奉为事实。

最强替代 A：目前没有真实任务暴露缺口，或用户主要想学方法时，先只归档；成本更低。整体替换仅在现有路由已实测失效、某一外部体系完整可用且替换成本更低时考虑。

假设/未知：用户是否以增强现有体系为目标尚未确认；还无同一真实任务的before/after对照；实际项目/数据权限/工具依赖未验证；来源许可和必要依赖需按选中切片核对。

改变意见的证据：原版已经同样给出可靠置信度区分，则模板无需迁；选中切片增加篇幅却未减少误判则撤回；反复任务证明必须独立触发，才考虑新skill。

置信度：策略中高；首批净增效果中低，待实际场景验证。

建议三张决策票：净新增价值对照；策略与归属；首批验证和回退。当前仅是推荐，不能把图中决策票自动关闭。
