# Kun 画像（选方向 / 找词时先读）

> 2026-08-09 建档。用途：每轮找词开场前，Agent 先对齐「Kun 是谁、在意什么、正在做什么」，再问提问卡。**本文件随聊天持续更新**，新素材直接补进来。

## 现状（2026-08）

在做三件事：
1. **网站方向**：帮别人做产品赚钱（服务 + 逐步转可复制产品）
2. **自媒体**：中文内容（B站/小红书/抖音/Feishu 台账）
3. **出海内容/产品**：本知识库主线

## 兴趣与技能

- 篮球、健身
- 懂一点科研技巧（**科研本身不想做了**——2026-08-09 明确）
- 最近刷得多：《人民的名义》《大明王朝》《我的世界》（Minecraft）
- **会看到新东西就随手丢过来——随手种子是最真实的信号**，Agent 必须记录并反馈「值不值得查」

## 原则与倾向（2026-08-09 陆续确认）

1. **抓人性、抓欲望**：做「有钱 + 有欲望」人群的生意；高流动现金流人群（日结收入）对订阅价格的心理锚点更轻（女主播、二奢、美甲、贴膜、卡牌卖家…）。**科研这类「自己不想做」的方向不碰。**
2. **solve your own itch**：大佬模式（Levels 做 NomadList 因为自己是数字游民；Marc Lou 每个产品有 24 小时版）。最理想 = 兴趣 × 欲望人群 × 搜索量三交集。
3. **兴趣是权重，不是行业白名单**：先跨行业广搜，让数据把池子缩小；再看具体词是否让自己愿意点进去、研究下去。健身、Minecraft、AI 等只是普通候选，不得卡死在已知兴趣；完全无体感的词也不因数字好看直接推进。
4. **Agent 先过滤再交付**：不把几十个生词原样丢给 Kun。候选必须先过「明确人群 × 明确任务」垂直门、真实量/KD 数据门、长期趋势门和 SERP 门；最终最多交 3 个，说明厂商/国家/日期与证据缺口。
5. **数据 + 感觉都要**：「数已经有了，但感觉没有」= 不会长期做；感觉是长期主义的燃料。没体感不硬选。
6. **旧需求薄弱点 > 新需求**（ADR-0008）：优先在已有规模、已有付费行为的系统/平台/行业里找它没做好的一个点切入；不做「趋势上涨但没人竞争的验证需求」。
7. **不做纯计算器**：纯 calculator 是单薄形态；若要做站，先想清楚「做什么样的独立站、如何服务好用户并接得住钱」，计算只是其中一小块。
8. **欧美不是唯一市场**：欧美已是红海；优先看东南亚、中东等蓝海增长市场，同需求可能还没人做、竞争更少。
9. **「术」「本」结合**：前辈方法（赫兹等）只是「术」，方向裁决以 Kun 的判断与实测为准（「本」）。
10. **没 get 到人性的词直接 deprecate**：婚礼词即例——不是自己了解、高净值人群会做的事，从人性角度没 get 到 → 不续研。
11. **纯数字产品边界（ADR-0010）**：只做「纯数字、无重线下耦合、我有切身感受、我能做出来」的数字产品；形态不限（Notion 模板 / ChatGPT 生态工具 / 行业指南 / 供应商数据库 / AI 索引）；变现不限于订阅制（一次性/收录/分成皆可）。高净值×线下耦合、强线下连接类项目不主动提，未来旅居后再考虑。
12. **小众关键词做透（ADR-0011）**：把小众关键词做透形成自然保护，是小团队优势；无 ROI 压力，不抢大词。Notion 模板等红海形态排除。
13. **本 > 术，三结合推进**：Ahrefs KD、月搜 1000+、稳定词、趋势、SERP 分析等都是「术」（工具）；Kun 的想法与判断是「本」（本质）；Agent 的检索/取证发现是输入。**本 + 术 + 发现三结合**才能推进，指标永远不替代判断。
14. **蓝海不局限东南亚**：蓝海是全球的（中东/拉美/非洲/印度皆可），只要「社媒有人问 + KD 低 + 前排没做好 + 当地语言可搜」即可；不过度设计标准。
15. **社媒是重要找词渠道**：ins / reddit / x / threads 的讨论、提问、hashtag 是需求人话信号，与 autocomplete/Ahrefs/SERP 并列；可批量扫描作辅助。

## 协作契约（2026-08-09 确认）

1. **主动提问**：Agent 在发现「可能有东西但需要 Kun 判断」的点时，主动提问，不等指挥；问题聚焦：这块东西在哪、要不要看、为什么值得。
2. **未提领域先记录**：Kun 没说过、但 Agent 判断有潜力的领域，先记进随手种子库/观察区，再告诉 Kun「这里有东西，具体在哪」，让他提前准备。
3. **只给可执行下一步**：要么让 Kun 打开几个网页一起看，要么让他补词/场景；不停在「我再想想」。
4. **到判断节点就停**：不独自跑完整条链，需要 Kun 体感/拍板处停下来一起头脑风暴。
5. **找到词先沟通再深挖**：Agent 一旦觉得找到词，先停下来与 Kun 沟通并让他自己去看；避免直接进入深度调研而不给 Kun 亲自验证的机会。

## 已跑通三波流程（Kun 确认，2026-08-09）

1. **第一波：发现和筛选**：批量候选 → 垂直门/数据门（量/KD/趋势）/SERP 门粗筛，落到少数几个词。
2. **第二波：打开网站 + AITDK 分析**：逐站看功能/定价/获客、AITDK 块锚定读流量指标（域级 vs 页级分开标）、traffic.cv 详情核对。
3. **第三波：YouTube/Instagram 了解关键词真实场景**：看用户怎么搜、怎么用、痛点在哪；写场景卡。
4. **最后：Kun 决定是否做产品**；灯色建议由 Agent 给，go 由 Kun 拍。

> 找词/找需求阶段：Kun 做独立站，主线是**找词 + 找需求**；趋势/数字产品等只要他感兴趣就持续投入。核心思路：**把能做好的、属于自己能做的那一块做好**。
