# 主会话核对意见

本轮只评议，未修改方法、HTML或既有决策。独立报告实际配置为 opus[1m]，具体底层版本未确认；原报告的“非 Opus 5”应理解为未以 Opus5 名义确认，不能据别名断言具体版本。

核对方法文件后：
- GEO 的稳定露出硬门与提前记录问题/来源基线有冲突；建议取消观察态的该前提。原报告仍为优化态保留稳定露出门槛，其必要性未取证，不能直接采纳。
- 观察窗不应阻止新的决定性反证触发复核、收窄或停止。不要把竞争者发布免费版自动当作决定性反证。
- Semrush 是 ADR-0016 明确的既有选择，其他数据能力存在不等于允许替代此专门流程。可讨论供应商依赖，但不定性为必修逻辑错误、不自动改ADR。
- lifecycle-route.md 第9行已有电商/代理/团队 reference，因此“总路由完全没有入口”不准确。待改善的是已有产品协作问题能否直接进入，而非新建全部分支。
- “内容 writer”是职责称呼，不必有独立skill；明确由谁承接写作即可，不因名字不存在增加第12个入口。
- 商业立项词池与后续支持内容选题可以分离；商业短名单未纳入信息词不等于禁止说明页。明确下游选题来源更合适。
- 渠道研究、素材和可行的站点验证可提前准备；页面导航可直链当前下一步，不必新建排序系统。

独立报告关于自建爬虫推导完整索引架构、排名与引用高度相关等说法仍超出所引证据的直接范围，不作为本轮确认的技术事实。后续若改机制说明，应核对一手资料并限制措辞。

建议优先三项：GEO准备/观察入口；决定性新证据的重新判断出口；正文与已有产品专项分支的责任交接。保留11入口与25模块结构。
