# 已废弃：validation-instrument 创建指示

> status: deprecated by ADR-0014（2026-08-16）

此文曾计划为“卖空气验证站”创建 `validation-instrument`，并以 `mvp-validation` 的概念页、预售和主动触达数据决定 build / maintain / abandon。

当前 SEO 产品组合改为：完成方向与搜索取证后，做能兑现核心任务的可用 MVP，同时完成 SEO/GEO 最小包；每站以 8–12 周观察窗观察收录、目标查询展示、真实使用、回访/留存与收入，并在每轮只改最早瓶颈。具体复盘由 `product-growth-review` 承担。

因此不创建该 skill，也不再引用已移除的 `mvp-validation` 资产。历史方法仍可从第 1 步卖空气材料中查阅；只有未来出现开发成本高、核心任务无法快速兑现且用户明确要求预售实验的情境，才重新为那个情境设计最小能力。见 [ADR-0014](../adr/0014-product-first-observation-window.md)。
