# vertical-keyword-loop

先找已经靠订阅或明确付费活下来的参考站，再从它们的流量和词里收自己的产品词。

```text
目标领域
→ 多模型参考站
→ 付费/订阅筛选
→ 人看站并导出 Semrush
→ 用导出写成功根源并挖词
→ 3 核心 + 10–15 长尾
→ Instagram / Reddit / TikTok 反查
→ 出海付费 App
```

## 1. 多模型找参考站

拿到目标领域后，并行问当前环境里能用的多个模型（Grok、ChatGPT、Cursor 等），各自列出这个领域里已经在赚钱的网站，再合并去重。缺某个模型时用已有通道补齐，不要因少一个模型停工。

正式清单只收能看清谁付钱、为什么付钱的产品站或 App 站：订阅、买断、应用内付费墙。Semrush 意图可标 C（Commercial）的词所指向的站优先。电商目录和靠广告活的内容站可以记一笔说明需求，不进正式参考清单。

按 [参考站清单](assets/reference-sites.md) 写成带超链接的 Markdown，方便人直接点开。每条写：站名、URL、一句话商业逻辑、为何像目标领域。不要编造流量、反链或 KD。

这一步完成的标准：人拿到一份可点击清单，能自己打开站，并导出准备深挖的域名的 Semrush。

## 2. 等 Semrush 导出，再写成功根源

人会自己看 Title、Description 和付费入口。流量、反向链接、流量占比和排名词**只读人导出的 Semrush**（或同等导出文件）。没有导出就停，说明还缺哪几个域名的哪些表，不要改用 treg、插件或脑补数字顶上。

导出到手后，按站整理：

- 这个域名大概有多少流量
- 反链和引用域量级
- 流量里搜索、直接、社媒、推荐各占多少

成功根源必须能用一句话说清：它靠搜索、品牌、社媒还是买量活着，钱是怎么收的。说不清就还没读完导出，不要开始挖词。

## 3. 从成功站挖词

只从导出覆盖、且确认是付费产品的站往外挖。词的月搜、KD、意图（C 优先）同样只读这份导出。

选词思路：

- 先找搜索量大、KD 较低的词。新手优先 KD 低于 50。更高不是禁区，只是通常意味着更强的品牌和更多外链。
- 偏门：该领域已经打出名堂的品牌词，常常量不小、竞争却低于同义大词。用它们观察用户怎么搜这个品类，不是去抢别人的品牌首页。

按 [选词短名单](assets/keyword-shortlist.md) 交出 3 个核心关键词和 10–15 个长尾词。每个词写清量、KD（导出里没有就写 No data）、来源站、为何值得做成付费 App。

## 4. 社区反查后交产品

词名单交给人之后，仿照参考站去 Instagram、Reddit、TikTok 等平台反查真实需求。需要登录态或原帖核验时走社区调研；需要公开检索或 treg 时交 `treg-research`。

反查要回答：这些人现在怎么凑合、卡在哪一步、会不会为结果付钱。然后再结合词和参考站的付费方式，决定做什么出海 App。

页面规划交 `seo-site-blueprint`；任务或形态仍不清时交 `direction-validator`。

**完成判据**：可点击的付费参考站清单已交出；成功根源和词表都写在人导出的 Semrush 上；3 个核心词和 10–15 个长尾有来源和量/KD（或明确 No data）；下一步是社区反查或产品。
