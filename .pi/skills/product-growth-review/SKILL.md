# product-growth-review

SEO 拉来第一次发现，产品与品牌决定是否回来。按完整链条找最早失效环节，而不是只盯排名、PV 或第三方流量估算。

```text
抓取/索引 → 展示/查询 → 点击 → 任务完成 → 回访/分享 → 注册/付费/留存 → 单一调整 → 决策
```

## 1. 建本轮基线

每站在上线时预设首个 **8–12 周**观察窗，并固定国家/语言和数据口径；记录 GSC/Bing 的索引、查询、展示、点击、排名与 sitemap 错误，站内到达、开始、完成、结果有用、回访、分享、注册、付费，分发来源、外链/引用变化与收入。区分 UV、PV、Session、Direct 和第三方估算，避免跨平台混算或把 Direct 全部当手输网址。

## 2. 从最早失效环节诊断

| 现象 | 优先检查 |
|---|---|
| 无展示或流量归零 | 需求是否下降；否则依次查可访问、抓取、索引、意图/页型、主题覆盖与竞争 |
| 有展示、少点击 | title/description、SERP 承诺、页型与目标国家/语言 |
| 有点击、少开始或完成 | 首屏承诺、速度、输入成本、核心功能、信任和结果质量 |
| 能完成、不回访/不分享 | 结果是否真有价值，保存/协作/后续任务、分享理由和品牌记忆 |
| 有用户、不注册或不付费 | 付费时刻、价格、支付摩擦、升级价值和市场匹配 |
| 广告收入差 | 有效市场、RPM、页面深度、体验损失和其他变现模型 |

短期没有排名不是自动失败；同样，流量大不是商业成立。分清需求消失与站点能力失效，第三方渠道占比只作线索，不倒推单一因果。

## 3. 一次只改变一个最早瓶颈

写清本轮：基线、最早问题、一个调整、预期可观察变化、观察窗口和停止条件。调整可能是补一个独立任务页、修正承诺、提升任务结果、补一个分发渠道、改变价格路径或收窄人群；不同时启动一串无法归因的改动。

窗口结束后输出：

```text
数据与口径：
最早失效环节：
本轮唯一调整：
预期 / 实际：
证据边界：
下一步：加码 / 再测 / narrow / watch / 归档
```

短期无排名不淘汰。完整观察窗内，连续两轮针对性调整后仍无收录改善、目标查询展示、真实使用或其他可解释的早期信号，且没有新的需求/承接/竞争证据时，归档该站或切口；已被证实有效的任务、页面或来源才加码。

**完成判据**：复盘卡有基线、最早诊断、一个改变和明确决定；成功以有效用户与业务结果收口，而不以单个流量数字收口。
