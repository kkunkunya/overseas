# ask-overseas

按当前最早未通过的环节路由，不按用户提到的名词堆叠 skill：

```text
外部信号 / 资料
→ 客户任务与当前替代
→ 值得承接的产品切口
→ 可用 MVP 与上线观察
→ 搜索、引用与增长资产
```

| 当前事实 | 下一步 |
|---|---|
| 要把视频、文章、帖子或课程材料归档进知识库 | `kb-ingest` |
| 需要用关键词、SERP、竞品页面、反链、社区或 AI 回答取得实时外部事实 | `treg-research`；先说明这条事实要改变哪个产品判断。 |
| 只有想法、人群、社区或产品方向，尚未确定客户任务和产品切口 | `direction-validator` |
| 已确定从搜索机会进入，要验证搜索词背后的任务、当前替代和可承接缺口 | `vertical-keyword-loop` |
| 已有窄承诺、目标词/SERP/竞争/场景与变现线索，准备做能兑现核心任务的首版 | `seo-site-blueprint`；再在独立产品仓库实现可用 MVP。 |
| 产品页已实现，准备上线、刚上线，或需要排查抓取/索引/收录 | `seo-readiness-audit` |
| 核心任务页已被用户完成，需要获得首批合资格用户、社区反馈或第三方引用 | `distribution-link-loop` |
| 已有明确的 AI 用户问题，需要查来源并补自有事实资产 | `geo-source-loop` |
| 已有一站的 8–12 周 GSC、行为、分发或收入窗口，需要决定补页、改产品、加码或停 | `product-growth-review` |
| 当前阻塞是具体代码、部署或界面实现 | 进入独立产品仓库的工程流程；本库提供方法背景，不写产品代码 |

已明确的任务直接进入对应 skill，不强制经过此入口。每次只给一个下一步，并说明它要消除哪项不确定性。

**完成判据**：当前环节、最早缺口与一个下游 skill 已确定；路由器不重复执行下游流程。
