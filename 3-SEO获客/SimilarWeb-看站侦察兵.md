# SimilarWeb — 竞品流量与需求分析工具

> 类型：网站流量情报工具（竞品分析 / 需求验证）
> 官网：https://www.similarweb.com/
> 记录日期：2026-07-20
> 定位：出海做 SEO 和竞品研究时的"侦察兵"——输入任意域名，看它的流量规模、来源、关键词、竞品

## 核心能力
- **流量估算**：输入一个网站域名，看它的月访问量、访问时长、跳出率、流量趋势
- **流量来源构成**：Direct / Organic Search / Paid / Social / Referral / Mail / Display 各占多少——一眼看出这个站是靠 SEO 还是靠投放
- **关键词**：带来流量的 top 关键词（自然 + 付费），直接给你 SEO 选词参考
- **竞品发现**：列出同类竞争站点——找对标、找细分
- **受众地理**：用户来自哪些国家/地区——验证你要做的市场有没有人
- **受众兴趣**：这些用户还访问什么——交叉需求挖掘

## 对出海做产品的用法
1. **找方向/验证需求**：看到一个赛道，搜头部几个站点，看流量大不大、来源是不是 SEO（能复利）。流量来源靠 Search 的 = 可以用 SEO 切入；全靠 Paid 的 = 砸钱赛道，慎重
2. **竞品研究**：输入直接竞品，看它的 top 关键词和引流站——直接抄作业（对应赫兹"竞品是最好的老师"）
3. **看市场天花板**：头部站点月访问量 = 这个赛道的流量天花板参考
4. **找外链资源**：Referral 来源 = 哪些站点在给它导流，那些站点可能是你能争取的外链/合作点

## 和已有资料的关联
- **05 AITDK**：AITDK 看 SEO 指标（KD/搜索量/收录），SimilarWeb 看整站流量画像——一个看词、一个看站，互补
- **03 赫兹"需求挖掘"大类**：赫兹多次用 Similarweb 看竞品流量、验证赛道（具体篇目见 03 索引"需求挖掘"）
- **04 增长漏斗**：SimilarWeb 的"流量来源构成"就是漏斗最上层的诊断工具——你的竞品流量从哪来，你也该往那发力

## 免费版限制与建议
- 免费版只显示部分数据、有每日查询次数限制，但看单站流量概览够用
- 出海早期用免费版 + AITDK + Google Trends 三件套先跑起来；做出规模后再考虑付费
- 浏览器装 SimilarWeb 插件，访问任意网站时侧边栏直接显示该站流量画像，最顺手
