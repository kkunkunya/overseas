# 框架：SEO × 产品 × 分发增长闭环

> 用法：把「找词、做站、SEO/GEO、分发、留存、变现、复盘」放进同一条决策链。它是当前「垂直细分 + 长期稳定增长」路径的执行总纲，不替代具体选词取证、产品验证或产品仓库的工程实现。
>
> 来源：从《[哥飞-SEO扫盲新手指南](哥飞-SEO扫盲新手指南.md)》54 节及本库已有实践归纳；材料是工具箱，实际取舍由路径与亲测裁决。

## 一句话

> SEO 不是给网页塞关键词，而是让合资格用户在搜索中发现一个能把任务办掉的产品；产品体验、分发、回访与变现共同决定这份流量是不是资产。

## 全链路

```text
兴趣/体感中的细分场景
→ 人群 × 场合 × 任务
→ 需求、SERP、竞争、变现与市场取证
→ go / watch / narrow / reject
→ 一页一任务的可用承接页
→ 可抓取、可理解、可索引的 SEO 基础
→ 社区 / 内容 / 目录 / 作者等首批分发
→ 真实任务完成、回访、分享、自然提及
→ 搜索拉新 × 品牌回访 × 外链/引用
→ 匹配的付费、线索、联盟或广告变现
→ 用 GSC 与站内行为复盘，补页 / 改产品 / 收窄 / 停止
```

这不是一条“网站上线后等排名”的流水线。产品承接和分发路径在立项时一起设计；搜索积累和用户反馈上线后一起发生。

## 1. 选的不是词，是可赢的用户任务

从自己愿意长期理解的场景出发，翻译成用户会主动搜索的语言。月搜、KD、KGR、CPC、趋势都只是候选排序线索；真正要看的是：

```text
这个国家/语言下是否有一组真实查询？
→ SERP 前十主要是什么页型，用户想要工具、文章、目录还是服务？
→ 对手为何能排：页面承接、品牌、外链、产品体验还是历史积累？
→ 我能否做一个资源匹配、窄于头名的任务、人群或页型？
→ 用户在这个任务、价格、支付方式下有没有变现线索？
```

结论允许是 `go / watch / narrow / reject`。需求有、但当前资源找不到可赢切口时，`reject` 是止损，不是失败。兴趣是长期做深的优势，不替代证据；低 KD 也不替代真实 SERP。

## 2. 页面先承接任务，SEO 再负责发现

用户进站是为了生成、编辑、比较、计算、导出、下单，或得到足够具体的下一步，不是来读 SEO 文案。

- **一页一任务，不是一词一页**：近义词和同一任务的长尾由一张强页承接；任务、流程或 SERP 页型不同才拆新页。
- **功能与文字是同一份承诺的两面**：功能完成任务；title、H1、正文、示例、限制和 FAQ 让机器与第一次来的用户理解它是什么、给谁用、结果是什么。
- **先做窄页面，再织主题树**：核心任务、子任务、场景问题用有语义的内链连接；每个新增索引页都必须有独立任务和独有价值，不能只替换关键词或城市。
- **首版不是空壳，也不是全功能平台**：完成核心任务的最短功能链 + 实质说明 + 正确 SEO 基础即可。账号、后台、复杂套餐等由真实使用决定是否补。

## 3. 机器理解是 SEO 的地基

要排名的页面先确保：关键内容在服务器初始 HTML 中可读（避免纯 CSR 空壳）、title/description/H1 说明核心意图、可从站内浅层抵达、允许抓取与索引，并进入只含规范索引 URL 的 sitemap。

```text
要排名：可访问 + 可抓取 + 可索引 + 内链 + sitemap
公开但不想排名：允许抓取 + noindex，不进 sitemap
敏感数据：登录/权限控制；robots 只能减少抓取，不能保护数据
```

GEO 不另起一套神秘优化。AI 答案通常仍以传统搜索索引与少量可信网页为上游：先让搜索与用户读懂你的工具、教程、案例、比较页，再观察 AI 是否引用；不为一次 AI 提及批量造空页。

## 4. 外链与分发不是“发 URL”

站内相关性让页面有资格参与结果，相关编辑性引用帮助搜索引擎信任它，体验决定用户会不会继续找别家。外链报告里的一条 URL 要拆成三层：

```text
用户能看见、能点
→ 不等于爬虫能稳定读到
→ 也不等于它有相关的编辑推荐价值
```

优先争取公开初始 HTML 中的标准 `<a href>`、与落地页任务相关、带真实推荐语境的链接。目录、资料页、社媒动态和 JS 跳转也可能带来发现、点击和品牌传播，但不能全部按 SEO 权威票计算。

竞品反向工程不复制全部链接，而是分类并建立可复用机会台账：用户自发推荐、榜单/目录/测评、内容或合作、PR、社区/创作者传播。每个来源记录它为什么会收录竞品、对应哪张任务页、规则/联系人、成本、实际点击/使用/引用结果。

## 5. 产品 × 分发 × 回访是增长飞轮

```text
SEO / 教程 / 社区 / 目录 / 创作者
→ 合资格新用户第一次发现
→ 产品完成真实任务
→ 用户保存、回访、直接打开、品牌搜索或分享
→ 更多自然提及、外链和稳定使用
→ 搜索与品牌继续增强
```

产品是入场券，分发是增长引擎，二者是乘法关系：产品不好，营销只会放大失望；产品有价值却无人看见，也不会变成生意。分享机制应是互利的：新用户立即受益，分享者获得合理价值（额度、导出、协作、展示或身份），并且单位经济、归因、限额和防刷都成立；不靠虚假噱头刷传播。

`Direct` 流量可作为回访/品牌线索，但也会混入书签、私聊、邮件和 App 的无来源跳转。第三方流量数据用来找问题，不用来倒推精确因果。

## 6. 变现跟着任务走，不跟着 PV 走

```text
高频、持续的核心任务 → 订阅 / 按量 / API / 高级能力
购买或选择时刻 → 一次性付费 / 联盟 / 商业线索
信息浏览、且流量规模足够 → 展示广告
三者都没有 → 回到需求与承接判断，不用广告硬救
```

市场价值不按国籍贴标签，而按「人群/国家 × 任务 × 定价 × 支付方式 × 变现模型」观察真实结果。广告看 RPM/CPM，工具看注册、激活、付费、留存与支付摩擦，线索生意看合资格程度和成交。

UV 是去重访客，PV 是页面浏览总数，会话是一次连续访问；平台口径会不同。对工具站而言，任务完成、回访、分享、注册与付费通常比漂亮 PV 更能指导决策。广告不能打断核心任务，短期 RPM 不能换长期留存损失。

## 7. SEO 是长期实验，不是短期排名赌局

SEO 要经历抓取、索引、比较和信任积累。已在上线前确认词群需求、意图、竞争和变现后，两周没排名不是换赛道理由；但也不能靠“再等等”逃避判断。

每个页面/站按最小闭环复盘：

```text
搜索任务
→ 可用承接页
→ 发布并确保可抓取
→ 带来首批真人
→ GSC：展示 / 点击 / 查询 / 排名
+ 站内：完成 / 回访 / 分享 / 注册 / 付费
→ 补页面、改产品、补分发、收窄或停止
```

用多个独立的「人群 × 场景 × 词群 × 承接 × 变现假设」小站分散风险，但每站都必须做深一个垂直；不是一次铺十个薄站。当前组合以证据决定加码或淘汰。

## 最重要的七条

1. **先选窄任务，再谈大流量。** 小站的优势不是更全，而是在一个具体场景更贴用户。
2. **SERP 比 KD 更重要。** 指标只排优先级，真实前十决定该做什么页、能否分食。
3. **需求先于短期排名。** 上线前取证；上线后用周期和证据判断，不让一时波动主导。
4. **一页一任务。** 关键词是入口语言，任务完成才是页面存在的理由。
5. **产品负责完成，SEO/GEO 负责被发现和理解。** 其中任何一端为零，增长很难成立。
6. **分发与外链都要回到真实价值。** 不是堆 URL，而是让合资格用户、编辑或作者有理由使用和引用。
7. **最终看有效用户，不看流量幻觉。** 完成、回访、付费、留存和收入才决定是否继续投入。

## 不要做的事

- 只看月搜、KD、KGR 或 DR 就立项；
- 为占词批量造换词、换城市的薄页；
- 把字数、关键词密度、外链数当成刷分 KPI；
- 把社媒动态、目录资料页或 JS 跳转全部当 SEO 权威外链；
- 把 AI 引用当作绕开 SEO、产品和分发的捷径；
- 用短期广告收入损害核心工具体验；
- 两周没排名就放弃，或因为已经投入又拒绝 `reject`。
