## 一句话概念

SEO = **和搜索引擎交朋友**：主动降低机器理解你网页的成本（抓取 → 理解 → 匹配 → 排名）。竞争单位是**关键词**不是全网；排名按三层走——站内 SEO 进候选池 → 外链上第一页 → 用户体验定名次；见效 2–6 个月，是慢变量不是开关。GEO（进 AI 答案）的本质还是来自 SEO。

## 可复用细节

### 1. 世界观（节 1–8）
- **交朋友 = 降低机器理解成本**：爬虫只读 HTML 文字，看不见你工具多好用。文字必须回答「我是什么、服务谁、解决什么需求」。
- **利益交换**：谷歌收录你不是慈善，是它需要最新最全的内容留住用户 → 已有网页覆盖不了新需求 → 新站永远有机会。
- **竞争单位**：一个关键词的 SERP = 几十页的小排行榜。选词 = 选战场（对接垂直细分）。
- **三层排名逻辑**：① 站内 SEO（标题/描述/H1–H6/正文讲清主题）→ 进候选池；② 外链（信任票）→ 上第一页；③ 用户体验（不 pogo-sticking、完成任务）→ 定名次。
- **主体内容**：爬虫先剥掉导航/侧栏/页脚/广告等模板区，只提取主体内容作判断——模板区堆词白堆。早年堆关键词有效，现在 AI 语义理解能读懂上下文，堆词失效且伤质量。写内容三标准：围绕一个明确主题，写**完整**（覆盖用户会问的）、**自然**（说人话）、**能解决搜索需求**（真有用）的内容（节 5）。
- **候选集合 = 入场券**：倒排索引先按词捞出候选页，页面主题和关键词关系不清就进不了候选池，后续排序与你无关（节 6）。
- **两个目标两道门槛**：① 被爬虫抓到、进索引库 = 有没有**参赛资格**（靠站内 SEO：可抓取性、内容结构、关键词匹配）；② 进前两页即前 20 名 = 排多靠前（靠页面/站点权重 + 真实满足用户意图）。第三页以后几乎没人翻，前 20 是近期目标线。后期维护就按两道门槛查：资格丢了（被 deindex/robots 误拦）先救资格；排名掉出前 20 是警报线，补内容/外链、看竞品（节 7）。
- **时间预期**：老词被服务多年的页面占着，你做得更好还要长期表现得更好；高竞争词 2–3 个月到半年。上线后没排名 ≠ 被惩罚（节 28）。
- **立项四维竞争评估**：选词时从四条线看与前十的差距——①排名面（SERP 前排是谁、有无薄页可打）②外链面（对手引用域门槛）③留存/体验面（对手页面好不好用，pogo-sticking 暴露）④时间面（对手积累了几年的历史信任）。差距可承受才 go，否则换更窄的词或换页型（narrow）——不止看 KD（节 8）。

### 2. GEO 的本质来自 SEO（节 4、32）
- AI 产品**不建谷歌级全网爬虫**（太贵），拿网页只有三条渠道：① 自己抓少量特定页面（训练/回答问题所需）② 读用户提交的网址 ③ 调第三方搜索接口拿少量结果。
- → AI 答案引用的网页，绝大多数来自**传统搜索引擎排名的上游结果**。不在 Google/Bing 排得上，基本对 AI 不可见。
- **GEO 来源资产闭环（节 32）**：从 AI 的检索/思考过程**反推真实检索词**（如问 Claude 工具类问题，看它检索 `Best AI Video Generator`）→ 去 Google/Bing 查这些词的前排来源页 → 建自己的工具落地页 + 有独有价值的教程/案例/比较页（真实用法、样例输入输出、限制、数据或工作流）→ 在规则允许的社区发帖带来反馈和自然引用机会 → 只挑任务真正匹配的少数外部榜单/测评/资源页争取真实收录。工具页负责完成任务；自有博客/教程页是可长期积累、可被搜索与 AI 引用的来源资产；社区贴偏分发与反馈；外部榜单是第三方推荐机会。必要时可评估付费收录，但 AI 每次改写词、取材动态，收录不保证引用，现阶段 AI 直接流量有限 → 不盲买所有前十，按相关性与投入产出筛。

### 3. 初始 HTML：避免纯客户端渲染（节 4–5）
- 爬虫第一抓只拿到服务器返回的 HTML。纯 CSR = 空壳模板，正文要 JS 跑完才有 → 爬虫要么额外执行 JS（谷歌把 SSR 渲染预算只留给高权重站，新站没这待遇），要么直接读不到。
- → 关键文本必须直接存在于初始 HTML；SSR/SSG/预渲染或至少正文服务端直出。对谷歌和 AI 爬虫同样成立。

### 4. 站内基本功（节 9–12、25、27、35–36）
- **页面写法模板（节 9、23，工具站最实操）**：功能满足到站后的使用，文字负责让机器在用户到来前发现你。五层——① **首屏功能优先**：核心工具/游戏入口/立即开始放首屏，SEO 正文不阻碍真人完成任务；② 语义主干：核心词进 title + meta description + H1–H6（爬虫靠这套骨架识别主题与章节）；③ 正文六要素：用途、适用场景、操作方法、优势、限制、常见问题，既是用户说明书也是机器主题声明，放在功能后覆盖新用户疑问；④ 信号互相印证：核心词在标题/描述/H1/关键段落自然出现，相关词/同义词补语境，不是同一词塞满全页；⑤ 最终服务真人：写「你的背景图一键抠干净」而不是「最好用的抠图工具」——自夸形容词零信息，把产品价值翻译成解决什么问题、怎么解决。机器可读不等于写机器垃圾，清晰准确的说明也服务第一次使用的人。
- **双层内容策略（节 24）**：同一页不是写两篇内容，而是同时过两套标准。机器理解层要让搜索/AI 解析「这页是什么、工具解决什么问题、服务谁、匹配哪些查询」——结构清楚、标题层级和关键词/功能表述明确，比文采更重要；用户阅读层决定信任、使用和转化——还要准确、自然、可读，有例子、步骤、边界和真实结果。机器可读不等于可以写垃圾：清晰准确有用的同一段说明通常兼顾两层；只为识别而堆词，即使有曝光也难留人。
- **标题层级与一词一页（节 25）**：`<title>` 是搜索结果/浏览器标签标题，H1 是页内主主题，核心意图应在两者中清楚出现；H2/H3 用来拆分用户的具体子问题，不能只为塞词造标题。每页服务一个核心搜索意图，强页可自然覆盖近义/长尾词簇；一个词群若出现不同任务/页型，拆页而不是硬塞。
- **密度与长度（节 10、25，课程经验要降级使用）**：核心词密度 3–5%是哥飞的自然覆盖**参考带**，不是 Google 公开目标，更不是 skill 要强行达标的 KPI；单页 600、800 词也是「更容易覆盖完整问题」的经验，不是长度门槛。正确顺序：先覆盖搜索意图 → 用 title/H1/H2/H3 与正文让主题清楚 → 再查核心主题是否完全缺失、无关模板词/精确短语是否异常重复 → 最后自然调整。扩篇幅靠补功能/用法/限制/比较/例子，不靠重复关键词。防界面词淹没核心词（音效站例子）：100 个「播放」按钮会把「音效」淹没 → 按钮名改成「点击音效」「鼓掌音效」等具体名称让核心词自然出现；再用图标/CSS 减少按钮文字重复，但必须保留 aria-label 无障碍名称，不能牺牲屏幕阅读器。
- **意图驱动的主题树与 sitemap（节 11、25–26）**：按搜索意图的父子关系组织「核心落地页/栏目页 → 独立子任务页 → 具体场景或问题页」，再用有意义的父子/相关内链连接；不要机械规定首页=主词、二级=次词、三级=长尾——首页只有自己服务核心意图时才承担核心词，独立任务另建落地页。**长尾页不是词更长，而是任务更具体、意图更明确的独立页面**；它更容易先获得收录、展示、用户使用与外部引用。把长尾页有语境地链接回对应的上层页，有助于爬虫理解主题关系并让链接网络传递页面重要性；不是「用户点击一次就有积分自动传给首页」。内链双重作用——帮用户逛 + 帮爬虫发现页面与看懂层级；离首页越近（层级越浅）的页面通常更重要。sitemap = 机器可读的网址清单：只列希望参与排名的**规范 URL**（可访问、可抓、可索引、非重复/非跳转/非 noindex），上线后提交 GSC + Bing Webmaster；每次发布由框架/CMS 自动更新，日常看后台抓取时间和错误，不必每次手动重提。它是站点架构的镜子，不是保证收录的技巧。robots.txt 必在 `/robots.txt`；sitemap 常放 `/sitemap.xml`，也可由 robots.txt 用 `Sitemap:` 声明。
- **抓取 ≠ 索引（重要纠正）**：robots.txt = 根目录规则文件，管「爬虫来不来访问」，主要用来降低无价值页面的抓取负担；noindex = 页面 HTML 标签或 HTTP 头，管「抓到的页面进不进搜索库」。Google 官方规则是：若目标是让一个公开页面**不出现在搜索结果**，应让 Google 能抓该页并读到 noindex，**不要同时用 robots.txt 把它挡住**；否则它看不到 noindex，外部链接仍可能让 URL 以无摘要形式留在索引。真正敏感页靠登录/权限，不靠 robots。
- **页面角色与维护**：要排名的产品/工具/内容页 = 放导航/栏目浅层 + 允许抓取/索引 + 列入 sitemap + 内链外链加速发现；公开但不想排名的登录/注册/筛选结果/重复页 = noindex（且允许爬虫读到标签）、不列 sitemap；敏感后台/账单/用户数据 = 权限控制，可另用 robots 降抓取。每次新增一类路由或改部署时，检查这三种角色有没有配错；新站大量低价值页会浪费抓取资源、稀释整站质量信号。
- **页面扩张边界（节 28）**：页面多不等于垃圾：真实电商商品/分类/分页、目录对象页、独立工具任务页可以规模化，前提是每页确实服务独立商品、任务或用户决策。危险的是为占词而批量替换城市/关键词/标题，内容薄、重复、没有新增结果或行动价值。页面数不是 KPI；每个新增索引页都要答出「服务哪个独立任务、提供什么独有价值、为什么用户不该只看父页/另一页」。排名差先排抓取/索引、意图/页型、独立价值、竞争/体验/外链，不能把“被惩罚”当默认解释。
- **要排名的页面四动作**：放导航/栏目浅层位置 + robots 不误拦 + 不带 noindex + 内链外链加速发现——让谷歌更快更清楚知道「这页重要」。
- **多语言 SEO（节 35–36）**：多语言不是把中文/英文页一对一翻译，而是对每个目标国家/语言重新研究一遍当地市场：真实任务词、用户常问问题、功能叫法/行业术语、当地 SERP 页型、竞品/替代方案；再按当地意图重组标题、正文、例子、问题顺序和 CTA。AI 只在真实语言市场研究之后做整理、扩写、润色，不能拿一篇中文原文直接翻成多语模板。已验证、能维护的语言版本才列入 sitemap/参与索引；未验证市场可暂不做，或测试但 noindex、不列 sitemap，集中维护少数带来用户/收入的版本。重复内容不等于必然“惩罚”，更常见是搜索引擎选一个版本、其余不收录/不排名；但大规模低价值近似页会伤质量判断，复制他人还叠加版权与品牌风险。用自己的产品能力、案例和使用流程回答用户问题。
- **先做 SEO 再上线**：首版 = 核心功能 + 围绕关键词的实质内容；登录/付费等日访 ~100 后再补（经验门槛，非教条）。
- **工具页不伤收录（节 37）**：真实可用的交互工具不会仅因“是工具页”而降低收录；搜索引擎看的是它是否完成用户任务、页面是否有必要说明来解释工具解决什么问题。工具页可作为个人开发者用 SEO 获客的产品形态之一，但不是唯一形态，也不是天然护城河。风险在不可用表单/空壳、内容空泛、批量复制的伪工具页——它们只占词、不产生独立结果或任务价值。

### 5. 外链（节 13–16、41、47–49）
- 外链 = 信任票 + 发现通道；现代谷歌不只是 PageRank，但外链仍是重要信号。
- **三条主线（实操模型，不是 Google 公开公式）**：①**站内相关性**回答「你有没有资格回答这个搜索」——可抓取 HTML、清晰 title/H1/正文、匹配搜索意图，才进候选池；②**外链权威**回答「谷歌凭什么优先相信你」——相关且可信的外站编辑性引用既帮助发现页面，也提供信任，争取前列；③**用户体验/意图满足**回答「用户来了有没有把事办成」——速度、清晰承诺、真实可用功能/内容、可信度让排名更可持续。三者不能互相替代：没相关性，强外链也答非所问；没权威，同类内容很难挤进前列；体验差，短期排名也守不住。不要把体验粗暴等同于「停留时长/CTR 越高越好」，Google 未公开单一行为指标公式，目标始终是完成用户任务。
- **外链的正确顺序与落地页匹配**：先让落地页可抓、可索引、能真正解决问题；用首页/栏目内链+sitemap 让爬虫发现；再争取相关网站的真实引用（工具目录、资源页、测评、合作、能给用户价值的博客文章）。外链不应全指首页：首页/栏目链接帮助品牌与整站发现，具体工具/任务页若要承接某个关键词，应争取来自相同任务语境的**深层外链**（如婚礼肖像教程链接婚礼肖像抠图工具页），让链接主题、锚文本与落地页任务一致。免费工具容易被分享的也是这类具体 URL。不用等「完全收录」才开始，但不要把外链指向空壳页。政府/大学/百科页面可能权威高，仍要看链接页本身是否相关、能否抓取、是否编辑性推荐；域名后缀不是魔法，Wikipedia 等 nofollow 链接也不能当权重采购目标。
- **抄作业**：用工具看竞品 backlinks → 逐条分类（用户自发 / 可联系争取的榜单收录 / 内容推荐 / PR / 目录提交）→ 只复用自己能控制的渠道；来源要**多样**，全同质会被怀疑操纵。
- **自然外链 vs 主动争取**：自然外链是别人认可后主动引用，最理想但新站慢；主动外链不是批量塞 URL，而是有计划地创造「值得被相关网站编辑引用」的机会——产品/AI 工具目录、行业资源页、测评文章、合作伙伴、能帮用户解决问题的博客内容。最终验收：链接在公开、可抓取的页面中真实指向有价值的落地页，而不是平台里留了一串不可访问文本。
- **社媒 / Build in public 的位置**：持续公开构建、在规则允许的相关 Reddit/社区发帖、产品目录提交，能带来第一批真人使用、反馈、品牌搜索和后续被作者/目录自然引用的机会；但社媒链接常是 nofollow、JS 生成或短命动态，不能直接当「SEO 权重外链」计数。当前路径把它当**多平台分发 + 外链机会**，不是群发 URL 或对同行自嗨；只在相关问题下提供真实价值并遵守社区规则，记录平台、页面、互动和带来的行动。
- **鉴别与挑选**：先看目标关键词 SERP 中反复出现哪些网站，优先争取这些主题相关、常被抓取的资源页/榜单/测评；再查看「页面源代码」（服务器初始 HTML）是否存在目标 `<a href>`，并看 `rel`、页面内容和编辑语境。初始 HTML 的普通链接最稳；交互后 JS 才生成的链接不必然无效，但发现与理解更不确定，新站不能把它当主要 SEO 策略。社交动态里的网址主要带来点击、反馈和品牌传播，不等于稳定 SEO 权重外链。

### 6. 策略与案例（节 21–22、31、43–44、50–52）
- **KD 工具与引用域（节 40）**：Ahrefs/Apify 等工具的 KD、月搜、CPC、SERP 和“进前十约需多少 referring domains”都可用于候选排序；愿意小额付费的原则是**付费买能减少某个具体候选判断不确定性的证据**，不囤工具、不购买虚假确定性。referring domains（引用域）= 链到你的独立网站数，不是链接页面数；“约需 108 个引用域”只是第三方估算的竞争量级，不是外链采购配额，相关性、编辑真实性、来源质量和落地页价值更重要。
- **品牌词 vs 非品牌词（节 30）**：品牌词是用户直接搜独有产品名（如 `Figma`），因别人通常不做同名页面而较易排名；它承接已知道你的人，是品牌防守与回访入口。品牌宣传、产品体验与分发会培养记忆、带来更多品牌搜索和自然提及，但不是 logo 一上就自动有流量。非品牌词是类别/问题/功能词（如 `online design tool`），竞争更强，却承接还不知道你的新增需求，是 SEO 扩大新用户的关键。两者形成循环：非品牌搜索→首次使用/记住品牌→以后品牌搜索或直接回访；品牌词容易排是起点，不是停止做非品牌 SEO 的理由。
- **趋势词窗口期**：哥飞自述 7 月底进 AI 视频词、10 月日点 8k–10k，但因没持续加防（内容/外链/品牌），被万兴等大厂反超。教训：早期排名 ≠ 护城河；趋势词要持续投入，否则把短期流量让给重投入者。← 佐证本库「热词抢占不做 + 长期稳定增长」。
- **AI 时代选型：可执行价值优先**：泛信息内容若能被 AI 一句话交付，容易同时受 AI 摘要截流与大编辑团队压制；优先评估用户拿到文字答案后是否仍必须进站完成任务——上传/生成/编辑/计算/导出（工具）、互动/保存进度（游戏）、比较/下单/支付（交易）、处理真实项目的持续工作（Workflow SaaS）。工具/游戏/电商只是形态，不是天然护城河：若功能只是 AI 对话里一句话就能完成，也可能被替代。当前策略是功能真解决任务，同时用文字说明主题、用途、用法与限制；**功能负责完成任务，SEO 负责被传统搜索发现，GEO 负责被 AI 理解、引用或推荐**。
- **真实使用与分发先于 SEO 幻想（从电商迁移）**：电商的「真实交易 + 品牌营销」不能直接照搬为工具站投广告，但原则通用：SEO 不是替代产品价值/市场活动的万能开关。工具站先让目标用户真实输入、完成任务、回访或分享，再通过社区、目录、内容等带来分发与品牌认知；SEO 承接后续非品牌搜索。广告、交易或品牌搜索不是可购买的排名魔法（Google 未公开单一直接公式），其主要价值是验证产品、获得用户反馈与传播。
- **需求先于短期排名（立项原则）**：是否值得做一个站，应在上线前先研究目标国家/语言下的词群需求规模、真实用户任务、SERP 竞争、意图/变现线索和自己的维护能力；兴趣/体感是能长期理解场景、持续做深的优势，不替代需求证据。上线后短期没排名不自动说明方向错——SEO 还在经历抓取、索引、比较和信任积累；确认需求后才持续补页面、工具与外链，不因波动频繁换方向。
- **多站组合（路径融合）**：哥飞的分散试验思路成立：不把方向、算法与竞争风险押在单一站。当前路径采纳为「方向并行、首批直接上线 3–4 个达标小站、常态维护 5–6 个、10 个硬上限」（ADR-0013），每站都须是独立的人群×场景×关键词簇×产品承接假设，不是同模板薄站。按收录→展示/出词→排名→有效点击/使用→留存/收入的证据链淘汰或加码；短期没排名不自动停，连续两轮针对性调整后仍无早期信号才归档。
- **案例**：invideo 靠 555 引用域+DR86+专门落地页守第一，单页覆盖 ~5900 相关词；某案例站 3–6 个月 12K→498K 月访问，外链仅 ~73 条，靠大量 AI 词根页面+产品体验+传播。
- **免费工具漏斗（节 40）**：SEO SaaS 将部分工具能力免费开放（例如少量 KD/结果），让用户先得到即时价值；只有用户需要更多结果、批量、历史、保存、导出或高级能力时，才以登录/付费解锁。可借鉴其「免费即时任务 → 真实后续需求 → 付费升级」的产品逻辑，不倒过来先造账户、套餐与付费墙。
- **变现测算**（粗略）：欧美流量 ~$5/千PV 广告；1 万 UV/日×3PV ≈ $150/日广告；同样流量工具站转订阅好时可达 $1000/日+。工具转付费 >> 纯卖广告。

### 7. 上线与长期主题防线（节 16–18）
- **一站做深，不先做站群**：这里的正确词是「**站内关联**」——默认用一个垂直站，把同一人群/任务的核心页、长尾页、工具、模板和说明内容用内链织成主题集群。它让整站比综合大站的一篇泛内页更完整；不是先建多个站互相交叉链接，也不是用链接网络对抗大站。
- **小站对抗大站**：竞争单位仍是具体关键词下有限的页面。小站的可赢方式不是在所有维度比公司大，而是在一个窄任务上让内容、标题、功能、内链和外链都更贴搜索意图，并持续更新；任何一项明显落后都可能失位。
- **上线前 SEO 最小包**：首版 = 能完成用户主要任务的核心功能 + 围绕目标词的实质内容 + 可抓取初始 HTML + 正确 title/description/H1 + 页面角色（可索引/不索引）+ 内链、robots 与 sitemap。登录、注册、付费、运营后台等只在真实流量/行为证明需要时再补；不是不上线前什么都不做，而是不为「功能完整」延误验证搜索需求。
- **广告放在验证后**：广告审核更愿意看有实质内容、清楚结构、可持续经营迹象的可信站点；About、隐私/联系、博客等页面的价值是补完整用户与平台需要的信息，不是机械凑页数。先建用户价值和自然流量，再把展示广告与订阅/按量付费比较；单页快速起量并获批是少数案例，不当首版预期。
- **任务完成优先的体验与新页测试（节 33–34）**：pogo-sticking（点进后立刻回 SERP 再点别家）可作为「标题承诺不符/加载慢/功能难用/回答不完整」的诊断；last click 的理想不是把用户拖久，而是用户已完成任务、不必继续找——10 秒导出结果后离开也可以很好。Google 确认综合许多页面级/站点级信号，但未公开停留时长、CTR、最后一次点击的固定排名公式，不刷指标。新页有时会获得发现/比较机会，不是保证的新站红利；用准确标题、快速首屏、清楚核心入口和真能完成任务的功能接住它。
- **有限展示 → 体验验证 → 扩大可见度（节 34，观察模型）**：新页可能先在有限查询/用户/地区中获得展示，再凭持续满足需求获得更稳定或更广的可见度；这不是 Google 公布的固定机制或保证。不同城市/地区结果也可能由本地意图、语言、市场竞争、个性化和正常波动造成，不能看到某地流量就断言“正在测试”。实践上按国家/语言/查询记录展示、点击、排名与真实任务完成；把早期展示当机会，用体验验证，而非刷行为指标。
- **长期维护节奏（含节 39 的通用排查）**：发布新页面时同步检查它是否属于索引 URL 集、能否从站内浅层抵达、是否已进 sitemap；每月看 GSC/Bing 的索引覆盖、查询/展示/点击/排名和 sitemap 错误，再看竞品的新页与外链。某页/站流量突然归零时，先分辨**需求消失**（Trends/整体 SERP 需求下降）还是**站点能力失效**；稳定需求下归零，依次排抓取、索引、页面可访问性、内容/意图、排名竞争力。主题扩展要围绕相邻任务与相邻用户问题：用攻略/案例/相关工具/对象页扩大可承接需求与 topical relevance，不是无关堆内容。细节排查是小团队能获得正反馈的差异，不用凭感觉盲目加页。
- **未来产品 skill 的内容检查要求**：按页面的核心意图输出/审计 title、单一 H1、H2/H3 子问题、正文六要素、初始 HTML、父子内链与索引角色；统计词密度、字数和重复界面词只作**告警与人工复核线索**，不得自动补词、为凑 3–5% 改写正文或阻断上线。工程性 skill 等具体产品、框架和页面数据源确定后，按 ADR-0003 放产品仓库实现。

## 防止误用

- **时间预期**：2–3 个月起效是常态不是失败信号；上线无排名先查索引/抓取/质量，不默认被惩罚。
- **数字归位**：8k–10k 日点击、498K 月访问、$1000/日都是案例结果不是承诺，复制前按自己的词与 KD 重算。
- **KD 只当线索**：SERP 结构（谁在前排、页型）才是裁决。
- **外链不比数量**：质量、相关性、来源多样、源码可抓取四条件缺一不可；别把社交动态当 SEO 外链。
- **多语言不直译**：直译 = 语法对但用户不这么搜；重复内容还有索引风险。
- **趋势词警惕**：窗口期拿量易、守量难，与「热词抢占不做」路径冲突时要按 ADR-0005 取舍。
