# Edoardo Stradella：创始人营销资源地图

> 来源层级：**辅源**，不覆盖赫兹主源（ADR-0001）。
> 仓库：Edoardo Stradella，*Marketing for Founders*（https://github.com/EdoStra/Marketing-for-Founders）
> 用法：这是「从首批 10 / 100 / 1000 用户」的外部资源导航；用它按当前闭环阶段挑选一条学习支线。具体选方向、SEO、投流与变现动作仍回到对应赫兹原文核验。
> 配套：`README.md`、`1-选方向/_本步导航.md`、`3-SEO获客/_本步导航.md`、`5-变现支付/_本步导航.md`。

## 一句话概念

这个仓库不是一套按顺序授课的方法论，而是面向 SaaS / App 创始人的营销资源索引：覆盖首批用户、无预算推广和 GTM。对本知识库最有用的用法不是照目录逐项执行，而是把它映射进「选方向 → 承接与定价 → 首批触达 → SEO / GEO → 留存与放大」的闭环；每次只补当前最早卡住的一环。

原仓库的定位原话：

> “a collection of practical marketing resources to get the first 10 / 100 / 1000 users for your SaaS / App / Startup.”

## 可复用细节

### 1. 先按阶段挑渠道，不按“热门营销方式”挑

- **首批用户阶段**：优先 User Research、Social Listening、许可式 cold outreach。目标是学到真实场景并取得走查、样例、询价或付款，而不是曝光量。
- **已有明确承接后**：再读 Landing Page、Messaging、Pricing 和 CRO；页面要回答“给谁、做什么、为什么比当前替代好”。
- **已有稳定任务与页面形态后**：再读 SEO / Free Tool / Content；SEO 是慢复利，不是第一周拿客户的替代品。
- **已有转化数据后**：才评估 Ads、Influencer、Affiliate、Product Hunt 等放大动作。

### 2. 把仓库的“渠道清单”当作假设库

仓库列出了 launch platforms、目录站、Reddit、社媒、冷外联、SEO、AEO/GEO、邮件、内容、广告、KOL、联盟、免费工具、定位、定价与研究等主题。它们回答的是“可能通过哪里触达或转化”，**不**自动回答“你的用户是谁”或“他们会付钱吗”。

每次从中选一个主题前，先写：

```text
我要验证：{哪类人} 在 {什么触发时刻} 是否会为 {可观察结果} 采取 {一个真实行动}。
渠道只用来把这条假设送到合资格用户面前。
```

### 3. 重新理解“免费工具”和 AI

仓库把 Free-Tool Marketing 视为获取流量、外链和曝光的办法。它适合承接一次性查询；用户完成即时任务后是否继续交出后续工作，才决定能否升级为混合式楔子或 Workflow SaaS。

因此：

- GPT 能给答案，不必然让工具无价值；工具仍可能胜在搜索触达、结构化输入/结果、行业规则、可分享页面或不同价格。
- 但若用户只要一次结果、没有历史状态/执行/协作/风险，产品更接近 SEO 资产或数字工具，而不是订阅 SaaS。
- 不要用 OCR、AI 或“更聪明”倒推需求成立；先确认用户真正需要做出的后续决策或完成的工作。

### 4. Reddit 与 cold outreach 的正确位置

仓库强调 Reddit 可获取早期用户，也提醒 Reddit 对营销极敏感；cold outreach 则可直接获得早期反馈。两者在本库的执行边界是：

1. 先用社区帖子、竞品评论、搜索和访谈理解用户语言、替代和失败点；
2. 查看社区规则，只对正在讨论相关问题的人做有上下文的回应；
3. 先征得继续交流的许可，再研究其最近一次真实行为；
4. 确认问题后才展示概念页或人工承接，并给出真实价格；
5. 将版规禁止、无回复、拒绝样例、询价/付款分别归因，不能混为“没需求”。

### 5. SEO、AEO 与 GEO 是同一条可见性链的不同观察面

仓库单列 LLM SEO / AEO / GEO，说明 AI 搜索已经成为获客入口。对新手的执行顺序仍是：先满足真实搜索/任务意图，形成有价值且可被抓取的页面，再观察传统搜索与 AI 引用；不要为了“被 ChatGPT 推荐”先制造泛内容或薄页面。

## 防止误用

- **资源索引不是统一方法论**：仓库大多链接到第三方文章；以后精读某一篇时，应单独归档该一手材料，不能把链接标题当成已经验证的规则。
- **不要按 README 顺序全做一遍**：它的 19 个主题服务不同阶段；当前最早未通过的闭环环节决定下一篇读什么。
- **首发平台不是需求验证**：Product Hunt、目录站或 launch platform 可带来反馈/外链，但不能替代合资格用户的使用、询价或付款。
- **SEO / GEO 不等于即时获客**：SEO 需要时间与内容/页面积累；AI 搜索可见性也不能脱离传统索引、清楚事实和用户任务。
- **广告、KOL、联盟不是新手第一动作**：没有承诺、价格和转化证据时放大，只会更快放大不确定性。
- **不跨越社区边界**：不得批量私信、伪装身份或无关推广；渠道规则失败不等于需求失败。
