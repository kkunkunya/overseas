# 新手找词：从一个词到一个可验证方向

## 1. “词”是什么

把“词”理解成用户为完成任务而输入搜索框的真实表达，不是产品名称，也不是孤立行业名。方向来自一组表达相同任务的词，即**词群**。

```text
领域/对象词 + 任务/功能词 + 场景/格式修饰词 + 商业意图词
```

示例：

- `Etsy`：只有领域，不能直接变成方向；
- `Etsy packing slip`：主题词；
- `print Etsy packing slip 4x6`：明确任务和格式；
- `bulk print Etsy packing slips from phone`：明确场景；
- `ShipStation alternative for Etsy packing slips`：出现替代与付费意图。

## 2. 新手要找的不是“神词”

先找 15–30 条带真实来源的种子，合并成不超过 5 个词群。每个词群回答：

1. 谁在搜索？
2. 他此刻要完成什么？
3. Google 前 10 用什么页面承接？
4. 我能做工具、目录、模板、内容还是交易页？
5. 钱从广告、联盟、订阅、单次付费、线索还是上架费来？

任何一问答不清，先继续查，不把词直接等同于产品。

## 3. 四个入口

1. **从词出发**：功能词根与领域词组合，查看 autocomplete、related searches、Trends related/rising queries。
2. **从问题出发**：社区抱怨、差评、workaround、付费服务中提取用户自己的措辞，再回搜索验证。
3. **从站出发**：找到承接需求的站，反查其 Top 关键词、新增落地页、流量入口和定价。
4. **从变化出发**：跟踪新模型、新平台功能、计费或政策变化，记录首发时间，再检查是否形成查询簇。

AI 只帮助生成同义词和修饰词；每个词仍需回到真实搜索、趋势、SERP 或用户行为证据。

## 4. 一轮最小产出

```text
词群 → 用户任务 → SERP 页面类型 → 具体差异 → 触达入口 → 变现假设
```

例：

```text
etsy packing slip + 4x6/mobile/bulk
→ 卖家要批量核对并打印订单
→ 官方帮助页、物流 SaaS、教程
→ 只做更轻的 4×6 批量流程
→ Etsy 卖家社区/搜索流量（需先检查规则）
→ 低价订阅或单次转换
```

这只是候选假设。按需求 → 意图 → 竞争 → 承接 → 触达 → 流量 → 变现逐项验证后，才能标为 `go`。

## 5. Landing Page 的位置

Landing Page 不是产品，也不是保证赚钱的广告页。它是在方向初步通过后，用最小成本测试“陌生人是否理解方案、接受价格并采取行动”的销售实验。

页面最少包含：具体人群、具体任务、方案/样图、真实价格、一个行动按钮。流量可以来自 SEO、社区、合作或小额广告。广告是在购买验证样本，初期可能亏损；只有出现真实询价、订金或付款，才接近商业验证。
