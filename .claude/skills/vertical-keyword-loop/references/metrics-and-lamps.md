# 量 / KD / SERP / 灯色（取证时读）

## 参考带

- 月搜约 **1000+**、KD 约 **0–30**：缩小池子与排序用。  
- **证据硬、阈值软**：必须尽力取证；略偏可 `watch`；过线但 SERP 铁板可 `reject`。  
- 禁止编造；跨厂商 KD 不可横比。

## 月搜从哪来

| 来源 | 性质 | 怎么写 |
|------|------|--------|
| Keyword Overview（登录/API） | 较完整 | `月搜=…；厂商；国家；日期` |
| 排名页 topKeyword 的 volume 等 | **线索** | 标明 topVolume/线索，非 Overview |
| 公开第三方词表 | 辅 | 标明全球/未知厂商，不单独裁决 |
| 没有 | No data | 写 No data + 用 SERP/Trends |

## KD 怎么读

| 区间（经验） | 体感 |
|--------------|------|
| 0–30 | 相对好啃 |
| 30–50 | 要耐心；常 `watch` 而非轻松 go |
| 50+ | 起手谨慎，除非 SERP 有明显破口 |

**永远用真 SERP 复核。** 低 KD + 前排 Canva/Adobe 级 → 信 SERP。

## SERP 优先于裸 KD

看前约 10：

- 页型是否匹配任务（要工具却全是百科/电商？）  
- 小站/薄页/答非所问 → 偏可打  
- 官方+巨头+成熟垂直站占满 → 偏铁板  
- 商店结果：记录分流，不把商店域名流量当产品流量  

## Trends / 国家

- 形状：稳、缓涨、季节、归零尖刺。  
- 指数 0–100 **不是**月搜次数。  
- **按国对比**：谁涨、谁大，可改优先市场；改国后 SERP/量应重取。  

## 付费线索

有标价/订阅/积分/询价 → 商业存在。  
仅「免费玩玩」→ 变现要想清楚，不自动 reject。

## 灯色速查

| 灯色 | 一句话 |
|------|--------|
| go | 场景懂 + 可打 + 有付费线索 + 窄承诺；进入最小实验（本 skill 外） |
| watch | 有希望，缺场景/数略偏/竞品密 |
| narrow | 需求在，词或任务切错 |
| reject | 铁板/无理由/做不了；记闸门 |

## 分食 vs 硬刚

- 分食：更窄人群、更窄任务、补缺陷、不同交付物。  
- 硬刚：与头名同一句主叙事、同功能集正面拼 → 新手默认避免。
