## Shortlist (≤3)

### 1) `therapy notes template` — narrow/watch

- **SERP:** attack a specialized promise only: modality + insurer/compliance context + note format + editable workflow, not generic “free therapy notes template.” KD 1/shortage 2 is favorable; results are mixed content, help docs and discussion.
- **Paid clue:** TherapyNotes, Mentalyc, TheraPlatform, Blueprint and Heidi use free templates to acquire users for documentation/AI-scribe subscriptions. Template pack is a lead magnet; do not sell unreviewed clinical documentation.

### 2) `ai tools for photographers` — narrow/watch

- **SERP:** independent 7.52K and 60.59K domain sites appear beside vendors, so it is not authority-locked. Build collections by job: wedding culling, real-estate staging, school portraits, proofing, catalog retouching; compare price, input/output, privacy and integrations.
- **Paid clue:** result tools sell subscriptions/credits. Directory can use disclosed affiliate/referral and sponsorship; only add a paid workflow layer after selection-intent traffic proves out.

### 3) `ai tools for dentists` — narrow/watch

- **SERP:** small listicles (SoftSmile 22.86K, MedixDental 3.72K AITDK domain clues) rank alongside specialized vendors. A vertical page cluster can compete if it organizes radiograph diagnosis, perio charting, ambient scribe, reception, recall, claims and practice-management integration.
- **Paid clue:** Pearl, Overjet and Denti.ai signal vertical, likely sales-led/subscription software. Early directory revenue: referral/sponsorship. Avoid clinical recommendations and unverified outcome claims.

## Verdict on “N industries × AI tools” directory

**Not as a broad directory.** Generic category pages are squeezed by vendors and authorities; each vertical has different buying criteria and risk. Test one workflow-rich vertical cluster first (dentists or photographers). Templates should remain a separate, compliance-reviewed acquisition layer.

- Generic teacher/law-firm/therapist AI terms: Ahrefs Hard (64/58/59) plus authority/product locks.

- Esthetician intake, SOAP notes and lesson plans: use as long-tail subclusters, not home-page terms.
