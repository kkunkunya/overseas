早上好，朋友们！ 我们日常在提交导航站或者宣传我的网站时，往往需要有一个演示视频，能够增加我们网站的点击，但是制作这样的视频，往往是很麻烦，但是最近HeyGen开源了HyperFrames框架。

https://github.com/heygen-com/hyperframes

只需要一个网址，搭配上claude code 就能帮我们生成一个演示视频了，下方就是我用我的表情包制作网站makememe 生成的，完全是从我网站获取的截图, 所有都是真实数据。

要生成这样的演示视频，首先执行命令进行安装
npx skills add heygen-com/hyperframes

然后就claude code 一个提示词，加上网址，使用hyperframes生成演示视频即可，下面这个提示词就是我生成的提示词，是我先用AI随便生成调整的。
使用 /hyperframes，根据网站 https://www.makememe.net/ 生成一个 20 秒的产品发布视频。

风格：
- 暗色风格（Dark UI）
- 电影感（cinematic）
- AI 产品质感，高级、未来感

内容：
- 展示 Meme 生成过程
- 展示输入图片/文字 → 自动生成 Meme
- 强调生成速度快、简单易用
- 展示不同风格的 Meme 模板或结果

视觉效果：
- 平滑转场（smooth transitions）
- 动态缩放和镜头移动（zoom / pan）
- 高对比度字幕（突出核心卖点）
- 轻微粒子或科技感背景

音频：
- 轻快但有科技感的背景音乐
- 可选 AI 配音（简短介绍产品）

结尾 CTA：
“Create viral memes in seconds”
“Try it now on makememe.net”

大概等了20分钟，视频就生成好了 然后使用下面命令，在浏览器预览这个视频
  npx hyperframes preview

使用渲染命令，把这个视频转化为mp4
npx hyperframes render --output renders/final.mp4
