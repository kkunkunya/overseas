早上好，朋友们，今天分享如何避免无关关键词影响核心关键词。

像下面这个例子，就是有一个apply configuration按钮，结果把这个页面的apply configuration关键词，变成了关键词密度是最大的词，严重影响了SEO。

[图] 

我们可以通过css conetent 去实现文字，来解决这个问题。

下面是我让AI修改的提示词。

页面的apply configuration文字，通过CSS Content去实现，避免影响页面的核心关键词，注意多语言适配。
下面是一个示例：我们可以通过CSS自定义属性（CSS Custom Properties）来实现这一点。我们可以在React组件中设置一个CSS变量，然后在CSS中使用这个变量。.play-button { position: relative; }.play-button::after { content: var(--play-text); margin-left: 0.25rem; font-weight: 700; font-size: 0.75rem; letter-spacing: 0.025em; }
<div className="play-button text-white rounded-full py-1 px-3 flex items-center space-x-1" style={{ '--play-text': `'${t('play')}'` } as React.CSSProperties} ></div>

其中：${t('play')} 还是取了国际化的文本。

修改之后，不影响网站的多语言，也不会有大量重复的无关词影响核心关键词了。
