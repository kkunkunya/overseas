## 两份实战共识（选对方向的实操版）

对比小耳朵sir（月入 4 万刀）和赫兹（月入 1 万刀），都跑通了且强调几乎同样的事：

1. **需求第一，不要先做产品再找用户** —— 顺序反了，先有痛点再做产品
2. **速度为王，SEO 要早布局** —— 流量是核心杠杆，唯快不破
3. **竞品是最好的老师** —— 研究他们怎么获客、流量从哪来
4. **形态选网站 / Web SaaS** —— "24 小时自动收款的全球自动贩卖机"，可复利、可躺赚
5. **流量是核心杠杆** —— SEO + Google Ads + 外链，三条腿走路
6. **AI 放大的是方向正确者的效率** —— 方向不对，AI 只会让你更快做错事
7. **都经历过迷茫期** —— "人不是慢慢变富的，是突然变富的"；"做出海 SaaS 的人没有早睡的，因为太爽了"
8. **产品快了 ≠ 找需求快** —— AI 把写代码门槛降到几小时，但赫兹明说"找需求的门槛、获取流量的门槛还是很高的"（《聊聊网站出海这个生意》）。省下来的产品时间应给"找需求 + 找渠道"，不是给"更快做错产品"。警惕"找需求只要 1 分钟"这类话——那是已跑通者的直觉，不是新手的时间预算；渠道主战场是 Google SEO + Ads + 外链 + 社媒 + GEO（AI 搜索），不是雅虎搜索。

> 想自己的方向时，用这 8 条套一遍。

## 怎么用这个知识库

- **不知道下一步怎么做** → 进对应步骤目录读 `_本步导航.md`，看"这一步解决什么 + 方法论 + 重点篇目"

- **想看跑通的人怎么做的** → 第 1 步（YC 评估）+ 第 6 步（小耳朵sir / 赫兹复盘）
- **遇到具体问题** → `原文/README.md` 搜关键词定位文章，再去对应文件看全文
