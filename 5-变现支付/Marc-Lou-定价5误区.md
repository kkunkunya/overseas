# Marc Lou：定价 5 个误区（为什么你的副业赚 $0）

> 来源层级：**辅源**，不覆盖赫兹主源（ADR-0001）。
> 视频：Marc Lou，*Why your side project makes $0*（https://www.youtube.com/watch?v=y3HV_KdGoZg）
> 用法：补充赫兹第 5 步定价篇的**心理学框架**（锚定 / 订阅抗拒 / 免费墙 / 试用 / 价格信号）。Stripe 手续费、提现、防薅等操作层仍以赫兹原文为准（`010/011/016/019/020/006/014`）。冲突时以赫兹为准。

## 一句话概念

**Pricing is marketing**——定价即营销。用户点开定价页几秒内就判断"这产品值不值、做什么"。Marc 总结 indie hacker 收入为 $0 的 5 个定价误区，核心是：**别让定价本身把买家劝退**。

## 5 个误区速查

| # | 误区 | 后果 | 解法 |
|---|------|------|------|
| 1 | 无脑订阅制 | 用户对"再添一笔月费"有心理抗拒，转化率被压低 | B2C 用终身买断 / 按量积分；订阅留给真有 recurring value 的 B2B |
| 2 | 没有价格锚点 | 单一价格让用户没参照、陷入犹豫 | 摆一个高价对比项；Good/Better/Best 三档，不超过 3 档 |
| 3 | 滥用免费版 | free→paid 行业平均仅 3%，养一堆免费用户烧钱且反馈水 | 砍掉 free plan 加 paywall；付费用户才给真实反馈 |
| 4 | 滥用免费试用 | 不绑卡不承诺，试用结束人就流失 | 落地页直接 demo / 给按次数的免费额度 / 绑卡 + 缩到 7 天 |
| 5 | 定价太低 | 低价向市场发"没价值"信号，用户反而不珍惜 | 买断 ≥ $19，订阅 ≥ $5/月；略高于你直觉的价位 |

## 各误区可复用细节

### 误区 1：订阅制不是唯一答案
- 用户算的是年化：$9/月 = $108/年，还叠加 Netflix/Spotify/WiFi，且要设取消提醒 → **产生异议 → 不买**。
- **经济性对比**：$10/月订阅（10% 月 churn）vs $100 一次性买断。同样获 100 客户：
  - 买断当月 $10,000；订阅要 **~4 年**才追平。
  - → 你要的是"现在 $10k"还是"4 年分摊 $10k"？多数 B2C 产品不需要 recurring。
- 「**recurring value = recurring payment**」——订阅适合真有持续价值的 B2B。
- **怕被滥用亏钱？** 两类成本：
  - **可忽略成本**（带宽/邮件）：他 50 万 PV/月 ≈ Vercel $100；Mailgun 4800 封/月 ≈ $5。除非用户天天重度用，不会亏。
  - **贵成本**（GPU/OpenAI/DB）：用 **credit-based 按量计费**（如 $10 = 100 张 AI 图），既消除订阅心理负担又防滥用。
- → 先上买断/积分，跑通后再加订阅也来得及。

### 误区 2：价格锚定（Price Anchoring）
- 单一价格 = 用户没参照 = 犹豫不买。
- **做法**：摆一个**贵一点的锚点**让主推价显得合理。
  - 案例 Zenvo（省 Stripe 4% 发票费）：主推 $69，锚点 = 更贵档（多 Stripe 账号功能）。
  - 案例 Indie Page（link-in-bio）：主推 $45 终身，锚点 = $ 同价但 1 年到期通行证 → 终身版显得划算。
- 可分 **Good / Better / Best** 三档，但别超过 3 档（多了变负担）。

### 误区 3：砍掉免费版
- **行业基准**：free → paid 转化率 ≈ **3%**。
- 想月入 $3,300（$5/月付费）→ 需 600 付费 → 需 20,000 注册 → 按 15% 注册转化 → 需 **133,000 访客**。对 solo dev 不现实。
- 砍 free plan 后三好处：①**更好用户**（掏钱的有 skin in the game，反馈真实）②**更有动力**（收到钱会专注）③**省钱**（免费用户占大头成本）。
- → 直接 paywall，更快盈利。

### 误区 4：试用要让人承诺
- 问题：不绑卡的试用 = 不承诺 = 试用结束人就忘。
- 三解法：
  1. **改落地页**：copy 触发情绪 + 清晰 demo（视频/截图讲清功能），可能根本不需要试用。
  2. **按次数免费额度**：如免费生成 3 张图 / 发 10 封邮件——绑动作不绑时长，用完即撞 paywall，趁热转化。
  3. **缩短 + 绑卡**：30 天 → 7 天，且要信用卡。**email 不是承诺，信用卡才是。**

### 误区 5：别定价太低
- 低价 = 向市场发"这产品没价值"的信号。
- **价值** = 产品客观有用性（省多少时间）；**感知价值** = 用户觉得值多少，受设计/定价影响。
- 规则：**一次性买断 ≥ $19；订阅 ≥ $5/月**；略高于直觉价。
- 副作用（正向）：价高 → 用户更珍惜 → 更认真用 → 更出成果。类比 Udemy $10 课 vs 创作者 $200 课。
- 没思路就**看竞品价位**，落在相近区间。

## 防止误用

- 「砍掉免费版」针对 **solo dev / 资源有限**；有融资、走"先增长后变现"路线的不适用（Marc 自己点明）。
- 终身买断对**真有持续服务器/AI 成本**的产品要算清——否则用 credit-based 兜底。
- 价格锚点的"锚"必须是**真实可买的档**，不是虚高摆设（否则是 deceptive pricing）。
- 「价高 = 用户更珍惜」有边界：远超竞品/价值会反噬，先看竞品区间。
- 三档上限是**认知负担**经验法则，不是铁律；复杂 B2B 可更多档。
- Marc 的 $10→$100、3% 转化等数字是其案例推演，不是普适数据；套自己产品要重算。
