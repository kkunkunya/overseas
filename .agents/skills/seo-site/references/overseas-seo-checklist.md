# 出海 SEO：五条收藏的执行清单

**何时读**：已有目标页面，想判断该补内链还是外链、选诊断工具、用 AI 改页，或扩大内容量。每轮只选当前缺口对应的一组，交一张改动卡；不把五组都变成必跑流程。

核对日：2026-10-14。S1、S3 读指定收藏的正文快照；S2、S4、S5 读 X 原页正文。以下是从作者经验转成的本地执行规则，不是搜索引擎官方规范；实施时仍按[引擎规范手册](engine-playbook.md)核对。品牌词排名、单页扫描和个别运营者经验都不能证明通用排名效果。

## S1：内页排名与链接

来源：[哥飞：内页要不要加外链](https://x.com/gefei55/status/2109878532461711735)，提炼为六步：

- [ ] 以目标 URL 为单位，写清目标查询与用户任务；先核主题、内容、可索引性，首页也按页面检查。
- [ ] 检查内容的信息增量、时效、事实依据和使用体验，确认页面能兑现搜索者的任务。
- [ ] 在相同国家/语言的 SERP 对比实际排名页，写明本站缺什么、哪项可以补；不以全站指标代替页面比较。
- [ ] 优先从相关首页、频道页或已有任务页补语义内链；记录来源页、锚文本和目标页，检查目标可访问。
- [ ] 内链与内容补好仍有竞争缺口时，再把目标页、可被引用的价值和相关渠道交 `distribution-link-loop`；不直接堆垃圾外链。
- [ ] 记录改动日期、查询与观察窗，按同口径复查收录、曝光、点击；窗口未满先观察，不因短期无排名重选方向。

**不照搬**：作者“任何链接都传权重”与“三四个月有效果”不设为保证；链接的相关性、属性、可抓取性及效果需实际核验。可被索引也不等于必然收录。

## S2：按缺口选工具

来源：[大罗 SEO：2026 SEO 工具锐评](https://x.com/daluoseo/status/2110216497410838878)，提炼为五条：

- [ ] 要看 Google 已发生的查询、曝光、点击和收录，先用有权限的 GSC；转化另接分析/业务数据，缺权限标 `待接入`。
- [ ] 要查反链或竞品关键词时，按当前问题选 Ahrefs / Semrush 等一个已有工具；记录来源、采集日期和估算口径，不把估算当本站实绩。
- [ ] 要查技术问题时，用已有爬虫（作者举 Screaming Frog）找状态、重复或孤儿页；回到具体 URL 验证，再列改动。
- [ ] 供应商报价或内容评分涉及 DA、关键词密度时，要求对应页面证据与任务收益；不为了指标分数填词或买链接。
- [ ] 要看 AI 是否提到本站时，记录引擎、问题、日期、答案与引用 URL，交 `distribution-link-loop`；追踪工具报告仍需抽查实际答案。

**不照搬**：夯拉排名、工具贬褒及“只有某工具知道”是作者观点；不据此采购，不新增订阅，不把 GSC 当转化系统或 AI 可见度的唯一证据源。

## S3：关键词 → 页面 → 真实引用的小实验

来源：[Wyong：Claude + OpenSEO 网页游戏实战](https://x.com/intentplex/status/2109719604373418002)，提炼为四条：

- [ ] 用已有关键词工具提出机会候选，并保存来源；查询实际意图、SERP 页型和产品能否承接，既有核心词不因候选自动重开。
- [ ] 把查询需求映射到当前页面 brief，只改确实缺失的承诺、说明或答案；AI 改写后由事实与页面任务把关。
- [ ] 准备与任务相关的论坛参与或引用请求，交 `distribution-link-loop`；实际发帖、邮件仍核对授权，不把引用数量当质量。
- [ ] 把品牌词与非品牌词分开记基线和后续数据，同时观察用户完成任务；缺数据写 `unknown`，不把一次排名当因果验证。

**不照搬**：作者报告的是品牌词一周到首页第五，未提供对照实验；不推广为任意关键词一周上首页，也不因此照搬网页游戏方向或强制安装 OpenSEO。

## S4：单页取证 → 精确编辑 → 复查

来源：[borja：Claude Code + Distribb 单页审计](https://x.com/borjafat/status/2109969783298867349)，提炼为六条：

- [ ] 选一张页，记录 URL、日期、页面任务与受众；用已有检查工具取 title、description、状态、canonical、robots。索引状态另查 GSC。
- [ ] 采集标题层级及上下文、内链的锚文本与真实目标；AI 只能用提供的目标提链接，不从链接数量猜是否合理。
- [ ] 区分缺失 alt 与空 alt，结合图片和周围正文判断；信息图描述信息，装饰图可以保留空 alt。
- [ ] 将 Schema 对照可见正文并验证；爬虫 Allowed 只证明规则允许访问，不能当收录、引用或推荐证据。
- [ ] 把证据交给 AI，只要最多三项优先改动；每项含观察、读者收益、具体位置/替换稿及复查方法。缺上下文就先补，不编事实。
- [ ] 产品仓按选定 diff 实现后，重新加载/扫描同一页，保留前后报告；逐项核文案、链接、图片和标记，再按时间观察 GSC。

**不照搬**：扩展版本、扫描分数、指定模型及安装步骤不成为依赖；作者展示的建议尚未应用，不算修复成功。FAQPage 等标记是否适用回引擎手册判断。

## S5：AI 内容、品牌与自动化边界

来源：[Nicholas Dulait：Claude SEO 五大错误](https://x.com/NicholasDulait/status/2109909279452868684)，提炼为五条：

- [ ] 对准备发布的页面问：搜索者会用它吗？相较同查询结果有何独有价值？答不出就改善、合并或不发布，AI 只加速已成立的任务。
- [ ] 对城市页、自家榜单或其他短期技巧逐项核真实服务与评选依据；无法兑现的城市页收敛，自家排名按可核标准重写，记录停止/回滚条件。
- [ ] 批量内容沿[现有 pSEO 门](content-scale-localization.md#程序化-seo)先做样本、小批观察；没有独有价值不扩量，不设“一键千篇”目标。
- [ ] 核真实 About、联系方式、适用的法务信息及作者身份；按可见事实补合适的 Organization / Person 数据，不编团队、经历、地址或评价。
- [ ] 将反复确认的页面规则存成 brief/模板；AI 或 CMS 自动改动先给 diff 与复查清单，产品仓实现与发布各按既有授权执行。

**不照搬**：作者明说是两位运营者、少量站点、无对照组；每周三四篇、等待一年、hack 六至十二个月失效、每页固定三条内链都不设为通用门槛。“品牌信号”是信任建设，不当作确定的排名因子。

## 塔罗站复用与交付

只引用本文件，不在 tarot 仓复制技能，也不因本清单自动新增牌义页或改产品：

| 可复用原则 | 塔罗站如何用 | 依据 |
| --- | --- | --- |
| 内链与目标页支持 | 从真实存在的相关入口/主题页链到任务页，检查锚文本与目标；不宣称“权重已提升” | S1、S4 |
| 页面竞争力 | 对具体查询看同类 SERP；补可完成的功能、解释、示例与限制，同任务页优先合并 | S1、S3、S5 |
| 品牌信号 | 统一真实站名、负责人、方法说明与联系渠道；身份与经历未知就待核 | S3、S5 |

塔罗涉及健康、投资等重大决定时，沿既有 E-E-A-T / YMYL 边界，不把解读包装成事实预测。

一轮只交这一张卡，站内改页回 `seo-site`，站外引用交 `distribution-link-loop`，效果观察交 `product-growth-review`：

```text
目标 URL / 查询 / 国家与语言：
采用 S几 / 当前证据与日期：
最多三项改动：观察 → 具体修改 → 复查方式：
待核项 / 所需授权：
观察窗 / 同口径复查日期：
结果与下一步 owner：
```
