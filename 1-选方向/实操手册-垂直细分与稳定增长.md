## 0. 总图（先看懂再动手）

```text
【方案 A · 垂直细分】先定「卖给谁、哪一件事、哪个英文主词」
        ↓ go
【最小承接】一页工具/landing + 真价格或真 CTA
        ↓
【冷启动】（稳定增长的前半段）Reddit 等发帖 + 台账三问
        ↓ 有真行动/首笔 $
【方案 B · 稳定增长加厚】内容 SEO · 外链 · 多平台 · 小步产品
        ↓
【复利】排名 + 订阅/重复购买 + 台账复盘
```

| | 方案 A 垂直细分 | 方案 B 稳定增长 |
|--|----------------|----------------|
| 一句话 | 开只卖一样东西的小店 | 天天扫地、写黑板、串门，让人记住你 |
| 主要产出 | 1 个主词 + go/reject | 持续流量与信任资产 |
| 时间感 | 数天～2 周选出词并上最小页 | 数周～数月堆厚 |
| 核心工具 | 找词三件套 + 真 Google | GSC/内容/外链/社区 + 台账 |
| 和指南 | 打法二 | 打法三 + Viking 冷启动 |

**现在默认顺序**：先完整跑完 A 的选词 → 最小页 → 再把 B 的「冷启动」打开；B 的「SEO 内容/外链加深」等有信号再加码。

## 1. 方案 A：垂直细分（完整实操）

### 1.1 目标与完成标准

**目标**：找到 **一个** 足够窄的英文场景词（或极小词群），你能在合理时间内做出最小页，且 SERP 看起来打得动。

**完成标准（阶段 A 结束）**

- [ ] 写清：`人群 × 场景 × 单一任务` 一句话  
- [ ] 主词英文写死；国家默认 **US**（除非你另定）  
- [ ] 做过真 SERP + 至少 3 条「我比现有结果更好」  
- [ ] 变现猜想写明（订阅 / 一次付 / 广告 / lead…）  
- [ ] 结论：`go` / `watch` / `narrow` / `reject` 一句话理由  
- [ ] `go` 时：下一步只做最小页，不并行第二个主词

### 1.3 怎么找词（方法合集）

垂直词 = **具体场景 + 清晰任务**，不是泛功能名。

#### 方法 1：场景脑暴（你最熟 → 优先）

问自己并写英文短语：

1. 谁会半夜急着搜这个？  
2. 他要交的是什么作业/照片/文件/结果？  
3. 现在不用你的产品会怎么凑合？（Canva / 修图店 / Excel / 问 ChatGPT…）  

模板（往空里填）：

```text
AI {场景} {产物} generator
{场景} {产物} maker
{产物} for {人群}
best {窄工具} for {场景}
{任务} template
```

例（仅示范形态，不是推荐你做这些）：

- `AI wedding photo generator`  
- `AI ID photo generator`  
- `headshot generator for linkedin`  

#### 方法 2：大词拆小（指南逻辑）

1. 想到一个大词：如 `AI image generator`  
2. **禁止**把它当主词  
3. 拆维度：场合（婚礼/证件/电商主图）× 对象（人/产品/宠物）× 规格（护照尺寸/亚马逊主图）  
4. 每个交叉点变成一条候选  

#### 方法 3：AITDK 扩词

1. 打开 AITDK Keywords，丢进种子  
2. 导出/抄下变体  
3. **立刻**用 Google 自动补全和相关搜索交叉，删掉离谱 AI 胡编  

见 [AITDK-SEO工具箱.md](../3-SEO获客/AITDK-SEO工具箱.md)。

#### 方法 4：Google 自己会「送词」

对每个种子：

1. 输入到一半看 **自动补全**  
2. 搜完整词，滚到 **People Also Ask**、**Related searches**  
3. 打开 1～2 个排名站，抄它们的 **H1 / 导航类目 / 底部链接**（竞品分类=免费词表）  

#### 方法 5：Trends 过滤形状

- 默认：地区 **US**，时间 **5 年**  
- 偏好：有稳定基线或缓升；纯一次性梗、归零尖刺 → 谨慎  
- rising 词可进候选池，但要再走 SERP，**不能**因 Breakout 直接建站  

#### 方法 6：SERP 闸门（决定能不能做）

对短名单每个词：

1. 无痕搜主词  
2. 记前 10：域名、页型（工具 / 博客 / 目录 / 官方 / 视频）  
3. `allintitle:"完整词"` 看有多少页标题硬撞  
4. 点进 3～5 个：有没有价格、注册墙、广告、明显薄页、答非所问  
5. 写下 **3 条你能具体更好**（更快出图、更贴证件尺寸、价更清、无水印试用…）  

**偏 go**：有小站/薄页/意图错配，你做得动。  
**偏 reject**：官方+巨头+成熟垂直站占满，你说不出 3 条更好。  

SERP 练习手感也可参考（形态不绑目录站）：[目录站找词方法.md](目录站找词方法.md) 里「SERP 体检」段。

#### 方法 7：Reddit / 社区抽检（补「人话」）

- Google：`"{候选词}" site:reddit.com`  
- 或 Reddit 站内搜任务词  
- 抄用户原话进笔记（以后写 landing 用）  
- 只有夸「好酷」没有「我现在就需要」→ 痛点可能偏兴趣档  

社区找 `why now` 的辅读：[Greg-Isenberg-Reddit趋势找方向.md](Greg-Isenberg-Reddit趋势找方向.md)（仍要回到词与 SERP，不单靠社区热度）。

#### 方法 8：定轨（避免词和产品形态拧巴）

选词前写一行（[产品找词-双轨流程.md](产品找词-双轨流程.md)）：

| 路线 | 适合垂直起手时 | 词的角色 |
|------|----------------|----------|
| **SEO 资产 / 轻工具**（默认） | generator / template / 小计算器 / 小目录 | 获客词为主，可变现一次付或订阅 |
| **Workflow SaaS** | 重复高风险工作流 | 先写工作流证据，再反推词；无搜索量不立刻杀 |
| **混合楔子** | 免费小工具导入，再看后续任务 | 免费页是入口，不自动升级 SaaS |

指南 PDF 路线更贴 **SEO 资产 / 轻工具**。`calculator/generator` **不要**自动当成「必须订阅的 SaaS」。

### 1.4 逐步动作（按天可执行）

#### 第 0 步：定轨 + 约束（15 分钟）

写在词表顶上：

```text
路线：SEO 资产 / 轻工具（或你改的）
国家：US
不做：热词；已 reject 的 TTS/激光清洗/专业服务；并行 >1 主词
截止：本周内必须 go 或 reject 一个主词
```

#### 第 1 步：种子 5～10 条（30～60 分钟）

- 只用你有体感的场景（用过、帮人做过、能看懂英文吐槽）  
- 每条写成英文候选短语 + 中文备注「谁·场合·任务」  
- 产出：种子列表  

#### 第 2 步：扩词（1～2 小时）

每个种子：

1. AITDK Keywords  
2. Google 自动补全 + 相关搜索  
3. 可选：竞品站类目抄词  

合并去重 → 可能 30～80 条草稿。**不要**条条深挖。

#### 第 3 步：粗筛到 ≤10，再压到 ≤3（1 小时）

杀掉：

- 品牌词（`canva xxx` 且只想找官网）  
- 你做不了的强合规/强硬件  
- 明显大战场泛词  
- Trends 五年几乎死掉且无相关簇  

留下 ≤3 进 SERP。

#### 第 4 步：三词 SERP 体检（每词 20～40 分钟）

按 §1.3 方法 6 填词表列：SERP 摘要、allintitle、3 条改进、竞品定价线索。

可选：SimilarWeb 看头部站流量是否纯靠品牌。

#### 第 5 步：软数字（有则填，无则写「缺失」）

- 指南软门槛：**月搜观感 1000+、KD 0–30**  
- 没 🔑：**禁止编造数字**；用 Trends 形状 + SERP 结构定性  
- 有 🔑：填厂商名 + 数字 + 日期  

#### 第 6 步：只深挖 1 个（半日）

四问简报（不必打复杂公式分）：

1. **有需求吗？** Trends + SERP 意图 + Reddit 人话  
2. **打得过吗？** 前 10 结构 + 3 条更好  
3. **怎么赚钱？** 竞品是否收费；你准备订/次/lead 哪种  
4. **这周值得你投入吗？** 最小页你能否做出来  

结论：`go | watch | narrow | reject`。

#### 第 7 步：go 之后的最小动作（进入简单闭环，仍算垂直落地）

1. **另开产品目录**（不在本知识库写业务代码，ADR-0003）  
2. 最小页：主词意图对齐 + 示例输入输出 + **真价格或真 CTA**  
3. 部署：Vercel 等白嫖档即可（细节查 `2-建站开发/`）  
4. 能埋点则埋：到达 → 试用 → 点购买；不能则至少手记  
5. **立刻进入方案 B 的冷启动段**（§2.3），不要静等 SEO  

作战卡同步清单：[第一步-垂直选词与简单闭环.md](第一步-垂直选词与简单闭环.md)

### 1.6 通过 / 淘汰速查

| 维度 | 偏通过 | 偏淘汰 | 软/硬 |
|------|--------|--------|------|
| 场景 | 人群×场合×一事清楚 | 泛功能大战场 | 硬 |
| SERP | 有切口、你有 3 条更好 | 巨头/官方/成熟站封死 | **硬** |
| 需求 | Trends 非长期死；意图一致 | 纯梗/纯噪声 | 软 |
| 量/KD | 约 1000+ & 0–30（有数据时） | KD 50+ 硬刚 | **软** |
| 付费线索 | 竞品有价/广告主/lead | 只有「应该有人用」 | 硬线索 |
| 你能做 | 合理时间最小页 | 强合规/数据你搞不定 | 硬 |

## 2. 方案 B：稳定增长（完整实操）

### 2.1 目标与两阶段

**目标**：在已选定的垂直切口上，用**可重复的节奏**堆流量、信任与收入，而不是赌单次爆款。

稳定增长拆成两段（避免一上来做 6 个月 SEO 却没人看过产品）：

| 阶段 | 名字 | 何时开始 | 核心 |
|------|------|----------|------|
| **B0** | 冷启动稳定节奏 | 最小页可访问后 **立刻** | 多平台发帖 + 回帖 + 台账 |
| **B1** | 资产稳定加厚 | 有真行动/首笔 $ 或明确「内容值得堆」信号后 | 内容 cluster、GSC、外链、产品小步 |

指南「稳定词优化」（周更内容、外链、体验）主要落在 **B1**；Viking 式冷启动落在 **B0**。路径里的「长期稳定增长」= B0 + B1。

### 2.2 工具箱

#### B0 冷启动

| 工具 | 干什么 |
|------|--------|
| **Reddit** | 目标人群版 + 产品反馈向版块（先读版规） |
| **Indie Hackers** | 高质量独立开发者流量 |
| **Hacker News · Show HN** | https://news.ycombinator.com/show |
| **Launch 列表** | https://launchpointzero.com/launchsites/recommended 等小目录 |
| **AI 写文案** | Cursor/Claude 等按**每个社区风格**各写一版，禁通稿刷屏 |
| **台账表** | 飞书多维表 / Sheets；字段见下 |
| **浏览器书签夹** | 「监测中的帖」一夹，每天打开回 |

Viking 战役细节与版块清单：[../4-流量放大/Viking-冷启动第一笔100美元.md](../4-流量放大/Viking-冷启动第一笔100美元.md)  
渠道菜单辅读：[../4-流量放大/Marc-Lou-10个获客渠道.md](../4-流量放大/Marc-Lou-10个获客渠道.md)

#### 稳定期 **后置**（有现金流再说）

- Google Ads / Meta 投流（先有转化再投）  
- 联盟、复杂自动化爬帖

### 2.3 B0 冷启动：逐步动作

#### 准备（上线当天可做）

1. 站点可打开；主 CTA 可点  
2. 准备 **3 套文案骨架**：求反馈 / 故事型 / 纯 Show（按版规选用）  
3. 建台账三表（可先一个 Sheet 三个 sheet）  
4. 书签：版规页 + 自己的帖  

#### 每日节奏（抄 Viking，按你时区改）

```text
1. 打开台账：待回条数 > 0？→ 先全部回完
2. 选 1 个版块/站点（一天大约 1～2 个，不 spam）
3. 该版 Top（月/年）看什么帖受欢迎
4. 读版规：禁广则只聊帮助/改求反馈，不硬广
5. 发适合该版语气的帖（AI 草稿 + 你改）
6. 链入台账：链接、文案版本、目的
7. 当天多刷自己帖下评论，认真回
8. 更新：赞/评/浏览粗数；新互动进「建联表」
```

#### Reddit 六步（可当 checklist）

1. Choose subreddit  
2. Sort Top → month / year / all  
3. Note what works  
4. Make your post（规则不行就不要硬广）  
5. Engage everyone under your post  
6. 换下一个 sub；**一天一帖量级**，坚持  

通用反馈向版块列表示例见 Viking 笔记；**你的垂直人群版块更重要**（与主词人群一致的 r/xxx），通用 indie 版是补充不是唯一。

#### 台账三问（必须能回答）

1. 今天/本周发了几帖、在哪？  
2. 这些帖下有什么新内容？  
3. 谁回了、我回了没、建联到哪一步？  

**表 A 发帖**：日期、平台、版块、帖链接、文案版本、目的、浏览/赞/评、状态、备注  
**表 B 建联**：来源帖、对方、原话摘要、已否回复、建联状态、下一步、提醒  
**表 C 每日**：日期、发帖数、新回复、**待回条数**、新建联  

飞书推送/自动化：**后置**。原则：**待回 > 0 先回再发**。  
私信：仅版规允许或对方愿意；不群发、不伪装。

#### B0 成功 / 停损（量级参考，不是铁律）

| 信号 | 含义 |
|------|------|
| 有人认真提问、要试用、留联系、点购买/付费 | 继续；可考虑进入 B1 |
| 有曝光、零有效行动 | 改文案/版块/承诺，或回到 A 换词 |
| 约 2 周量级仍零有效行动 | 停损复盘，不先加十个功能 |

### 2.4 B1 资产加厚：逐步动作

**前提**：B0 已证明有人在乎，或你明确接受「先堆 SEO 更慢」的时间成本。

#### 步骤 1：Money page 优先

- 产品页/定价页/主工具页必须是主词意图的落点  
- 没有转化页就先写十篇博客 = 空转  

（Surfer 课与库内 topical authority / money page 术语）

#### 步骤 2：围着主词建一个小 cluster

1. 主词 1 个 money page  
2. 5～15 个支撑页：how-to、对比、场景变体、FAQ（来自 PAA/Reddit 原话）  
3. 内链：支撑页 → money page  

节奏：指南 **周更约 1～2 篇**；你可改为「双周 1 篇」但不要零。

#### 步骤 3：技术 SEO 最小集

1. 可被抓取（别整站挡机器人）  
2. Sitemap 提交 GSC（+ 可选 Bing）  
3. 标题/H1 含场景词，别堆砌  
4. 移动端可用、加载别太烂  
5. 固定看 GSC：有展示无点击 → 改标题描述；有点击无转化 → 改页和 CTA  

#### 步骤 4：外链与多平台（稳定曝光）

- 继续目录站/小 Launch **顺手攒 backlink**（Viking：不必为小站付费冲排名）  
- 有质量的来源：真有流量的介绍、工具榜、客座、开源/文档外链  
- 质量 > 数量；「有真实点击过来」比「几百条垃圾链」重要  

#### 步骤 5：产品小步

- 只做用户原话里反复要的  
- 先运行后自动化（CONTEXT）  
- 定价避坑：[../5-变现支付/Marc-Lou-定价5误区.md](../5-变现支付/Marc-Lou-定价5误区.md)  

#### 步骤 6：复盘节奏

- 每周：台账透视——哪版块有效、哪文案有效、注册/付费  
- 每月：是否仍垂直（有没有漂成泛大词）  
- 数字参考指南收入曲线 **仅作量级**，不是你的 KPI 合同

## 5. 明确不做什么（两条共用）

- 热词抢占  
- 以任何单一作者为教主或「必须先过某某公式」  
- 复活 TTS / 激光清洗 / 专业服务（除非你明确重开）  
- 未选词先造数据中台 / 全自动爬 Reddit  
- 并行深挖多个主词  
- 把 generator 词自动升级成重型 Workflow SaaS  
- 零行动时用「再加功能」代替换词或改承诺
