# AI 时代公司 35 步：阶段化学习

> 来源层级：**辅源**，不覆盖赫兹主源。  
> 视频：Greg Isenberg 与 Jordan Mix，*The Complete Playbook for Building Million Dollar Companies in the AI Age*。  
> 本地底稿：`/Users/kun/Downloads/New_notebook.md`（用户于 2026-07-24 提供）。  
> 用法：把“35 步”作为从发现需求到业务组合的长期世界观；方向裁决、词评估和卖空气验证仍以赫兹 015 / 018 / 028 / 029 为准。

## 一句话结论

这不是一张让新手从第 1 条机械做到第 35 条的待办清单，而是一套跨越多个阶段的经营 playbook：

```text
发现细分人群与痛点
→ 做出一个可验证的核心承诺
→ 触达合资格用户并获得真实行动
→ 从手工服务中产品化
→ 形成内容、用户、产品的循环
→ 才可能扩张为产品组合
```

当前第一个方向只取前半段：**验证问题和付费意图**；不要提前建设自动化、受众大号、Creator 股权合作、完整 SaaS 或 holding company。

## 12 条可复用体会

| 体会 | 它真正说的是什么 | 当前阶段的最小动作 |
|---|---|---|
| 1. 固定专注时段 | 进度来自持续完成一个小实验，不来自同时维护许多想法。 | 每次只推进一个候选的一条未知：人、痛点、价格或触达。 |
| 2. 找细分切口，不只找热门词 | 值得做的是“一个人群在一个场景的一个任务”，不是宽泛赛道。 | 把关键词、人群、场景和任务写成一句话，再进 018。 |
| 3. 读痛点，也读用户语言与内容 | 用户原话同时决定产品承诺、页面文案和触达方式。 | 保存痛点、替代方案、原话、所在社区及允许的沟通方式。 |
| 4. 解决方案要从观察长出来 | V1 不是功能清单，而是对一个强痛点给出可理解的结果。 | 先写“用户输入什么，立刻看见什么结果，为什么这个结果重要”。 |
| 5. 分发先找入口，不先追大粉丝数 | 早期分发的目标是让少量合资格用户看见实验，不是先经营大号。 | 锁定一个规则明确的社区、创作者、邮件名单或线下入口。 |
| 6. 用真实承诺验证，而非融资或称赞 | 预售、订金、预约或真实购买按钮，比“这个想法不错”更接近付费意愿。 | 在概念页上展示具体价格与真实行动按钮，并明确交付边界。 |
| 7. 私聊是高密度研究，不是群发获客 | 一对一私聊可以用来理解真实案例、测试承诺和邀请试用；前提是对方合资格、沟通场景允许且不打扰。 | 先在允许的公开入口说明研究目的，或只联系已明确愿意交流的人；记录每次邀约和回应。 |
| 8. 先运行，再自动化 | 尚未重复发生的流程没有资格被自动化。 | 先手工完成几次报价、访谈、结果解释或跟进；只自动化稳定、重复且耗时的步骤。 |
| 9. Creator 合作是分发合作 | 分成或股权不是“找网红”，而是与能带来目标人群的人交换收益。 | 只有产品已有明确承诺、归因和单位经济时，再测试小规模 affiliate / rev-share。 |
| 10. 免费工具是漏斗入口 | 免费工具的价值是先解决即时小问题，再自然暴露更深的工作流需求。 | 先验证一个免费结果是否被使用；保存、导出、预设等功能只在真实需求重复出现后收费。 |
| 11. 定价是连续学习 | 早期不需要复杂价格表；先确认是否付费，再理解为什么付、为谁付、愿意付多少。 | 保持“免费即时价值 + 一个明确 Pro 报价”的最小价格实验。 |
| 12. 手工服务是产品需求的采样器 | 重复出现的手工解释、计算或交付，才是后续功能候选。 | 每次人工协助后记录：用户目标、输入、卡点、手工步骤、愿意付费的结果。 |

## 私聊触达：可执行而不骚扰的方式

私聊是当前验证的一种手段，不是唯一渠道，也不是可以不分对象群发的渠道。

### 先判断对方是否合资格

一位可触达对象至少应同时满足：

1. **角色匹配**：确实是目标人群，而不是泛兴趣围观者；
2. **场景匹配**：近期遇到过页面要解决的任务或痛点；
3. **判断资格**：能讲出自己现在怎么做、卡在哪里，最好能决定是否试用或付费；
4. **沟通正当性**：社区规则允许，或对方曾公开表示愿意交流、留下联系入口、回应过研究招募。

### 推荐顺序

```text
公开评论 / 管理员许可 / 对方主动回复
→ 简短说明研究目的与非推销性质
→ 询问是否愿意私聊或看概念页
→ 私聊一个具体问题或页面
→ 观察真实输入、追问、点击、预约或付款
```

避免直接对大量陌生 Reddit 用户复制粘贴私信；不要伪装成同类卖家；不要把点赞、礼貌回复或“看起来不错”记作需求验证。

### 首条私聊的最小结构

```text
Hi {name}, I saw your post about {specific context}.
I'm researching how {target people} price {specific work}; I am not selling a finished tool yet.
Would you be open to a 10-minute chat, or to trying one simple pricing page with a real project?
If not, no worries at all.
```

重点不是话术“转化率”，而是让对方能清楚判断：你为什么联系她、你想研究什么、她需要付出多少、拒绝是否无压力。

## 与赫兹主线的接法

```text
细分人群 / 趋势 / 社区线索
→ 用户原话、痛点与替代方案
→ 候选词与细分切口
→ 赫兹 018：需求、竞争、赚钱、ROI
→ 赫兹 015：概念页、真实价格、真实行动
→ 手工服务与真实工作流
→ 产品化与必要的自动化
```

这份视频的价值在于提醒：用户、内容、工具和信任可以长期复利；赫兹主线的价值在于防止在这个长期愿景下跳过“是否有需求、是否打得过、是否有人付钱”的硬验证。

## 防止阶段错配

- 还没有合资格用户行动前，不以“做内容、涨粉、建社区”替代验证。
- 还没有重复工作流前，不搭 Agent、自动化或复杂运营后台。
- 还没有明确产品承诺、归因和单位经济前，不谈 Creator 股权、长期分成或大规模投放。
- 还没有单点价值成立前，不把产品设计成生态、平台或多产品组合。
