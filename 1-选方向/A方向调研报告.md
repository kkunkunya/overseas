# A 方向调研报告：AI Agent / MCP 目录站

> 日期：2026-07-21  
> 方法：免费档（🤖 + 🌐）——候选词 → SERP 竞品 → 竞争度粗估 → Reddit/HN 信号 → 趋势 → 变现证据  
> 精确搜索量 / KD / 外链：**未做**（要 🔑 Ahrefs/Semrush）  
> 本报告只给证据，**不替你拍板**。拍板见文末 👤 决策清单。

---

## 一句话结论

**泛做「AI Agent 目录」或「MCP Server 目录」= 偏红海（接近 beaches near me 陷阱）。**  
有搜索意图、有人付费上架，但前排玩家多、官方/社区已占坑；新手泛目录很难成为"为数不多的竞争者之一"。  
**若做 A，建议只做细分切口，不做大而全目录。** 否则优先换 B（自己踩过的 Agent 痛点工具）。

信号灯：**🟡 黄（有需求，但泛目录不推荐；切口或换方向）**

## 1. 候选词表（分层）

### 头词（流量大、竞争几乎一定高）

| 候选词 | 意图 | 免费档观察 |
|---|---|---|
| AI agent directory | 找站收录的 Agent | SERP 被多家专用目录占满 |
| best AI agents | 榜单/评测 | 内容站 + 目录站混战 |
| AI agents list | 列表 | 同上 |
| AI tools directory | 更宽（工具≠Agent） | 更老更挤 |
| MCP server directory / list / registry | 找 MCP | 官方 registry + 多家社区站 |

### 中长尾 / 切口假说（相对可能还有缝）

| 候选词 / 切口 | 为什么可能有缝 | 风险 |
|---|---|---|
| Claude / Cursor / 某 IDE 专用 agent 目录 | 绑定工具生态，主题更尖 | 平台一变就废 |
| vertical: sales / legal / recruiting agents | 已有 saastr 等垂直站，但仍比泛目录窄 | 垂直里也可能有人 |
| MCP security / risk / audit list | HN 在喊"安全风险分析"；armor1 类新产品刚冒头 | 窗口短，技术门槛 |
| agent templates / starter kits | 开发者"拿来就用"，比纯列表更产品化 | 更像工具站，偏 B |
| open source AI agents only | 筛选维度明确 | 和 awesome 列表抢 |

> 赫兹原则：先有词再验证。上表长尾是**假说**，精确量要 🔑 再筛。

## 2. SERP 竞品表（前排玩家，非完整）

### 2.1 AI Agent 目录类

| 站 | 定位粗描 | 免费档可读信号 |
|---|---|---|
| [aiagentstore.ai](https://aiagentstore.ai/) | 大目录 + 分类 + 博客 + **Get Featured** | 规模感强；明确 featured 变现 |
| [aiagentsdirectory.com](https://aiagentsdirectory.com/) | Agent 目录 + 分类浏览 | 专用域名 exact-match 感 |
| [aicouncil.com](https://aicouncil.com/) | Agent 目录 | 品牌站形态 |
| [agent.ai](https://agent.ai/) | Agent 平台/目录混合 | 产品感强，不只列表 |
| [topai.tools](https://topai.tools/) | AI 工具大目录（含 agent） | 老牌工具站截流 |
| [aihub.directory](https://aihub.directory/) 等 | 更多目录变体 | SERP 上同类多 |

**竞品结构共性**：分类标签 + 提交入口 +（多数）featured/推广位 + SEO 博客。  
**"我能不能做得比它好？"** —— 泛目录维度上，你很难只靠"多收录几个"赢；要赢必须有**不可复制的筛选标准或数据**（安全评分、实测、某生态 exclusive 等）。

### 2.2 MCP 目录 / Registry 类

| 站 | 定位 | 信号 |
|---|---|---|
| Anthropic 官方 MCP registry | 官方源 | 权威性最高，泛目录很难压官方 |
| [pulsemcp.com](https://www.pulsemcp.com/servers) | 社区 MCP 目录 | 公开称 6k+ servers 量级 |
| mcp.so / glama.ai 等 | 社区浏览/搜索 | 多家并存 |
| github awesome-mcp-servers | 开源列表 | 开发者默认起点之一 |

**关键事实**：MCP 不是"没人做目录"——是**官方 + 社区 + awesome 已经三层占坑**。2025 年初 HN 已有人说 "multiple directories already"；到 2026 只会更挤。

### 2.3 垂直 / 新切口（值得盯，不是让你立刻抄）

| 站/动态 | 切口 | 启示 |
|---|---|---|
| SaaStr AI agent 目录 | B2B sales 垂直 | **垂直 > 泛** 仍有人做 |
| armor1 等 MCP risk | 安全/风险分析 | "列表"升级成"评估" |
| 各站 "submit / get featured" | 变现模型验证 | **有人愿意为曝光付费** ✅ |

## 3. 竞争度（免费档粗估，非 KD）

| 信号 | 观察 | 类比目录站笔记 |
|---|---|---|
| SERP 前 10 | 专用目录站 + 工具站 + 媒体榜单，**不是**一堆烂页凑数 | 像 beaches：玩家多且专职 |
| allintitle | 精确条数难免费稳定拿到；搜索 "AI agent directory" 返回大量标题党/专用站 | 不能当绿灯 |
| 官方玩家 | MCP 有 Anthropic registry | dog park 没有"官方 dog park 联盟站"级别对手 |
| 新站速度 | 2025–2026 持续有新目录/新 registry 叙事 | 窗口在关，不是刚开 |

**粗判**：头词 **高竞争**；精确 KD/外链门槛未知 → 若你强烈想做泛目录，**先补 🔑 再决定**，别先建站。

| 证据 | 含义 |

## 9. 三种走法（供 👤 选）

### 方案 0：不做泛 A，优先 B
把自己做 Agent 时的痛点列出来 → 查有没有人搜/吐槽 → 单功能小工具订阅。  
**匹配最高、闭环可能更快。**

### 方案 1：A 改成极窄切口（仍叫 A 的亲戚）
只选一个，例如：
- **仅** Claude/Cursor 生态可用的 Agent + MCP（绑定你日常栈）
- **仅** B2B sales / recruiting 某一行
- **MCP security / quality score**（列表升级成评估）

验证顺序：该切口词的 SERP 是否已有 3+ 强专职站 → 没有再考虑建。

### 方案 2：泛目录硬刚（不推荐，除非 🔑 数据打脸）
补 Ahrefs：头词月搜、KD、top 页外链 → 若 KD≤15 且 top 页都是薄内容，再谈。  
**当前免费档证据不支持一上来就这样。**
