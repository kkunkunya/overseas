# 调研人机分工（A 方向起，可复用）

> 第 1 步选方向调研时，哪些动作 Agent 做、哪些 Agent+浏览器做、哪些要付费 API、哪些必须人看。可复用于任何方向的调研。
>
> **修正记录**
> 1. 原版把"要登录态/插件"都归"要你给账号" → 改：agent 有浏览器操控，归 🌐
> 2. **2026-07-21 实战修正（A 方向调研后）**：免费档能覆盖"有没有需求 / 竞品是谁 / 社交信号 / 趋势方向"；精确搜索量、KD、外链、CPC 仍缺 🔑；Trends 页面常被反爬，优先用 🌐 或二手报道。

## 判据（四档）

| 档 | 含义 | 典型能力边界 |
|---|---|---|
| 🤖 **Agent 直做** | 信息处理 + 公开页抓取 / 搜索 API | 列词、SERP 名单、Reddit/HN 帖、竞品页文案、域名 whois 公开页 |
| 🌐 **Agent + 浏览器** | 要渲染 / 交互 / 登录 / 点展开 | Trends 图、Similarweb 公开页、站点内筛选、提交页交互 |
| 🔑 **付费 API / key** | 精确搜索量 / KD / 外链 / CPC | Ahrefs / Semrush / Google Ads——**唯一要你给 key 的档** |
| 👤 **人看** | 判断 / 决策 / 创意 | "打得过吗"、做不做、选切口、卖空气文案 |

## 实战可跑性（A 方向验证过）

| 信号 | 免费档够不够 | 说明 |
|---|---|---|
| 候选词 + 变体 | ✅ 🤖 | AI 扩词 + 搜索建议 + 竞品页 H1/分类 |
| "有没有人在做" | ✅ 🤖/🌐 | SERP 前 10 名单 + 站点数级（粗） |
| allintitle 精确数 | ⚠️ 粗估 | Google 结果数常被挡；用 SERP 密度 + 站点数级代替，精确要 🔑 |
| 月搜索量精确值 | ❌ 要 🔑 | Trends 只能看相对涨跌；数字靠 Ahrefs/Semrush |
| 趋势涨跌 | ⚠️ 🌐 | Trends 页面反爬多；可用新闻/行业报道补 |
| 竞品是谁、形态 | ✅ 🤖 | 首页文案、分类、submit 页、featured 定价 |
| 外链 / DR | ❌ 要 🔑 | 免费页只能猜 |
| Reddit / HN 信号 | ✅ 🤖 | 需求/吐槽/饱和评论都能抓 |
| CPC / 商业价值 | ⚠️ 粗 | 能从 featured listing 存在推断"有人付费"，精确 CPC 要 🔑 |
| "打得过吗" | ❌ 👤 | 只能给你证据，不能替你拍板 |

**结论**：免费档足够做**去/留初筛**；要算 ROI / KGR / 外链门槛再补 🔑。

## 推荐调研顺序（免费档 → 决策）

```
1 列词 → 2 SERP 竞品表 → 3 社交信号 → 4 趋势方向
        → 5 变现证据（有没有人在卖 featured）
        → 6 写报告：红/黄/绿 + 切口假说
        → 👤 拍板
        →（若绿/黄且要精确 ROI）补 🔑
        →（若做）卖空气
```

> 不要一上来就买 Ahrefs。先用免费档判断是不是 beaches 陷阱；是陷阱就换词/换切口，省钱。

## 你实际要做的事（👤 汇总）

1. **拍板"打得过吗"**——看完竞品表 + 报告后的最终判断
2. **拍板 A 做不做、做哪个细分切口**（泛目录 vs 垂直 vs 不做）
3. **要用付费 API 时给 key**（Ahrefs / Semrush / Google Ads）——唯一需要人提供的物料
4. **（后置）卖空气定文案 / 定价 / 卖点**

> 原则：免费档（🤖 + 🌐）覆盖大部分调研；人主要只做判断和拍板。
