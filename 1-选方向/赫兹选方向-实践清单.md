> 主源：赫兹 `原文/1-选方向/`（ADR-0001）

> 目标：第 0 阶段练到手；**先跑通一轮「词 → 评估结论」**，不急着建站。  
> 标记：**🤖 = Agent 做**｜**👤 = 你做**｜**🤝 = 一起**｜**🔑 = 要付费/账号才精确**
>
> **标准免费三件套（ADR-0002）**：**AITDK** + Google SERP/语法 + Google Trends。AITDK 网页端 Agent 可开；**插件需你安装**后 Agent 才能看站面板。
>
> **取数只走两条简单通道**：① 用户明确指定时用 **Chrome** 看网页/登录态/插件，逐项说明看了什么和缺什么；② 有明确批量需求时用**官方 API / 官方 MCP**。付费直连不方便就回退 Chrome，当前不搭完整 trending 平台。

## 0. 赫兹方向观（先记 4 句）

1. **搜索即需求**——很多人在搜的词 = 需求线索（004 / 005）  
2. **先有痛点/词，再谈产品**——别先做完再找用户（015 / 017）  
3. **评估顺序固定**：有没有需求 → 能不能打 → 能不能赚钱 → 值不值得投入（**018**）  
4. **痛点有等级**——越刚需越好转化：娱乐 < 兴趣 < 效率 < 赚钱 < 强刚需（**029**）  
5. 加一句：**什么人 × 什么场景 × 愿花多少钱 × 解决什么问题**（028 引小排）

## 1. 实践总流程（按周练，可循环）

```
第 1 轮（本周就做）
  A 收集种子线索（至少 5 条）
  → B 扩成候选词表（15～30 个）
  → C 粗筛砍到 3 个
  → D 对 1 个主词跑满 018
  → E 你拍板：绿继续 / 黄再挖 / 红换词

第 2 轮（词过了再谈）
  F 抄/超/钞 看竞品
  → G（可选）卖空气验证付费
  → H 点头后另开项目建站  ← 离开第 0
```

**第 0 结束标志**：至少 1 个词走过 D，你写下「做 / 不做 / 再查」和原因。

**当前阶段边界**：只做到“候选进入 → 018 证据齐 → Kun 拍板 → 第一个 MVP”。GSC、GA/Plausible、Clarity 等上线后工具先记录，不提前建设自动化。

## 3. 人机边界（一张表记牢）

### 🤖 Agent 可以稳定做的

- 读/摘赫兹原文要点，按清单执行  
- Chrome 打开 Google / Trends / 竞品页 / Reddit 公开帖  
- 扩词、下拉词、相关搜索、allintitle 粗查  
- 整理前 10 竞品表、写 018 报告草稿  
- 标绿/黄/红**建议**（最终你改）  
- 维护 `实践-候选词表.md` / `实践-018-*.md`  
- 提醒你卡在清单哪一步  

### 👤 只有你能做的（我替不了）

- 愿不愿意做这个品类/人群（兴趣与长期）  
- 「打得过吗」的最终判断  
- 痛点是不是你认同的「真痛」  
- 定价心理、卖空气文案是否像你  
- 是否花钱买 🔑（Ahrefs/Semrush）  
- 是否结束第 0、开产品项目  

### 🔑 没有也能练，有了更准

| 数据 | 无 key | 有 key |
|---|---|---|
| 月搜量 | Trends 相对热度 | Semrush/Ahrefs 数字 |
| KD | 看 SERP 结构 | KD 分数 |
| KGR/EKGR | 算不出精确 | 可算 |
| 外链 | 难 | Ahrefs |

**实践原则：先用免费档跑通手感；卡在「差一个数字才敢拍板」时再上 🔑。**
