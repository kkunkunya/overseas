## 一句话概念

AI 应用出海 = 用 Web 站 + SEO 自然流量 + 订阅收款，把「国内难付费 / 难获客 / 政策重」换成「白品牌可卖 / 谷歌可躺流 / 订阅可复利」。新手默认走**垂直细分词**，别一上来赌热词或硬刚大词。

## 可复用细节

### 1. 国内三重困境（用来决定「要不要出海」）

- **付费意愿**：作者观察——工具月费 ¥20 时，用户先找闲鱼/免费替代；海外 100 访客里约 10 付费，国内约 2–3。
- **政策门槛**：小程序要执照+认证+经营范围匹配；网站/APP 要备案；未上线已耗钱耗周。
- **流量困境**：百度前页广告重；抖音/小红书「做就有、不做就没」，难攒持续自然流量；稍有起色大厂易跟进。

### 2. 海外五优势（对标「躺赚 + 复利」）

- **白品牌认可**：先看产品是否解决问题，不先看是不是亚马逊/谷歌。
- **订阅习惯**：年费常 $100–300 量级；续订带来滚雪球（新用户 + 老用户续费）。
- **消费力**：国内 ¥9.9 档，海外可试 $9.9+。
- **谷歌自然流量**：广告少、SEO 做好有免费流量；作者举「3 个月 900 万曝光 0 广告」案例（个案，非均值）。
- **Web 为主**：先做 Web，不必同时上 iOS/Android 原生。

### 3. 三种选方向打法

| 打法 | 适合谁 | 核心逻辑 | 操作要点 | 风险 |
|------|--------|----------|----------|------|
| **热词抢占** | 有模板、能 3 小时上线的老手 | 大厂发新模型 → 词搜索量暴涨、KD≈0 → 当天占位 | 预置模板；盯发布；域名 `.com` > `.ai` > `.io`；预对接模型中转 | 窗口几周～几月；慢一步归零 |
| **垂直细分**（新手默认） | 新手 / 风险可控 | 大词难排，场景词 KD 低、意图清 | 例：`AI wedding photo generator`、`AI ID photo generator`；KD 0–30、月搜 1000+；有商业意图 | 量小于大词，要接受小而美 |
| **稳定词优化** | 有耐心长期投 | 已定格局的大/稳词，靠内容+外链慢慢顶 | 周更 ≥2 篇；外链；站结构/体验；持续功能更新 | 3–6 月+ 才见效 |

**热词案例（作者口径）**：2025-08 谷歌图像模型 Nano Banana 发布当日搜索暴涨、相关站极少；有人当晚注册域名、3 小时上线，靠低 KD 上首页。数字（转化 1.5%、客单 $20、月入数十万）是作者推演/个案，**复制前过赫兹 018，不当承诺**。

**挖垂直词四步**：

1. 用 SEMrush 等看竞品词（库内免费档先 AITDK + SERP + Trends）
2. 落到具体场景，不泛功能
3. 筛 KD 0–30、月搜 1000+
4. 优先有付费意图的商业词

**KD 速记**：0–30 新手友好；30–50 要 2–3 月；50+ 不适合新手起手。

### 4. 技术实现七环节（交叉 2/3/5）

| 环节 | 推荐 | 注意 |
|------|------|------|
| 域名 + 企业邮箱 | Namecheap（.com 约 $10–15/年）；Zoho 免费企业邮 | 域名贴关键词；避免带 `-`；Stripe 常要企业邮 |
| 网站开发 | Next.js；非程序员可买模板（作者估 ¥几百） | 必备：登录、AI 调用、订阅支付、额度、响应式 |
| 部署 | Vercel + Supabase | 免费额度够起步；赚到钱再付费 |
| AI 模型 | 中转商聚合多厂 API | 按量计费；后期成本常占收入 20–30%（作者口径） |
| 支付 | 首选 Stripe；备选 Lemon Squeezy / Paddle | 用户付 → Stripe（约 2.9%+$0.3）→ Wise → 国内卡/投资 |
| 分析 | GA + GSC 必备；Clarity 免费回放；SEMrush 可用中转降本 | 北美加 Bing；俄区加 Yandex |
| SEO | Sitemap 交 GSC/Bing；周更 1–2 篇；外链 | PH / HN / Reddit / Quora / 导航站；快加载 + 移动端 + 清定价 FAQ |

### 5. 成本 / 时间 / 收入预期（作者保守口径）

**前期成本**：域名 + 可选模板 + 初期 AI/SEO 工具 ≈ ¥1000–2000；月度工具/调用 ≈ ¥500–1000。  
**开发**：模板 1–2 周；从零 1–2 月。  
**上线到首单**：垂直 1–2 月；热词可能几天；稳定词 2–3 月。  
**稳定收入**：作者写「正常 3–6 月到 $1k–5k/月」——**个案区间，不是保证**。

| 月 | 作者保守区间 |
|----|----------------|
| 1 | $0–100 |
| 2 | $100–500 |
| 3 | $500–2000 |
| 4 | $1000–3000 |
| 6 | $2000–5000 |

前 1–2 月接近 0 是常态：收录、排名、信任都要时间。

### 6. 俄罗斯市场（可选补洞）

主流支付（如 Stripe）受限 → 竞争少。若做：Yandex Webmaster、俄支付渠道、俄语界面（可 AI 译）。**当前主线不必跟**，记作观察位。

### 7. 常见问题（执行边界）

- 非程序员：学基础 / 找合伙人 / 买模板，门槛可降不可跳过验证。
- 不一定要去香港开实体卡：Wise 虚拟账户可用大陆身份证。
- Stripe 不过：Lemon Squeezy / Paddle；把站、企业邮、产品描述做专业。
- **不需要备案**（海外站）。
- SEO 要持续；排稳后维护成本下降。
- 前期不建议买量；站内不建议主靠 Google 广告赚钱（订阅 > 广告）。

### 8. 30 天行动计划（作者版）

| 天 | 动作 |
|----|------|
| 1–7 | 选垂直方向；SEMrush 等分析 3–5 词；定 1 个 月搜 1000+、KD&lt;30 的主词 |
| 8–14 | 域名 + 企业邮 + 模板/开发基本功能 |
| 15–21 | 接 AI API + Stripe，跑通付费闭环 |
| 22–28 | 上线；交 Sitemap；发第一批博客 |
| 29–30 | 盯数据、按反馈改 |

30 天后目标：**完成 0→1**，不是当月暴富。之后 2–3 月持续 SEO/内容/产品。

## 防止误用

- **适用边界**：这是 C 端 AI 工具站 / 轻 SaaS 入门地图，不是 Workflow B2B 或目录站专项手册；专业服务商家等当前主线仍走 Community-first + 018。
- **别把收入曲线当 KPI**：表内美元是作者保守叙事/个案区间，复制前自己重算单位经济与 018。
- **热词不是新手主线**：3 小时上线需要模板、中转、域名手速；失败成本是沉没时间，不是「看了案例就会」。
- **KD 数字厂商各异**：SEMrush KD ≠ 唯一真理；本库默认免费三件套 + SERP 结构，🔑 精确档另算。
- **最大误读**：读完就按 30 天计划写代码——**跳过卖空气**。与赫兹/本库规则冲突时：先概念页 + 真实行动，再重产品。
- **俄罗斯/中转商/具体报价**：时效性强，用前复核；不因「竞争少」跳过支付合规与触达可行性。
