## 1. 你现在在哪

```
第 0 阶段 = 选方向 + 验证（还没建产品项目）
     ↓ 确认「做哪个主词 / 哪种站」之后
第 1 步完成 → 另开独立文件夹建站（那才是做产品）
```

**本仓库 `overseas/` = 查阅 + 调研笔记，不是产品代码库。**  
产品另开项目。你说得对：先聚焦第 0 阶段，确认后再建项目跑起来。

---

## 2. 第 0 阶段要达成什么（成功标准）

不是「想出一个完美 idea」，而是：

| # | 达成 | 人话 |
|---|---|---|
| 1 | 选定 **1 个主词** | 例如以后只围绕 `xxx near me` 做站 |
| 2 | 能回答 **打得过吗** | 看过 Google 前 10 + 至少 1 个竞品站 |
| 3 | 说清 **第一笔钱怎么来** | 广告 / 付费上架 / 销售线索（先不要求订阅） |
| 4 | 愿意 **做第一站练闭环** | 允许不完美，先跑通：有人搜到 → 有变现路径 |

第 0 阶段 **结束标志**：你点头「就做这个词，可以开项目了」。

---

## 3. 总方向（目标不丢）

> **躺赚 + 复利** = 被动收入倾向 + 能滚雪球  
> **形态** = 网站小站（不是 App）  
> **第一站策略** = 目录/索引类 SEO 站（大佬推荐的起手式）→ 先跑通闭环  
> **以后** = 你有自己想法或看了更多文章，再叠订阅、工具、第二站……

| 目标 | 第一站怎么贴 | 以后怎么加强 |
|---|---|---|
| 躺平（少维护） | SEO 自然流量为主 | 内容/收录一次，搜索持续来 |
| 复利 | 域名+排名是资产 | 站稳后加订阅/多站/外链 |
| 闭环 | 广告或商家付费上架 | 再谈订阅会员 |

**第一站不要求完美躺平+强订阅同时满格。** 先闭环，再优化。

## 4. 我们怎么配合（分工）

| 角色 | 做什么 |
|---|---|
| **Agent（我）** | 执行：开浏览器搜、记 SERP、写笔记、整理灯色、改方法 |
| **你** | 查看 + 学习 + 拍板：讨厌的词划掉、选词、问「这是什么意思」、最终「做不做」 |
| **一起** | 对齐语言 → 调研 → 你确认 → 再开产品项目 |

你不需要会 SEO 术语；看不懂就喊停，我用人话讲。

## 5. 第 0 阶段路线图（阶段内小地图）

```
① 对齐语言与方法          ← 已做一部分（目录站、near me、找需求）
② 粗筛一批候选词          ← 已做 E 词表 v0
③ 浏览器实查 1～2 个词    ← 进行中（已查 batting cages）
④ 你选中 1 个主词          ← 等人
⑤ 深挖：多城 SERP + Reddit + 竞品 + 变现
⑥ 你拍板：建 / 换词
⑦ 第 0 结束 → 另开项目建站（第 1 步之后）
```

**现在指针：③～④ 之间。** 不急着写代码。

## 6. 方法一句话（找需求，不是造产品）

```
谁已经在 Google 搜什么？
→ 搜出来的网站烂不烂？
→ 我能不能做得更好？
→ 钱怎么收？
→ 你愿不愿意做这个主题？
```

**目录站** = 像黄页（**形态**，辅源视频讲得很细）。  
**主框架** = 赫兹：找词/找需求 → 018 评估词 → 015 等验证付费。  
目录站可以是第一站形态，但**判据跟赫兹走**，不是只跟视频清单走。

## 7. 工具真相（免费用到哪、缺什么）

| 能力 | 状态 | 说明 |
|---|---|---|
| Chrome 实搜 Google | ✅ 已接通 | 比纯 Web Search 真 |
| 打开竞品站 / Reddit 公开帖 | ✅ 可用 | 已读 Austin 帖 + CageList |
| Google Trends 截图 | ⚠️ 半可用 | 图能看；有时 reCAPTCHA |
| **near me 定位** | ❌ 偏差 | 浏览器在**上海**，near me 会出中国结果 → 要用「城市名」搜美国 |
| Ahrefs 月搜/KD/外链 | ❌ 无 | 要付费 key；第 0 可先不做 |
| Semrush / Similarweb 深度 | ❌ 无 | 同上 |
| Reddit 登录后更多 | 可选 | 公开帖够用 |

**保证不了「一定赚钱」**；保证的是：按大佬流程做验证，少踩「没查 SERP 就建站」的坑。

## 9. 刻意不做的事（第 0 边界）

- ❌ 不开产品代码仓库（确认词之前）  
- ❌ 不追求完美订阅 SaaS 第一站  
- ❌ 不绑 AI Agent 主题（除非以后你改主意）  
- ❌ 不并行深挖 10 个词（一次 1～2 个）
