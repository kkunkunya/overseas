## 1. 产品一句话

**把一张手机自拍变成菲律宾 PRC（Professional Regulation Commission）执照/考试要求的合规照片：线上版 2x2（白底、无名字条）+ 现场版 1½×1½（白底、带完整名字条），一键下载，含 4 张打印纸 PDF。**

## 2. 目标用户与场景

| 场景 | 用户 | 时机 | 频率 |
|---|---|---|---|
| 执照考试申请（Board Exam / LERIS） | 护士、会计、教师（LET）、工程师、建筑师等考生 | 每年 2-4 次报名窗口 | 波峰明显 |
| 初始注册（通过考试后） | 新晋执业者 | 出成绩后 1-2 周 | 波峰 |
| PIC 续期（Renewal） | 在册专业人士 | 常年滚动 | 持续 |
| 补办（Duplicate）/ 改名更正（Petition） | 在册专业人士 | 偶发 | 低频 |

**核心人群画像**（已取证）：
- 菲律宾考生/执业者，手机自拍为主，无 Photoshop 技能
- 照相馆贵（P150-300/次）、报名窗口短（错过等半年）、照片不合格要重拍
- 在 Reddit/TikTok 大量求助「PRC 照片到底什么规格」「名字条怎么写」

## 3. 痛点（已多重取证，不赘述证据链）

| # | 痛点 | 证据 |
|---|---|---|
| 1 | 线上（2x2 无名字条）与现场（1½×1½ 带名字条）规格不同，官方 FAQ 分散，考生搞混 | PRC 官网 FAQ X 条 vs 申请表 PDF；r/AccountingPH「护照尺寸还是 2x2？还是都要？」 |
| 2 | 名字条格式与排版常做错（白底黑字；姓，名 中间名首字母） | TikTok @buyayi 11.5K 赞纠错教程 |
| 3 | 通用工具（PhotoAiD/PhotoGov）只做尺寸转换，不做 PRC 双规格 + 名字条 | SERP 实测：前排无 PRC 专用工具 |
| 4 | 替代流程笨：Word/Canva 手工拼版，YouTube 教程几十万观看 | YouTube「2x2 with name tag」「passport size with nametag」教程 |

## 4. 用户流程（端到端）

```
1. 落地页/工具页 → 点击「Start」上传自拍（手机相册/拍照/拖拽）
2. 系统自动：人脸检测 → 裁切到 2x2（白底替换、头部占比 70-80%、脸居中）
3. 输入名字条信息：Surname / First Name / Middle Initial（或全名自动解析）
4. 预览两版并排：
   - 线上版：2x2 白底无名字条（对照官方要求清单）
   - 现场版：1½×1½ 白底 + 底部白底黑字名字条「SURNAME, First Name M.I.」
5. 合规自检（V1.1）：头部占比/背景纯度/清晰度 绿黄红
6. 选择下载：
   - 免费：带水印预览 + 低分辨率单张
   - 付费：无水印高清单张（线上版+现场版）+ 4 张现场版打印纸 PDF（A4）
7. 完成页：下一步指引（去 LERIS 上传 / 打印 4 张带去 PRC）
```

## 5. 功能清单

### MVP（M1-M2，必须）
- [ ] 自拍上传（手机/桌面，支持拖拽）
- [ ] 人脸检测 + 自动裁切 2x2（白底替换、头部 70-80%）
- [ ] 名字条输入与自动排版（白底黑字、居中、格式校验「Surname, First Name M.I.」）
- [ ] 双规格生成：线上 2x2 无名字条 / 现场 1½×1½ 带名字条
- [ ] 预览对比（官方要求清单对照勾选）
- [ ] 下载：单张 PNG/JPG（免费水印 / 付费无水印）+ 4 张打印纸 PDF（A4，付费）
- [ ] 提示：6 个月内近照、有领得体着装（中英文双语）
- [ ] 官方链接与免责声明（非官方、规格以官网为准）

### V1.1（上线后快速迭代）
- [ ] 合规自检绿黄红（头部占比/背景/清晰度）
- [ ] 多场景切换：考试申请/续期/补办/改名 → 自动调整规格与名字条
- [ ] Tagalog 界面（en + tl 双语切换）
- [ ] 相机引导（拍照姿势/光线提示，手机端）
- [ ] 照片有效期提醒（按上传日期倒推 6 个月）

### 明确不做
- 通用护照照片制作（PhotoAiD 红海）
- AI 头像生成（Kun 已否决）
- 真人修图服务、线下打印合作
- 账号体系/订阅制（一次性任务不做订阅）

## 7. 技术建议

**架构原则（Kun 2026-08-09）：AI 是可选增强，规范是硬约束。** 不把技术方案卡死——未来可接 GPT 视觉模型生成/识别，但无论用什么模型，**输出必须过「规范校验器」**（确定性规则：尺寸/背景/名字条格式/头部占比），AI 不做最终裁决，避免幻觉导致照片被拒收。

| 模块 | 方案 | 备注 |
|---|---|---|
| 前端框架 | 静态站（Next.js 或 Vite + React） | SEO 友好，SSR/SSG |
| 人脸检测 | MediaPipe Face Detection（免费、浏览器端）或 face-api.js | 手机端性能优先；未来可换视觉 AI |
| 白底替换 | remove.bg API（免费额度）兜底 + 纯色检测算法（无 key 也能跑） | 双保险；未来可接 AI 抠图模型 |
| 图像处理 | Canvas API：裁切/缩放/白底/名字条渲染 | 纯前端 |
| 名字条 | Canvas 文字渲染：白底黑字、居中、大写、格式校验 | 严格校验输入；全名可交给 LLM 解析为 Surname, First Name M.I. |
| **规范校验器（必做）** | 确定性规则引擎：尺寸、白底纯度、头部占比、名字条格式/颜色、分辨率 | **所有输出必经此关，AI 结果也要过** |
| AI 辅助（V1.1+，可选） | 视觉模型（如 GPT-4o/Claude 视觉）：照片合规性识别、自动纠偏、全名解析 | 不卡死具体模型；能力可插拔 |
| PDF | jsPDF 排版 4 张现场版到 A4（带裁切线） | 可打印 |
| 支付 | Stripe Payment Links（无后端最简单）；PayMongo V1.1 | 收单需后端 webhook（可选极简） |
| 部署 | Vercel/Netlify/Railway 静态 + 极简 serverless | 低成本 |
| 分析 | Plausible/GA4 | 埋点：上传/生成/付费/下载 |

### 8.2 页面结构（GEO A 级基线，第 6 轮实证：小站拿 A 不难，结构化/可引用/Trust 是分水岭）

**全站硬性（一次做对，不后补）：**
- 单 H1，清晰 H2/H3 层级
- canonical / robots.txt（允许 GPTBot 等 AI crawler）/ sitemap.xml / OG+Twitter 全套
- 语义 HTML（article/section/table）、图片 alt 描述性、标题+meta description 完整
- 结构化数据（JSON-LD）：FAQPage + HowTo + SoftwareApplication
- 每页正文铺任务词词频（如尺寸/名字条/白底/打印/2x2/passport size/name tag）

**页面清单（V1 同步上线）：**
| 页面 | 类型 | 内容 | 对应词 |
|---|---|---|---|
| `/` 工具主页 | 工具页 | 上传→生成主流程 | 品牌 + prc photo |
| `/prc-photo-requirements` | 内容页 | 规格总览 + FAQ（官方引用） | prc photo requirements |
| `/prc-2x2-picture` | 内容页 | 线上规格 + 工具入口 | prc 2x2 picture |
| `/prc-passport-size-photo-with-name-tag` | 内容页（金矿） | 现场规格 + 名字条格式 + 工具入口 | prc passport size photo with name tag |

**Trust 增强：**
- 所有规格页引用 prc.gov.ph 官方链接（官网 FAQ / 申请表 PDF / LERIS）
- 「Last updated 2026」+ 免责声明：非官方、规格以官网为准
- 名字条格式页给正确/错误示例（可引用性高）

**内链策略：** 内容页 → 工具页（转化路径）；内容页互链（词族覆盖）。

## 9. 风险与合规

| 风险 | 缓解 |
|---|---|
| 规格随年份调整 | 内容页注明版本 + 更新机制（配置化规格表，改一处全站生效） |
| 被当官方冒充 | 显著免责声明 + 官方链接 + 不仿 PRC 视觉 |
| 名字条/裁切错误导致拒收 | 严格格式校验 + 合规自检提示 + 「不保证通过」声明 |
| 免费盘分流（用户只用免费） | 水印 + 低分辨率 + 打印纸付费点（打印纸是刚需） |
| 手机端浏览器兼容 | 主测 iOS Safari + Android Chrome；降级提示 |
