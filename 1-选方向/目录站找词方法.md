# 目录站找词方法（E 路线 · v0）

> 目的：在**不靠空想 idea、不绑 AI 主题**的前提下，用可重复流程挖「有搜索量、能打、能变现」的目录/内容站主词。  
> 来源拼装：目录站赛道验证视频 + 赫兹 018 评估词 + 本库人机分工 + 2026-07-21 实跑修正。  
> 用法：**边做边学**——每轮输出一张词表；方法不对就改方法，词不对就换词。  
> 状态：v0 已跑过 1 轮免费档；若你认可，再沉淀为全局 skill。

---

## 0. 核心思路（为什么这样造词）

```
不是：我想做什么 → 再找有没有人要
而是：谁已经在搜 → 现有结果烂不烂 → 我能不能做得更好 → 钱从哪来
```

三层目标对齐你的「躺平 + 复利」：

| 层 | 含义 | 方法里对应 |
|---|---|---|
| 躺平生长 | SEO 自然流量，少运营 | 选 evergreen 意图词；一站一主题（topical relevance） |
| 能闭环 | 有变现路径 | 先定 ads / featured / lead 哪一种，再开干 |
| 可复利 | 资产可叠加 | 排名+域名是资产；站稳后再加订阅/工具层 |

**Agent 放哪**：你是造词/扫 SERP/写页的杠杆，**不是**产品主题。第一站主题尽量非 AI。

---

## 1. 流程总览（一次完整轮次）

```
① 种子入口     → 列出 15–30 个「可能有人搜」的词根
② 模式扩词     → 套模板变成可搜词
③ 硬过滤       → 杀掉品牌词、巨头盘踞类、明显红海
④ SERP 体检    → 每个词看前 10：谁在、薄不薄、能不能打
⑤ 社交抽检     → `[词] Reddit` 有没有真实抱怨/比价
⑥ 变现贴标签   → ads / featured / B2B lead / 以后订阅
⑦ 打灯        → 🟢可深挖 🟡观望 🔴不做
⑧ 👤 选 1 个   → 只深挖一个：城市页结构 + 域名 + 是否建站
```

**节奏建议（边做边学）**

| 轮 | 你做什么 | Agent 做什么 | 学到什么 |
|---|---|---|---|
| 第 1 轮（本轮） | 看灯色表，否掉你讨厌的 | 批量造词+SERP 粗判 | 什么叫 beaches 陷阱 |
| 第 2 轮 | 从 🟢 里挑 1–2 个 | 深挖：多城市 SERP + Reddit + 变现 | 什么叫「能做得更好」 |
| 第 3 轮 | 拍板唯一主词 | 出建站信息架构 + 页面清单 | 一站一主题怎么落 |
| 之后 | 另开产品仓建站 | 批量页 / SEO | 闭环与躺平是否成立 |

不要第 1 轮就建站。**词表 → 深挖 → 建站**，每步都有可见产物。

## 2. 造词方法详解（重点）

### 2.1 种子从哪来（五条入口，可并行）

| # | 入口 | 怎么用 | 例子 |
|---|---|---|---|
| A | **已知好案例邻域** | dog park / stump grinder 旁边长什么 | indoor dog park、chipper rental、aeration rental |
| B | **生活场景清单** | 列海外日常：宠物/搬家/户外/DIY/孩子/车/房 | dump station、batting cage、tool library |
| C | **模式模板**（见下） | 把名词塞进槽位批量生成 | `{X} near me`、`{X} rental` |
| D | **SERP 连带** | 搜一个词看「相关搜索 / 别人还在找」 | 从一个词滚出一串 |
| E | **竞品分类页** | 打开一个目录站看它的 category | 偷结构不偷主题 |

**刻意不用的入口（第一站）**

- ❌ 「我最近用 Claude 不爽什么」→ 工具站路线，维护重  
- ❌ 「AI 很火所以做 AI 目录」→ SISP，已验证偏红  
- ❌ 只看 KD 数字不看 SERP → beaches 陷阱

### 2.2 模式模板（造词引擎）

把「东西」塞进槽，一次可生成几十个候选：

```
本地发现类
  {place/activity} near me
  {place/activity} in {city}          ← 建站后的长尾页，不是先用来选题
  best {place/activity} near me
  free {place/activity} near me
  indoor / outdoor / 24 hour {X} near me

租赁/高客单（更偏 lead / featured）
  {equipment} rental
  {equipment} rental near me
  rent a {equipment}
  {equipment} hire                 ← 英联邦写法，后置

服务目录
  {service} near me
  emergency {service} near me
  cheap / same day {service} near me
```

**名词从哪填**：宠物、运动场、RV、工具、园林设备、儿童活动、小众爱好……  
**原则**：名词越具体越好；`sports near me` 太宽，`batting cages near me` 才像目录站。

### 2.3 硬过滤（10 秒杀掉垃圾）

出现任一条 → 直接 🔴 或降级，不进入深挖：

1. **大品牌 + near me**（Walmart / Chipotle / U-Haul 本尊）→ 官网 locator 打死你  
2. **著名景点/海滩/酒店类** → Yelp/TripAdvisor 盘踞（beaches 型）  
3. **已被单一超级 App 官方绑定**（如 pickleball 被 Pickleheads + USA Pickleball）→ 类似官方 registry  
4. **你完全无法采集/更新数据**（强实时、强合规、要上门）→ 躺不平  
5. **纯信息无变现 imaginable** 且流量还小 → 先放着

### 2.4 SERP 体检清单（每个进表的词必做）

打开前 10，打勾：

| 检查项 | 🟢 信号 | 🔴 信号 |
|---|---|---|
| 页面类型 | 本地小站、薄列表、答非所问 | Yelp/Tripadvisor/巨头官网占满 |
| 是否答得上意图 | 搜 A 出 B（机会） | 正好有完美目录 |
| 信息厚度 | 缺筛选/缺照片/缺更新 | 特征全、UGC 强、地图强 |
| 全国 vs 本地 | 全国目录弱，城市页空白 | 每个城市都有强本地站 |
| 你能否更好 | 能列出 3 条可执行改进 | 想不出任何改进 |

**唯一关键问句（留给 👤）**  
> 「如果我花 2–4 周做一站，我有没有机会在至少一部分城市进首页？」

Agent 给证据，人不外包这一问。

### 2.5 变现标签（没标签不进 🟢）

| 标签 | 适合 | 躺平度 | 复利度 |
|---|---|---|---|
| **Ads** | 高流量 toC（dog park 型） | 高 | 中（跟流量走） |
| **Featured listing** | 商家/场馆愿意买曝光 | 中高 | 中（年付可续） |
| **B2B Lead** | 高客单租赁/服务（stump 型） | 中 | 高（单 lead 贵） |
| **以后订阅** | 有工具层再加 | — | 高（第二阶段） |

第一站优先：**Ads 或 Featured 或 Lead 至少能说清一种**。

### 2.6 打灯规则（免费档）

| 灯 | 条件 |
|---|---|
| 🟢 | SERP 可改进点清晰 + 无单一官方巨头锁死 + 变现路径说得清 + 数据可批量采 |
| 🟡 | 有需求，但已有 1–2 个专职目录 / 或变现弱 / 或采集难 → 可深挖也可弃 |
| 🔴 | 巨头/官方锁死，或品牌词，或完全想不出比前 10 更好 |

精确月搜/KD 缺 🔑 时：**灯色以 SERP 结构为准，不以脑补搜索量为准。**
