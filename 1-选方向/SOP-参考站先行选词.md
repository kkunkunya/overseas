# SOP：参考站先行选词

> 2026-08-23 起默认。旧的「先从任务假设扩词」已归档，见 [`归档-SOP-垂直选词人机闭环.md`](归档-SOP-垂直选词人机闭环.md)。  
> 术语见 `CONTEXT.md`；量/KD 与选词顺序见 ADR-0016。  
> 项目 skill：`vertical-keyword-loop`（`.pi/skills/`，`scope: project`）。

## 一句话

```text
目标领域
  → 多模型找付费参考站（Markdown + 超链接）
  → 你看站，并导出或截 Semrush
  → Agent 写成功根源，先记关键词分析账，再挖词
  → 3 个核心词 + 10–15 个长尾写入笔记
  → 停扩词：社区三问或「缺哪一键」
  → 做出海付费 App
```

- **Agent**：并行调用多个模型找参考站，整理成可点击清单；拿到你交的 Semrush 导出或截图后，先写成功根源和分析账，再交词表。3+15 写入笔记后停止扩词，只点名社区反查或方向验证。不编造流量、反链、月搜或 KD，也不自己登 Semrush 硬拉。
- **你**：点开站点看 Title、Description 和付费入口；对准备深挖的域名，把 Semrush 的流量、反向链接、流量占比和自然关键词导出或截图交给 Agent。
- **产品形态**：出海 App / 订阅或明确付费。电商和纯广告站只作背景，不进正式参考清单。

## 1. 找参考站

你给出目标领域后，Agent 用当前能用的多个模型（Grok、ChatGPT、Cursor 等）各自列站，再合并去重。

优先收：订阅、买断、应用内付费墙，或能看清谁在付钱的产品站。Semrush 意图可标 **C（Commercial）** 的词所指向的站优先。

交付：一份带超链接的 Markdown 清单。你直接点开看。

## 2. 你看站，并导出 Semrush

对准备深挖的站，你自己看 Title、Description 和付费入口。SEO 概况和挖词所需数字，从 Semrush 导出或截图后交给 Agent，不要让 Agent 自己猜或改用别的工具顶上。截图和导出都算证据；图上没有的数写 No data。

每个准备深挖的域名，导出这些就够：

| 导出什么 | 用来判断什么 |
|----------|----------------|
| 流量规模 | 这个域名大概有多强 |
| 反向链接 / 引用域 | 外链底子 |
| 流量占比（搜索 / 直接 / 社媒 / 推荐） | 成功是靠 SEO、品牌还是别的渠道 |
| 自然关键词（量、KD、意图） | 从站挖词；C 优先 |

Agent 用导出写清：流量多少、反链多少、各渠道占比，以及「钱怎么收、人从哪来」。说不清就还没读完导出，不要开始挖词。

## 3. 从站挖词

只从证据覆盖、且你确认过的付费参考站往外挖。量/KD/意图只读这份导出或截图。

有搜索、有流量才有获客。月搜说明有人在搜，参考站该词的流量说明排上去真能进客；某种意义上 **volume 先于 KD**。KD 仍是关键依靠：同样有量时，蹭更好做的 KD 拿排名。正式池只收意图为 **C** 的词。量大的 C 不因 KD 略高就丢掉；KD 极低但量瘦的只当长尾。新手优先 **KD < 50**；更高不是禁区，只是更难排到前面。

Agent 先记关键词分析账，再交短名单：

- **蹭流量**：参考站已经在吃的通用任务词
- **品牌观察**：成名产品名，用来看用户怎么叫这个品类，并从旁边反推通用 C 词；不拿品牌词去抢别人首页
- **反推**：旁边看到的词，必须在下一张图或导出里对上量、KD、C 才进正式池

交出 **3 个核心关键词** 和 **10–15 个长尾词**，每个词写清量、KD（没有就写 No data）、来源站、从分析账哪一行来、为何适合做成付费 App。3 个核心词对应可做的任务页；长尾并进这 3 页。

## 4. 停扩词，再社区或方向验证

短名单写入笔记后，同一领域不再扩词。还缺哪一块，只走一步：

- 现在怎么凑合、卡在哪一步、会不会为结果付钱——这三问还没有可回溯原帖 → 社区调研或公开检索
- 用户任务、当前替代，或参考站收费那一键我们能否交付，仍写不清 → `direction-validator`
- 任务、承诺、词群和变现已齐 → `seo-site-blueprint`，在独立产品仓库做可用 MVP

## 每轮检查清单

- [ ] 参考站清单可点击，且优先是付费/订阅站
- [ ] 你已看过 Title、Description 和付费入口，并导出或截了准备深挖站的 Semrush
- [ ] 成功根源写在证据上：流量、反链、流量占比
- [ ] 关键词分析账已转录：蹭流量 / 品牌观察 / 反推，正式池只留 C；先按月搜/词流量排，再用 KD 判断好不好蹭
- [ ] 3 个核心词 + 10–15 个长尾都从分析账抽出，有量/KD 或明确 No data
- [ ] 品牌词只作品类观察和反推，不作为去抢别人首页的理由
- [ ] 短名单写入笔记后停止扩词；下一步只点名社区三问、方向验证或页面规划其中一项
