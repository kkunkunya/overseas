## 0. 一句话总思路

```text
做一份可复制的 Web 产品
→ 对准「有人搜、你排得上、有人愿付」的窄场景
→ 用自然搜索 + 持续内容/外链养流量（不是靠天天买量）
→ 用订阅/重复付费滚雪球
→ 收入尽量不绑死在你当下坐在电脑前的那几小时
```

PDF 里所有域名、框架、支付、SEO 软件，都只是把上面这条链 **跑通** 的零件。零件可换，链不能断。

## 1. 先想清楚：你在做哪种生意？

### 1.1 时间换钱 vs 产品收钱

| | 接外包 / 咨询 | PDF 说的 AI 应用出海 |
|--|----------------|----------------------|
| 你停工时 | 收入停 | 仍可能有人下单（「躺赚」的本义） |
| 上限 | 你的工时 | 流量 × 转化 × 客单 × 续订 |
| 积累 | 难复利 | 订阅续订 + 新客 = 滚雪球 |

**思路**：出海不是换个国家接外包，而是做 **可复制产品**——做一次，卖给很多人； ideally 订阅，让老用户也继续贡献。

### 1.2 为什么把战场放在「海外 Web + 搜索」？

PDF 用「国内三重困境 / 海外五优势」对比，背后不是崇洋，是 **结构差**：

| 维度 | 国内困境背后的结构 | 海外优势背后的结构 |
|------|-------------------|-------------------|
| 付费 | 低价/免费替代习惯强 → 转化难 | 工具/订阅付费习惯成熟 → 同样访客更易收钱 |
| 政策 | 上线前资质/备案吃时间钱 | Web 出海无国内备案那套前置 |
| 流量 | 广告盘厚、社媒「做就有不做就没」、大厂易碾 | 搜索自然结果空间大 → **可积累的免费流量资产** |
| 品牌 | 强依赖大牌 | **白品牌**：先问「解决没」再问「是不是巨头」 |
| 形态 | 常被推去小程序/双端 App | **Web 优先** → 先一条产品线验证 |

**思路**：你选的是「**付费习惯 + 可积累流量 + 轻交付形态**」的组合，不是选某个云厂商 logo。

### 1.3 躺赚 + 复利（别神话）

- **躺赚** ≠ 不干活；= 收入不 100% 等于「此刻是否在加班」。  
- **复利** = 新付费 + 老用户续订叠在一起，曲线可以越来越陡——**前提是产品还在、流量还在、续订还在**。  
- PDF 收入曲线是 **心理预期尺子**，不是合同。

## 2. 选方向：三种打法背后是同一种「窗口思维」

三种打法表面是战术，底层都在回答：

> **需求（有人搜/有人要）× 供给空档（你还排得上）× 商业（有人付）× 你的速度/耐心是否匹配？**

| 打法 | 窗口本质 | 你在赌什么 | 当前路径 |
|------|----------|------------|----------|
| 热词抢占 | **时间窗口**：新事物搜索暴涨，结果页还空 | 手速、模板库存、发布嗅觉 | **不做** |
| 垂直细分 | **意图窗口**：场景词需求真、竞争尚未成铁板 | 找得够窄、做得够贴、1–2 月可见信号 | **起手** |
| 稳定词优化 | **时间换权威**：格局已定，靠持续内容/外链/体验上移 | 耐心、周更、不换赛道 | **节奏（与垂直叠加）** |

### 2.1 热词（只作理解，不执行）

- **思路**：搜索量突然从≈0 拉爆时，竞争度短暂≈0 → 谁先成为「这个词的结果」，谁临时收流量。  
- **工具在干什么**：监控发布、秒注域名、预置可部署模板、预接通模型 API——全是 **压缩上线时间**。  
- **为何你不做**：窗口短，失败模式是「慢半拍归零」；路径要可积累，不靠赌发布日。

### 2.2 垂直细分（你要练的主思路）

- **思路**：大词（如泛 AI 生图）= 需求大但 **结果页已被强者占满**；场景词（婚纱照/证件照/产品图…）= 量可能小，但 **意图清、付费理由清、排名窗口在**。  
- **挖词四步背后的问题**（工具可换 SEMrush / AITDK / 其他）：  
  1. 别人已经靠什么词活着？（竞品词 = 市场已验证的语言）  
  2. 是否落到 **具体使用场景**，而不是功能形容词？  
  3. 需求是否够用、竞争是否你啃得动？（量 + 难度，数字软、**SERP 硬**）  
  4. 搜这个的人 **有没有付钱的理由**？（商业意图）  
- **KD / 月搜数字的真正含义**：  
  - 月搜 ≈ 「有多少人在表达这个问题」  
  - KD ≈ 「要撬开结果页大概有多费劲」（厂商算法不同，不可神化）  
  - 软门槛 1000+ & 0–30 = **新手先要「做得动 + 看得见反馈」**，不是数学最优  

**一句话**：垂直 = **用场景换可赢的竞争**，不是「做小生意认怂」。

### 2.3 稳定增长（和垂直怎么叠）

- **思路**：词或主题选定后，Google 信的是 **持续相关、持续有用、持续有站外认可** 的站，不是一夜改标题。  
- PDF 列的动作翻译成思路：  
  - 周更内容 → 保持主题活跃、覆盖长尾问法  
  - 外链 → 别人愿意引用 = 信任投票  
  - 结构/体验/功能更新 → 人能用完、愿回来；引擎也偏好健康站  
- **见效慢（3–6 月级）是机制，不是你不行**：权威和信任都是积分制。  

**和垂直的关系**：垂直解决「切哪块肉」；稳定解决「这块肉怎么越啃越有」。  
冷启动发帖（Viking 等）是稳定里的 **人肉获客层**：搜索还没养肥前，你先走进人群。

## 3. 「七环节」背后：跑通一台自动贩卖机

PDF 的域名 / Next / Vercel / Stripe… 是 **参考零件**。按链路记思路：

```text
能被找到的名字（域名）
→ 能被信任的联络身份（企业邮，常为支付审核）
→ 能完成任务的产品（登录·调用能力·额度·两端能用）
→ 能上线的承载（部署/数据，先免费额度）
→ 能力来源（API/中转 = 不自研模型，价值在场景包装）
→ 能收款的闭环（支付 → 提现路径）
→ 能看见真相的仪表盘（分析 + 搜索控制台）
→ 能持续被搜索喂食（Sitemap·内容·外链·体验）
```

| 环节（PDF 说法） | 可替换零件举例 | **不可替换的思路** |
|------------------|----------------|-------------------|
| 域名 + 企业邮 | 各注册商 / Zoho 等 | 可记、可贴词；**支付与品牌要专业身份** |
| 网站开发 | Next 或其它；模板或手写 | 最小闭环功能：**用上 → 限量 → 能付费**，不是只做皮 |
| 部署 | Vercel+Supabase 或其它 | **成本跟规模走**：没钱时别先养服务器舰队 |
| AI 模型 | 官方 API / 中转 / 换模型 | **不练大模型**；你卖的是场景与工作流，模型是水电 |
| 支付 | Stripe / Lemon / Paddle… | **收款是产品的一部分**；过不了就换通道，但站要像样 |
| 分析 | GA、GSC、Clarity… | **用数据打脸直觉**：人从哪来、卡在哪、搜什么词来 |
| SEO | 各种内容/外链手法 | **持续**让引擎与用户理解「这站管这个主题」 |

### 3.1 特别重要的几条隐含规则

1. **套壳合法且必要**：价值在「非技术用户的具体任务」，不在自研权重。  
2. **订阅 > 站内广告变现**：广告伤体验、降付费转化；主粮是用户付钱。  
3. **前期不靠买量**：先证明自然路径与产品；广告是油门，不是方向盘。  
4. **一人能启、无公司前置**：降低试错成本，才能用垂直词快速试。  
5. **AI 成本会吃收入一定比例**：定价与额度要想「调用差价」，不是只想订阅价好看。

## 4. 工具层：记住「问题」，名字当便签

以后换工具，用这张表对齐——**左列永远比右列重要**。

| 你要回答的问题 | PDF 里出现的例子 | 思路标签 |
|----------------|------------------|----------|
| 谁在搜什么？量大概多大？多难排？ | SEMrush 等 | 需求 × 竞争 |
| 真结果页长什么样？ | （你自己打开 Google） | **SERP 结构 > 分数** |
| 站上线了引擎知不知道？搜什么词来？ | Search Console + Sitemap | 收录与查询真相 |
| 人来了会不会用、在哪怒关？ | Analytics、Clarity | 行为与转化 |
| 钱怎么进口袋？ | Stripe、Wise… | 商业闭环 |
| 能力从哪来？ | 模型中转 / API | 可替换水电 |
| 如何被更多站提起？ | PH、HN、Reddit、导航站… | 曝光 + 外链投票 |

库内默认免费找词组合（可替换实现）：**扩词工具 + 真 Google + Trends**——见 CONTEXT「标准免费三件套」。  
**禁止**：背下工具名却答不出「我今天用它否定了哪个词 / 改进了哪一页」。

## 5. 30 天计划背后的行动哲学

PDF 30 天表：选词 → 上站 → 接模型与支付 → 提交搜索 → 内容 → 看数据。

翻译成思路：

1. **先选可赢的窄战场，再砌砖**（不是先学完框架再找事做）。  
2. **技术周的目标是商业闭环能点通**，不是架构优美。  
3. **上线日 = 学习日的开始**，不是毕业。  
4. **0→1 是完成定义**：站在、链通、可被发现；**不是**首月暴富。  
5. **反完美主义**：永远不会「准备好」；边做边补，比空学七环节更接近收入。

**本库补强（PDF 偏弱处）**：  
仅 SEO 等收录往往慢；应用 **冷启动**（社区发帖、回帖、台账）与 **真 CTA/行动信号** 并行，才更像「简单闭环」。思路仍一致：**尽早让真实用户碰到真实承诺**。
