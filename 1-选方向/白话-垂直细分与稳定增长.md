# 白话拆解：垂直细分 + 稳定增长（你要试的路）

> 2026-08-09。给「准备动手试」用的说明，不是新方法论。  
> 材料：《AI应用出海新手完全指南》三打法里的 **② 垂直细分** + **③ 稳定词优化**；冷启动补 **Viking**。  
> **热词抢占（指南表里的①）路径明确不做。**  
> **工具/分步/找词细则** → [实操手册-垂直细分与稳定增长.md](实操手册-垂直细分与稳定增长.md)  
> 若你口头说的「第一和第三」其实是指热词+稳定，请当场纠正；当前按 **垂直起手 + 稳定节奏** 落盘（与 ADR-0005 一致）。

---

## 0. 先用一个比喻记住整条路

你要开的不是「全世界最大的超市」，而是：

1. **先开一家只卖一样刚需小东西的路边小店**（垂直细分）——东西具体、好找、你做得动。  
2. **店开了以后，天天扫地、写小黑板、去附近社区串门**（稳定增长 + 冷启动）——慢慢变成「这片区的人想到这类东西就想到你」。

热词抢占像「演唱会门口 3 小时摆摊抢限量周边」：窗口短、拼手速。你现在不走这条。

```text
选一个很窄、很具体的词/场景
        ↓
做一个最小网页/小工具（能点、能付或能留线索）
        ↓
自己去 Reddit 等地方发帖、聊天、回每一条（冷启动）
        ↓
用表记下：发了啥、谁回了、我跟进了没
        ↓
有人真付钱或强行动 → 再加内容、SEO、外链（长稳定）
没信号 → 换词或改说法，不硬加功能
```

## 1. 垂直细分是什么？（指南打法二）

### 1.1 一句话

**不要做「所有人的大词」，做「某一类人、某一个具体场合、只干一件事」的小词。**

| 太宽（难） | 够窄（更像垂直） |
|-----------|------------------|
| AI 图片生成器 | 婚纱照 AI 生成 |
| AI 写真 | 证件照 AI 生成 |
| 简历工具 | 程序员 Tailwind 风格简历（Viking 例，仅作形态参考） |

宽词 = 操场上很多人抢球，你是新人插不进。  
窄词 = 小巷子里的需求，人少一点，但你更容易被搜到、也更容易讲清楚「我帮你干啥」。

### 1.2 为什么新手更适合

- **好理解**：用户搜这个词时，脑子里画面是清楚的（要证件照、要某场景图），不是「随便玩玩 AI」。  
- **相对好排**：指南软门槛是月搜大概 1000+、竞争度 KD 大概 0–30（不同工具分数不能横比；**真去 Google 看前 10 页比光看数字重要**）。  
- **好做最小版**：一页工具或一页说明 + 按钮，就能开始试，不用先造大平台。

### 1.3 你怎么「找」这样一个词（小学生步骤）

1. **想 5～10 个种子**  
   问自己：我了解谁的麻烦？什么场合会反复出现？英文可以长成  
   `xxx generator` / `xxx maker` / `xxx template` / `xxx for [人群]`。  
2. **拿免费工具扩词**  
   AITDK、Google 搜索框自动补全、「别人还搜了」、Trends 看稳不稳。  
3. **扔掉明显打不过的**  
   品牌名锁死、首页全是官方/巨头、你两个月做不出来的。  
4. **只留 ≤3 个，再只深挖 1 个**  
   打开 Google 前 10：是工具站还是文章？有没有小破站？有没有标价？  
   你能不能说出 **3 条比他们具体更好**（更快/更便宜/更贴场景/说明更清楚……）。  
5. **拍板**  
   `go`（这周就做最小页去试）/ `watch` / `narrow`（再收窄）/ `reject`。  
   **一次只 dig 一个主词**，不要并行五条「好像都行」。

细节清单见：[第一步-垂直选词与简单闭环.md](第一步-垂直选词与简单闭环.md)

### 1.4 垂直选完，你手里应该有什么

- 一句话：**谁 + 在什么场合 + 要完成哪一件事**  
- 一个英文主词（或极小词群）  
- 一眼能讲清的收费/试用说法（哪怕以后改价）  
- 「go」的理由：有人搜/有人付过类似的/你做得动/SERP 不是铁板

还没有这些，就还在「选词」，别急着写完整产品。

## 2. 稳定词优化 / 长期稳定增长是什么？（指南打法三）

### 2.1 一句话

**选定窄方向之后，不三天换赛道；用内容、站内结构、外链、多平台露面，让流量和信任慢慢堆厚。**

指南里的「稳定词优化」常指：词本身可能已经有点格局，靠**持续更新**往上顶。  
和你路径叠在一起时，更准确的说法是：

- **切口**用垂直（小而具体）  
- **节奏**用稳定（周更内容、外链、社区、产品小迭代）  
- **时间感**：常见是数月级，不是三天爆

### 2.2 和「垂直」什么关系？

| | 垂直细分 | 稳定增长 |
|--|----------|----------|
| 解决什么 | **做哪一件小事** | **做成之后怎么持续有人来** |
| 时间 | 先定下来（天～周） | 拉长（月～半年+） |
| 失败信号 | 词没人要、打不过 | 有站但不露面、不更新、不回帖 |

它们是 **叠加**，不是二选一：  
先垂直定「卖啥」，再用稳定定「怎么天天有人知道你」。

### 2.3 稳定期你具体干什么（先记菜单，有信号再加深）

**简单闭环阶段（现在优先）**

- 最小页在线，价格/按钮是真的  
- **冷启动发帖**（见下节），不是等 Google 发善心  
- 台账：发了哪、谁回了、跟进了没  

**长闭环阶段（有人付钱或强行动之后）**

- 围着主词写内容（一周一到两篇量级是指南口径，可按你精力裁）  
- 交 Sitemap、看 Search Console  
- 外链与目录站、更多平台  
- 产品按真实抱怨加一点，不按想象加十个功能  

### 2.4 稳定 ≠ 躺着不动

「稳定」是 **节奏稳**，不是 **人不出现**。  
不做推广的「稳定站」= 森林里的自动贩卖机，没路标。

## 3. 冷启动：为什么流量放大里它这么关键

### 3.1 一句话

**海外你几乎没有粉丝时，第一批用户要靠你「走出去」：发帖、聊天、回评论，而不是只改代码。**

Viking 的可抄点（产品形态不用抄）：

- 每天大约 **1～2** 个平台/版块，不 spam  
- Reddit：先看版规和该版什么样的帖受欢迎，再发；禁广就别硬广  
- **自己帖下面每一条评论都认真回**  
- 多平台「无心插柳」：单个帖可能扑街，组合起来才有第一笔钱和第一批外链  

详见：[Viking-冷启动第一笔100美元.md](../4-流量放大/Viking-冷启动第一笔100美元.md)

### 3.2 「在 Reddit 活跃气氛」到底在干什么

不是刷存在感灌水，而是：

1. **先做人**：在目标人群版块正常回答别人的问题（真有帮助）  
2. **再露产品**：规则允许时发 Show / 反馈帖，或签名式轻提  
3. **帖下运营**：有人问价、质疑、要功能 → 你是客服 + 销售 + 产品调研  

这三步里，**第 3 步最吃记录**——你人在海外、时差和多帖并行时，靠脑子记一定会漏。

### 3.3 和 SEO 的关系（别对立）

| 冷启动 | SEO/内容 |
|--------|----------|
| 快：几天～几周可能见到人 | 慢：常要更久才有稳定搜索 |
| 你主动出现在社区 | 人通过 Google 找到你 |
| 早期验证「有没有人在乎」 | 后期降低获客边际成本 |

**现在**：冷启动扛「第一批人」。  
**以后**：SEO/内容扛「睡觉时也有人来」。  
两条都要，但顺序是 **先能对话、再堆资产**。

## 4. 你要的「记录」：先定要看见什么（工具后置）

你已经说了：实际操作时再用飞书多维表/推送；现在先把 **必须能看见的三件事** 写死，避免以后表建歪。

### 4.1 每天要能回答的三个问题

1. **我今天/这周发了几帖？发在哪？**  
2. **这些帖下面现在有什么新内容？**（赞、评、骂、提问）  
3. **谁回复了？我要不要建联？建联到哪一步了？**

### 4.2 最小字段（飞书多维表以后按这个建就行）

**表 A · 发帖台账（一行 = 一条帖）**

| 字段 | 干啥用 |
|------|--------|
| 日期 | 哪天发的 |
| 平台 | Reddit / IH / HN / X / 目录站… |
| 版块或网址 | 具体 r/xxx 或链接 |
| 帖链接 | 一键点开 |
| 文案版本 | A/B，方便以后知道哪种话有效 |
| 目的 | 求反馈 / 分享故事 / 回答贴里顺带… |
| 浏览/赞/评（可手填） | 粗效果 |
| 状态 | 监测中 / 已冷 / 已总结 |
| 备注 | 版规、是否险些违规等 |

**表 B · 互动与建联（一行 = 一个值得跟的人/一条关键回复）**

| 字段 | 干啥用 |
|------|--------|
| 来源帖 | 关联表 A |
| 对方昵称/主页 | 是谁 |
| 原话摘要 | 他到底要啥/喷啥（尽量贴用户语言） |
| 我是否已回复 | 是/否 + 回复时间（**第一时间响应**靠这列） |
| 建联状态 | 未跟 / 已回帖 / 已私信(合规) / 已约 / 已付费 / 放弃 |
| 下一步动作 | 一句人话：例如「明天回功能问题」 |
| 截止提醒 | 可选；飞书推送以后挂这里 |

**表 C · 每日计数（一行 = 一天，可透视生成）**

| 字段 | 干啥用 |
|------|--------|
| 日期 | |
| 发帖数 | 回答「每天发几个」 |
| 新回复数 | 粗监控量 |
| 待回条数 | **今天必须清的清单** |
| 新建联数 | 关系有没有往前走 |

### 4.3 原则（现在就遵守，不依赖飞书）

- **先有表结构，再谈爬虫/自动推送**；手工填两周也比零记录强。  
- **待回条数 > 0 时，优先回帖，再开新帖**（Viking：engage everyone under your post）。  
- 私信只在 **版规允许或对方愿意** 时；不群发、不伪装。  
- 点赞不算胜利；**提问、留邮箱、点购买、付钱** 才往「闭环」记一笔。

术语上，这就是路径里的 **信息台账** 在冷启动上的展开；实现细节等你开跑时再落飞书。

## 5. 两条路叠在一起时，你「尝试」的顺序

```text
本周：阶段 A 垂直选词
  → 1 个主词 go/reject
有 go：阶段 B 简单闭环
  → 最小页 + 真 CTA
  → 冷启动发帖（Viking 节奏）
  → 台账三问（可先表格手记）
  → 2 周量级看有没有真行动
有信号：阶段 C 稳定加深
  → 内容 / SEO / 外链 / 产品小步
无信号：换词或改承诺，不先做自动化大系统
```

**现在不做什么**

- 不搭完整监控中台、不先写爬虫（你已说操作时再定）  
- 不并行多个主词  
- 不做热词抢占  
- 不复活已 reject 的旧三方向（ADR-0006）

## 6. 和指南数字的关系（防幻觉）

指南里的月收入曲线、转化率、KD 门槛都是 **作者口径/个案**，用来建立数量级感觉，不是你的 KPI 合同。  
你的合同只有更土的一句：

> 我选的这个窄场景，有没有陌生人愿意为了它留下行动或付钱？
