# SOP：垂直选词人机闭环（标准模式）

> 2026-08-09 起默认。由第 5 轮 `tattoo stencil maker` 实战后沉淀。  
> 目标：**可复用找词 + 场景理解 + 拍板**，不绑定某一赛道；工具可换，顺序尽量不跳。  
> 术语见 `CONTEXT.md`；量/KD 纪律见 ADR-0007。  
> **项目 skill（仅出海/overseas）**：`vertical-keyword-loop`（`.claude/skills/`，`scope: project`；方法自包含，不绑本库笔记路径）。  
> 同项目可选：`direction-validator`（证据卡/闸门更全）。**不装 global**——非出海项目不加载。

---

## 0. 一句话

```text
发现词 → 取证（SERP + 量/KD + 趋势/国家）
  → 短名单（≤3）
  → 人打开网页 + 插件读流量
  → YouTube/真实流程还原场景与痛点
  → go / watch / narrow / reject
```

- **Agent**：找词草稿、拉数、爬已打开页、写词表与灯色建议、拆竞品缺陷。  
- **Kun**：开网页建体感、补 Agent 不好拿的渠道、看 YouTube、**最终拍板**。  
- **不做**：凭感觉填月搜/KD；人没看过场景就 go 做完整产品；与巨头/成熟站**同一句话硬刚**。

## 1. 找词（Seed）

### 1.1 Agent 默认可执行的发现方式

| 方式 | 做什么 | 产出 |
|------|--------|------|
| 场景脑暴模板 | `{场景} generator/maker/template/converter` 等 | 种子短语 |
| Google 自动补全 | suggestqueries 或真输入框 | 说法变体 |
| Google 相关搜索 / PAA | 搜完滚到底 | 问法、长尾 |
| Google Trends | 词 + **多国对比** + related/rising | 形状、优先国家、相关词 |
| 社区公开检索 | `site:reddit.com` 等（合规；登录态社区用 Chrome） | 人话、抱怨 |
| 竞品站抄导航/H1 | 打开 1～2 个结果站 | 类目词 |
| AITDK Keywords Generator | 网页扩词 | **仅说法**，不是月搜 |
| 词找站 / 站找词 | 搜词看谁在排；从站反推词 | 词群扩大 |

可加、不绑死：Trends rising 递归（有上限）、公开榜单、差评区用词。

### 1.2 Kun 补全（Agent 不方便或要登录/插件时）

| 你做什么 | 为何 |
|----------|------|
| 无痕 Google（`hl=en&gl=国家&pws=0`） | 真 SERP、少个性化 |
| 打开 AITDK 插件看站/看 SERP 旁指标 | 月访问、站龄等 |
| Trends 里切换/对比国家 | 选市场，不默认死磕美国 |
| 登录态社区（Reddit 等） | 版规内人话 |
| 把词表/截图贴回对话 | Agent 继续取证 |

**国家**：默认常看 US，**不是唯一**；谁涨、谁好做 SERP，谁优先（见 CONTEXT「按国看趋势」）。

### 1.3 找词完成标准

- 有 **5～15 条种子**（英文短语 + 中文「谁×场合×任务」备注更好）  
- 标了来源（Trends / 社区 / 脑暴 / 你贴的）  
- 已粗杀掉明显巨头盘/已 reject 方向（ADR-0006）

## 2. 取证（每个准备进短名单的词）

| 必做 | 怎么做 | 记录 |
|------|--------|------|
| **真 SERP** | 目标国 Google 前约 10 | 域名、页型、强/薄 |
| **月搜 / KD** | Ahrefs 免费 KD、插件、🔑 Overview… | 厂商、日期、精确或线索/No data |
| **Trends** | 目标国 + 可选多国；时间建议 1y 或 5y | 涨/稳/尖刺；related |
| **付费线索** | 点进 3～5 结果 | 有无价、订阅、积分 |
| **3 条具体更好** | 相对前排 | 写得出才算承接有缝 |

纪律：**证据硬、阈值软**；**SERP 优先于裸 KD**；参考带约 1000+ & KD 0–30 不卡死（ADR-0007）。

### 取证完成标准

- 短名单 **≤3 词**  
- 每词：需求一句话 + 量/KD 字段 + SERP 摘要 + 灯色建议  
- 禁止空数字

---

## 3. 短名单与交付（Agent → Kun）

交付物固定：

1. 词表（作战卡列）  
2. ≤3 深挖简报  
3. 每词 **谁×场合×任务** 一句话  
4. 灯色建议（go/watch/narrow/reject）  
5. 数据缺口清单  

**不在此步**：建完整产品、同时深挖 >1 个主词。

---

## 4. 人开网页建认知（Kun 主场）

对**准备拍板的 1 个主词**：

1. 自己打开：Google SERP、前排 3～5 竞品、Trends  
2. 开 AITDK（或同类）看流量/站龄  
3. 告知 Agent「页已开好」→ Agent **复读已开标签**补竞品表  

目的：建立「这是一门什么生意」的体感，不是替 Agent 打工。

---

## 5. YouTube / 真实流程还原场景（决策前强烈建议）

> 第 5 轮教训：没行业体感时，只看 SERP 容易「觉得能做」或「吓跑」；**视频还原流程**后再拍板。

| 步骤 | 做什么 |
|------|--------|
| 1 | 用主词或任务句搜 YouTube，如 `how tattoo stencil works` / `thermal stencil printer` |
| 2 | 看 1～3 条 **实操向**（店里/学徒），跳过纯广告片 |
| 3 | 记：**输入是什么 → 手怎么做 → 输出贴到哪 → 痛在哪一步** |
| 4 | 对照竞品：工具省的是哪一步？还缺哪一步？ |
| 5 | 用小学生能懂的话写 5 行「场景卡」（见模板） |

### 场景卡模板（每主词一张）

```text
主词：
谁：
场合（什么时候急着做）：
任务（成功长什么样）：
现在不用我们的产品怎么凑合：
最痛的一步：
我是否大致看懂（是/否）：
是否值得本周投入（go窄/watch/换词）：
```

**完成标准**：Kun 能不看笔记口述流程；说不清 → 不 go，只 watch 或换词。

## 6. 决策

| 灯色 | 条件（经验） | 下一步 |
|------|----------------|--------|
| **go（宜窄）** | 场景懂了 + SERP 可打 + 有付费线索 + 能写清**不与头名同一句话**的切口 | 最小页 + 真 CTA（阶段 B） |
| **watch** | 数/SERP 还行，场景未懂或 KD 略偏或竞品密 | 补 YouTube/样张对比或换窄切口 |
| **narrow** | 需求真、切口错（如量极低的纯转换器） | 改词/改任务再取证 |
| **reject** | SERP 铁板 / 无付费理由 / 你做不了或不愿懂场景 | 记原因，回找词 |

**分食原则**：大站有流量 ≠ 不能做；**禁止**在其主叙事上硬刚；找缺陷与更窄人群/任务。

## 7. 案例锚点：tattoo stencil（跑通 SOP 用，非强制做产品）

| 项 | 内容 |
|----|------|
| 主词 | `tattoo stencil maker` |
| 场景（简化） | 纹身前要在皮肤上先有一份**线稿底样（stencil）**。常见：设计/照片 → 做成高对比线稿 → 打在转印纸/热敏纸上 → 贴到皮肤上定位，再上真色。手描慢，故有人买「图转 stencil」工具。 |
| 取证摘要 | Ahrefs KD≈38；量线索主词约 1000 级；词群更大；Trends US 曾见同比大涨；SERP 多小工具/App；竞品有订阅。 |
| AITDK/SERP 级流量感 | 通用老站、新 AI 站、专职订阅站并存（数万～十余万月访量级竞品），**可分食须更窄**。 |
| 灯色（流程案例） | **watch / 可 go 窄**；不建议无体感时做「又一个全能 photo→stencil」。 |
| 若继续做产品 | 须先场景卡 + 多站同图对比 + 唯一承诺句（如转印 PDF/线宽/学徒价）再最小页。 |
| 若只当 SOP 样例 | 流程到「场景看懂 + 词表归档」即可，**允许换词**开下一轮。 |

材料：`实践-垂直选词-第5轮-2026-08-09.md`。

- [ ] 种子有来源

- [ ] Trends/国家看过  
- [ ] 人打开过网页（主词）  
- [ ] YouTube/流程场景卡写过（拍 go 前）  
- [ ] 灯色 + 一句话理由
